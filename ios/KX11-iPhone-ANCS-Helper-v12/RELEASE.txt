KX11 ANCS Helper v12
====================

Companion release: Status Widget v2.8.2-ha1162
Bundle identifier: ru.natro.kx11ancshelper
Marketing version: 12.0
Build number: 12
Minimum iOS version: 13.0

Release verification
--------------------

- Default role is Peripheral and keeps the v11 iPhone_ANCS route.
- Central role scans only for Geely_ANCS, connects with RequiresANCS and uses system
  auto-reconnect on iOS 17+.
- PAIR plus encrypted SECURE fixes the peer before KX11 performs same-peer ANCS attach.
- Role changes stop the previous Core Bluetooth route before starting the next one.
- B4 telemetry is READ/NOTIFY in Peripheral mode and encrypted WRITE in Central mode.
- Background modes contain bluetooth-central and bluetooth-peripheral.
- The modern disconnect callback remains visible to the iOS 13 deployment target, as required by
  current Xcode SDK protocol-conformance checks.
- Classic Bluetooth profiles and names are untouched.
