KX11 ANCS Helper v40
Bundle ID: ru.natro.kx11ancshelper
Build: 40
Marketing version: 40.0
Matched Android build: Status Widget v2.8.2-ha1205

Recommended production configuration: Helper **Peripheral** + Status Widget **iPhone
Peripheral** (the defaults). The Central/Central ANCS configuration remains available only as an
alternate diagnostic/recovery route.

Changes from v39:

- automatic protocol recovery may cancel/reconnect an exact RequiresANCS owner only once for the
  complete retained CBPeripheral/restoration lineage;
- didDisconnect, didFailToConnect and the replacement didConnect no longer re-arm that destructive
  budget, closing the observed 38-cycle `uuidNotAllowed -> cancel -> reconnect` storm;
- if the replacement F04 namespace is still stale, Helper retains the live owner and waits for
  Service Changed/new exact F04 publication instead of issuing another cancel;
- exact-current-object F04 invalidation re-arms one automatic recovery; a different owner or a
  stopped/restarted route begins a new lineage; a complete B3 + ANCS-READY + Android ANCS/B4 CCCD
  proof also re-arms it, while didConnect/discovery alone never do;
- explicit manual reconnect remains independent and usable after the automatic budget is spent,
  but does not silently re-arm automatic cancellation;
- all v39 exact-owner B3/ANCS-READY, authoritative Android CCCD proof, bounded restoration claims,
  two-sided restored-B4 proof, publication object-lineage and poweredOn gating remain unchanged;
- bundle identifier, restoration identifiers, saved Geely identity and system pairing are kept.
