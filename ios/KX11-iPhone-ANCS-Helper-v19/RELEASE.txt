KX11 ANCS Helper v19
====================

Companion release: Status Widget v2.8.2-ha1176
Bundle identifier: ru.natro.kx11ancshelper
Marketing version: 19.0
Build number: 19
Minimum iOS version: 13.0

Release verification
--------------------

- Central mode publishes a non-advertised generation-3 B4 READ/NOTIFY relay on the iPhone GATT
  owner while generation 2 remains the PAIR/B3 bootstrap service on KX11.
- Android reads and subscribes generation-3 B4 on the already-working ANCS client; telemetry does
  not require a second post-handoff BLE connection.
- The generation-2 Central B4 write/wake loop is removed, so a stale bootstrap handle cannot reset
  an otherwise healthy ANCS session.
- Helper stops reconnecting Central after a secure handoff and waits up to 30 seconds for a B4
  read/subscription proof; loss of the relay gets a five-second grace period.
- Battery percentage and cable/charging/full state come directly from public UIDevice APIs.
- Network type comes from a fresh public CoreTelephony snapshot and is normalized before encoding.
- The frame remains A5/01, eight bytes, little-endian sequence and CRC-8/ATM.
- Default Peripheral mode preserves the v11 iPhone_ANCS route.
- Core Bluetooth system auto-reconnect stays disabled for the Central bootstrap.
- Background modes contain bluetooth-central and bluetooth-peripheral.
- Classic Bluetooth profiles, names, pairing, the system LE bond and ANCS authorization are
  untouched.
