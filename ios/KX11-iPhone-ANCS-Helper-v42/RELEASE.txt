KX11 ANCS Helper v42
Bundle ID: ru.natro.kx11ancshelper
Build: 42
Marketing version: 42.0
Matched Android build: Status Widget v2.8.2-ha1207

Recommended production configuration: Helper **Peripheral** + Status Widget **iPhone
Peripheral** (the defaults). The Central/Central ANCS configuration remains available only as an
alternate diagnostic/recovery route.

Changes from v41:

- ordinary reclaim marks a request as issued only after the actual `centralManager.connect` call;
  a consumed/queued intent or an already `.connecting` wrapper cannot forge that authority;
- every actual issued request captures a monotonic token, exact saved owner and current fixed F04
  publication generation (`2F04`); a later ordinary terminal binds that retained provenance to
  the descendant AutoReconnect terminal/evidence generation. A new direct actual request does not
  require AutoReconnect; only reuse of its token across a later terminal does;
- a later exact saved-ID/current-2F04 beacon for that same request token may arm the short
  `didConnect` grace even when the F04 system table has not materialized; the existing exact
  system-table route remains available in parallel;
- a beacon without a matching issued token, or one observed before the latest terminal/connect,
  remains read-only and can never cancel an owner;
- a qualifying beacon delivered while the wrapper still reports `.disconnected` is retained for
  that exact token/generation and arms grace only when the observer later sees `.connecting`;
- `didConnect`, `didFailToConnect`, `didDisconnect` and Bluetooth power-off invalidate pending
  request evidence/grace. Terminal and power callbacks preserve the active/spent one-shot budget;
  only full green proof, validated replacement F04, manual reconnect or a new owner/route re-arms;
- the claim is consumed before its sole cancel, waits for a terminal callback or observed
  `.disconnected`, and reopens the same owner once; no later beacon/terminal can form a storm;
- all v41 Service Changed validation, bounded restoration claims, two-sided restored-B4 proof,
  exact-owner B3/ANCS-READY, Android CCCD proof and poweredOn gating remain unchanged;
- bundle identifier, restoration identifiers, saved Geely identity and system pairing are kept.
