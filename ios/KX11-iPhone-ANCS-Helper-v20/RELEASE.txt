KX11 ANCS Helper v20
====================

Companion release: Status Widget v2.8.2-ha1177
Bundle identifier: ru.natro.kx11ancshelper
Marketing version: 20.0
Build number: 20
Minimum iOS version: 13.0

Release verification
--------------------

- A token invalidates every cancelled Central connect timeout, so stale work cannot reset a newer
  connection.
- A timeout that resumes while Core Bluetooth is still `.connecting` gives the queued
  `didConnect` callback one three-second grace period before recovery.
- A peripheral already `.connected` at timeout resumes discovery without being cancelled.
- Core Bluetooth restoration reuses the saved/connected/connecting peripheral and does not start
  a parallel connect.
- Delayed reconnect work is tokenized and cancelled when a live connection wins.
- v20 restoration identifiers isolate the new state machine from outstanding v19 manager state.
- Central mode retains the non-advertised generation-3 B4 READ/NOTIFY relay on the iPhone GATT
  owner; generation 2 remains the protected PAIR/B3 bootstrap on KX11.
- Battery percentage and cable/charging/full state come from public UIDevice APIs.
- Network type comes from a fresh public CoreTelephony snapshot.
- The frame remains A5/01, eight bytes, little-endian sequence and CRC-8/ATM.
- Core Bluetooth system auto-reconnect remains disabled for the Central bootstrap.
- Classic Bluetooth profiles, names, pairing, the system LE bond and ANCS authorization are
  untouched.
