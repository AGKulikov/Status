KX11 ANCS Helper v29
====================

Companion release: Status Widget v2.8.2-ha1191
Bundle identifier: ru.natro.kx11ancshelper
Marketing version: 29.0
Build number: 29
Minimum iOS version: 13.0

Release verification
--------------------

- Central mode scans a stable beacon and decodes the Android GATT generation before connecting.
- Bootstrap service, CONTROL B2, and SECURE B3 UUIDs are derived from that generation.
- Restored fixed-F04 owners are discarded; a fresh namespace advertisement is mandatory.
- Phase one uses RequiresANCS=false, writes PAIR and ANCS-HANDOFF, then releases the link.
- Android never schedules the old 350-ms GATT-server cancel after ANCS-HANDOFF.
- Phase two uses RequiresANCS=true, rediscovers dynamic B3, and writes ANCS-READY.
- didConnect and B4 traffic remain yellow; neither is accepted as proof of ANCS readiness.
- Green requires Android's ANCS-SUBSCRIBED acknowledgement after both ANCS CCCDs succeed.
- F05/B4 carries live telemetry and the post-CCCD acknowledgement on the same ATT owner.
- Restoration identifiers move to v29 so older callbacks cannot own the new state machine.
- Classic Bluetooth profiles, names, pairing, LE bond, and ANCS authorization remain untouched.
