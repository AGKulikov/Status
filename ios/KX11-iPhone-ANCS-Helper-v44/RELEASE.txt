KX11 ANCS Helper v44
Bundle ID: ru.natro.kx11ancshelper
Build: 44
Marketing version: 44.0
Matched Android build: Status Widget v2.8.2-ha1210

Changes from v43:

- adds one exact-owner restoration-publication adoption for the observed system-owned
  `.connecting` state which has no app-issued connect token;
- requires fixed generation 2F04 manufacturer protocol 2 and a nonce strictly newer than the
  current restoration/terminal baseline;
- rejects protocol 1, malformed, foreign, same, older, pre-boundary and timeout-only evidence;
- uses bounded low-duty `AllowDuplicates=true` observation so one exact wrapper can advance from
  baseline N to N+1, with terminal-boundary and stale-work token guards preventing scan overlap;
- shares the durable `(owner, nonce)` spent record with ordinary automatic adoption and reads the
  v43 record during upgrade, so the same publication cannot cancel again after restart;
- consumes the shared ordinary/restoration destructive root before exactly one cancel;
- waits for an exact terminal callback or read-only `.disconnected` state, then materializes one
  RequiresANCS reopen whose root remains spent;
- suppresses duplicate cancel/connect work across late callbacks and Bluetooth power transitions;
- binds the sole reopen to its actual issued token, quarantines an old delayed terminal while the
  new request is connecting/connected, and keeps a spent no-second-connect gate across power-off;
- preserves an iOS 17 `isReconnecting=true` owner across transient disconnected power snapshots
  until the matching system didConnect, without another Helper connect;
- preserves the committed Helper v43/v42/v41 contracts, bundle/restoration identifiers, saved
  owner identity and Classic/LE pair.
