KX11 ANCS Helper v22
====================

Companion release: Status Widget v2.8.2-ha1178
Bundle identifier: ru.natro.kx11ancshelper
Marketing version: 22.0
Build number: 22
Minimum iOS version: 13.0

Release verification
--------------------

- Public iOS protected-data lock/unlock events update the telemetry snapshot immediately.
- B4 frame flag bit 5 is set while the iPhone is locked and cleared while it is unlocked.
- The frame has no separate state-valid bit and retains the exact A5/01 eight-byte shape.
- The one-second sampler and 30-second heartbeat carry the current lock state after recovery.
- A filtered B2/B3 `CBError.uuidNotAllowed` now retries one unfiltered characteristic discovery
  on the same connected ATT link instead of entering an endless disconnect/rescan loop.
- v22 restoration identifiers isolate this Helper generation from outstanding v21 manager state.
- Central mode retains the non-advertised generation-3 B4 READ/NOTIFY relay on the iPhone GATT
  owner; generation 2 remains the protected PAIR/B3 bootstrap on KX11.
- Battery percentage and cable/charging/full state come from public UIDevice APIs.
- Network type comes from a fresh public CoreTelephony snapshot.
- The frame remains A5/01, eight bytes, little-endian sequence and CRC-8/ATM.
- Core Bluetooth system auto-reconnect remains disabled for the Central bootstrap.
- Classic Bluetooth profiles, names, pairing, the system LE bond and ANCS authorization are
  untouched.
