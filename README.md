# Natro

Natro — приложение для Geely Monjaro KX11 / ECARX Android 9: основной экран, HUD, собственная панель приборов, навигация, управление медиа и интеграции умного дома. Пакет приложения — `ru.natro.statuswidget`.

## Текущий выпуск

**3.5.9 от 27.11.2026.** Исправлено подключение ADB и восстановлен стандартный путь сбора QNX. Natro обновляется поверх 3.5.8 с прежним сертификатом. Совместимая версия Навигатора — 30.3.0 Natro 3.5.8. [Скачать обновление](https://github.com/AGKulikov/Status/releases/tag/natro-v3.5.9) · [Ветка разработки](https://github.com/AGKulikov/Status/tree/release/natro-3.5.9)

ADB принимает готовность CNXN и штатный запрос AUTH. QNX подключается через ADB к службе приборки на порту 8000. Сохранённый SSH-профиль выбирает SSH. В разделе «Доступ к QNX» доступна проверка ответа службы. Журнал белой полосы отдельно показывает, выполнено ли чтение режима приборки.

Прошли 2 386 тестов Android и 323 проверки инструментов. APK скачан из публичного канала, подпись проверена для Android 9. Подключение к конкретной магнитоле, сбор QNX и исчезновение белой полосы требуют проверки после установки. [Протокол выпуска](docs/releases/3.5.9/README_RU.md)

## Разработка и проверка

Прочитать [AGENTS.md](AGENTS.md) и относящиеся к изменению требования. Для сборки использовать закреплённые исходники и явную пару versionName/versionCode; не принимать исторический Gradle default за номер текущего выпуска. Подпись, пакеты и данные пользователя сохраняются. Собственные исходники и доказательства выпуска публикуются; приватные ключи и исходные пользовательские журналы — нет.

SOURCE означает наличие реализации, TEST — выполненные проверки, APK — проверенные установочные файлы, PUBLISH — проверенную публикацию, FIELD — результат на автомобиле. Эти состояния не заменяют друг друга. Ревизия 24.11.2026 меняет только документацию и не выпускает новый APK.
