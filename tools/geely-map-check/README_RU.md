# Проверка запуска карт Natro — Mac, версия 1.0.0

Этот сборщик нужен для отказа HUD и приборки после обновления Navigator mapfix.
Он собирает журнал Android и состояние приложений, необходимые для следующего
шага диагностики. Снимки поездки таких данных не содержат.

1. На стоящей машине оставьте Natro и Навигатор включёнными в состоянии, когда
   карты не запускаются. Не очищайте журнал и данные приложений.
2. Подключите Mac к магнитоле через прежний ADB, как для сборщика поездок.
3. Распакуйте архив и откройте `Collect-Maps.command`.
4. Дождитесь завершения — общий предел 90 секунд. На рабочем столе появится
   `Natro-Map-Check-ДАТА-ВРЕМЯ-….zip`. Пришлите этот ZIP, даже если сбор частичный.

Если macOS не открывает файл двойным щелчком, в Терминале введите `bash` и пробел,
перетащите `Collect-Maps.command` в окно и нажмите Enter.
Нужны прежние ADB и Python 3.8+, дополнительные Python-пакеты не требуются.
При нескольких устройствах используйте `--serial` для магнитолы. Для нестандартного
расположения ADB есть `--adb /путь/к/adb`. `--plan` показывает план без соединения.

В ZIP сохраняются:

- ошибки наших компонентов MapKit/Surface/bridge и AndroidRuntime из logcat;
- существующий журнал Natro, если он включён и доступен через прежний root;
- версии пакетов и SHA-256 установленных APK — сам APK не копируется;
- службы, Activity, состояние окон и дисплеев, SurfaceFlinger и gfxinfo;
- статусы команд, ограничения, хеши сохранённых файлов.

Сборщик только читает Android. Он не устанавливает APK, не меняет настройки,
не сбрасывает поездки, не очищает логи и не перезапускает приложения или службы.
Каждая удалённая команда ограничена 10 секундами, потоки имеют пределы размера.
Сбой отдельного чтения сохраняется вместе с остальными доступными результатами.
При отсутствии root сохраняется доступная диагностика без приватного журнала Natro.
Выбор одного ADB-устройства и бинарный транспорт проверяются до основного сбора.

Архив предназначен для этого разговора: логи и заголовки окон могут содержать
пользовательские сведения. Исходные записи не публикуются в Git. Настройки аккаунтов,
пароли, APK и образы прошивки сборщик не скачивает.

Сценарий проверен офлайн; на KX11 эта версия ещё не выполнялась. Успешный сбор
означает получение диагностики, а не восстановление работы карт.
