# Status Widget HA1182 + iPhone Helper v25

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1182`

Version code: `208021182`

## Sprut.hub

- Password proof now follows the current official `beta.spruthub.ru` client exactly:
  `Argon2id(password, rootSalt, kdfParams)` produces the 32-byte Ed25519 seed and the challenge
  is signed directly.
- The incorrect extra HKDF-SHA256 stage from HA1181 is removed. That stage produced a valid
  Ed25519 signature for the wrong key and caused `Sprut.hub authentication failed`.
- An independent hash-wasm/Node Ed25519 vector protects the protocol from another silent drift.
- Password, derived seed, token and challenge contents are never written to the journal.

## iPhone BLE / ANCS

- The reported Helper v24 connection reaches the live D2D9 service, but iOS rejects every B2/B3
  enumeration with `CBErrorDomain:8` (`uuidNotAllowed`). Repeating discovery or rediscovery on
  the same cached F02 database cannot change that state.
- Android and Helper move together to fresh private GATT namespaces:
  - protected PAIR/B3 bootstrap: generation 4, suffix `F04`;
  - iPhone-owned post-handoff B4 relay: generation 5, suffix `F05`.
- Helper restoration owners move to `v25/g4/g5`, so Core Bluetooth cannot restore pending v24
  operations into the new database.
- Existing bounded discovery, current-link security recovery, ANCS handoff, lock flag `0x20`,
  battery/network telemetry and notification backpressure handling remain unchanged.
- Classic HFP/A2DP/PBAP, the system LE bond, Bluetooth names and ANCS authorization are not
  removed.

## Установка

1. Install Status Widget HA1182 and Helper v25 as one matched pair.
2. Open Helper once and choose **Central**.
3. In Status Widget choose **Phone → iPhone BLE role → Central**.
4. Do not delete the Classic pair or the system LE pair.
