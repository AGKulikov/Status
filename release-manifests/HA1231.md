## Provenance boundary

The exact Android source snapshot used to create the supplied Natro 2.1.2 APK was lost. This
release restores the missing 2.1.x behavior as normal reviewable Java, resources, tests, Helper
source, fixtures and GitHub workflows on top of the last available source history. The supplied
2.1.2 APK and the documented 2.1.3 binary-recovery patch were used as forensic references.

This release does **not** claim byte-for-byte reconstruction of that unavailable snapshot and
does **not** claim successful physical KX11/iPhone acceptance before the matrix below is run. It
does provide one complete Git commit, full source archive/bundle, reproducible unsigned Android
handoff, and separately verified signing input.

## Restored and corrected behavior

- HOME attaches an opaque shell before preference migration, PackageManager queries, icon decode,
  vendor car construction or decorative JSON. Applications and action buttons are admitted first;
  application metadata is published before icons, visible icons decode on a dedicated worker, and
  adapter refreshes are coalesced.
- The selected iPhone's exact integer percentage comes first from the standard BLE Battery Service
  (`180F`, `2A19`, `2BED`) or Android's selected-device battery source. Full-range ECARX HFP is a
  later direct fallback. Helper and six-step HFP percentages are explicitly coarse fallbacks and
  cannot replace a newer exact reading. Helper remains authoritative for charging/external power.
- Phone battery warnings compare the exact integer and expose two independently configurable
  low-battery thresholds, colours and persistent hysteresis latches. Both enter the same ordered
  delivery queue as ANCS notifications and obey the same status-row, popup, lock-state,
  foreground-application and external-overlay switches.
- HWGPS route loss is armed by Natro's active-route repository, uses bounded current-state probes,
  and maps exported `filtered`/`spoofing` evidence immediately; ordinary `notFixed` retains the
  evidenced HWGPS confirmation and recovery hysteresis.
- LTE/network text reserves outline and typeface overhang on both edges, preventing `LTE`/`5G`
  clipping at compact sizes.
- Popup notification centring is owned by WindowManager `CENTER_HORIZONTAL`/`CENTER_VERTICAL`, not
  a stale logical display-width calculation.
- Android 9 accessibility window add/remove metadata can delay phone notifications behind 360°
  camera and other external overlay windows even when UsageStats does not report a new foreground
  application. Framework, IME, foreground and Natro windows are excluded; bounded expiry fails open.
- Global SystemUI content hiding remains separate from the launcher and never hides Natro's own
  TIME/Bluetooth elements. Existing KX11/OEM blacklist syntax is preserved with crash-safe
  ownership and rollback.
- Helper 52 adds explicit authenticated LE enrollment, encrypted pending/active WAL recovery,
  standard BAS publication and serialized on-demand telemetry refresh without a one-second poll.
  ANCS and control traffic retain priority, one GATT owner and generation fencing.

## Mandatory physical KX11/iPhone acceptance

1. Install 2.1.4 over 2.1.3 without uninstalling and retain all preferences, Classic pairing and
   Helper enrollment.
2. Measure cold HOME first draw, application-label availability, action-button availability and
   interaction latency for the first 60 seconds; compare the emitted startup markers.
3. Observe a non-five-percent battery value through Android/BAS, verify both configured warning
   thresholds on exact crossings, and test every row/popup/lock/overlay destination combination.
4. Exercise HWGPS route loss, `filtered`, `spoofing`, recovery and mid-route subscription while
   comparing the HWGPS widget and Natro scenario state.
5. Test LTE/5G at minimum and maximum icon/text/outline sizes and visually confirm no edge clipping.
6. Update/build/install Helper 52, perform SAS enrollment if needed, then test ANCS foreground and
   background reconnects, lock/unlock, radio restart, process restart, ACC cycle and 20 reconnects.
7. Enter and leave reverse/360° camera over Navigator and another application; confirm ordered
   notifications wait only while the material external window is present or until their deadline.
8. Verify popup horizontal/vertical centring on every KX11 display mode and with windowed Navigator.
9. Toggle global SystemUI content hiding across HOME, Settings and third-party apps, then restore it
   before uninstalling or clearing Natro application data.
