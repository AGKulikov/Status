# Status Widget HA1141

Version name: `v2.8.2-ha1141`

## Исправлено

- Весь HUD-рендерер, канал карты Навигатора, `ImageReader`, внешние окна и прямой
  SurfaceFlinger-слой перенесены в отдельный процесс `:hud`. Ошибка OEM/MapKit/HUD больше не
  может завершить основной процесс строки состояния, панели водителя и интеграций.
- На Android 9/ECARX полностью отключён опасный обход `AccessibilityWindowInfo` и дерева
  Навигатора. В отличие от HA1140, код не пытается выполнить эту операцию и затем перехватить
  исключение: потенциально аварийный вызов вообще не попадает в основной процесс.
- На Android 9 активное приложение определяется по компактному событию смены окна. Навигационные
  данные продолжают поступать через штатные broadcast/notification-контракты модифицированного
  Навигатора.
- Команды включения, выключения, применения конфигурации и обновления автоматизации передаются в
  изолированный HUD-процесс явно. JSON конфигурации передаётся вместе с командой, поэтому результат
  не зависит от задержки записи `SharedPreferences`.
- Состояние HUD для экрана диагностики хранится в отдельном атомарном межпроцессном файле. Падение
  только HUD записывается отдельно и не показывается как падение основного Status Widget.

## Совместимость

- Пакет: `ru.natro.statuswidget`.
- Версия: `versionCode=208021141`.
- Минимальная версия Android: 9 (API 28).
- Подпись: штатный ключ обновлений HA; установка поверх HA1140/HA1135 без удаления данных.
