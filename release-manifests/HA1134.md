# Status Widget HA1134

Version name: `v2.8.2-ha1134`
Version code: `208021134`
Package: `ru.natro.statuswidget`

## Sprut.hub cloud challenge login

- Supports the current `QUESTION_TYPE_CHALLENGE` password-proof step introduced by the Sprut.hub
  cloud relay.
- Reproduces the current official web client algorithm: Argon2id with the server-provided
  parameters, HKDF-SHA256 and an Ed25519 signature of the one-time challenge.
- Keeps compatibility with hubs that still return `QUESTION_TYPE_PASSWORD`.
- Runs the memory-hard proof on the connector's background executor instead of the WebSocket
  callback thread.
- Bounds all server-provided KDF and binary parameters to prevent malformed challenge data from
  exhausting the head unit.
- Passwords, derived keys, challenge payloads and signatures are never written to diagnostics.

## Upgrade compatibility

- Preserves package `ru.natro.statuswidget`.
- Uses version name `v2.8.2-ha1134` and version code `208021134`.
- Must be signed with the stable HA update certificate SHA-256
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`,
  so it installs over HA1133 without deleting settings.
