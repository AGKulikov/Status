# Status Widget HA1176 + iPhone Helper v19

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1176`

Version code: `208021176`

## ANCS-owner telemetry relay

- ANCS continues to use Android's same-peer GATT client after the reverse-route handshake.
- Helper v19 publishes an iPhone-owned generation-3 B4 READ/NOTIFY relay on that same GATT owner.
- Android reads one atomic battery/power/network snapshot before ANCS subscriptions and subscribes
  to B4 after ANCS reaches READY.
- Periodic reads keep exact battery percentage, charger state and LTE/5G current in the background;
  notifications remain the immediate change path.
- Generation-2 Central B4 writes are removed, eliminating stale-handle resets and the competing
  bootstrap reconnect loop.
- Classic Bluetooth, the selected iPhone identity and the system LE bond are preserved.
