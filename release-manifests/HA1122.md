# Status Widget HA1122

## HUD correction

- Fixes the false `system layer 1` success shown by HA1121.
- The supplied ECARX dump maps the verified HUD `Display ID 2` (`local:2`) to
  `SurfaceFlinger layerStack 2`; Android 9 blocks reflective access to
  `Display#getLayerStack()`, so HA1121 incorrectly fell back to stack 1.
- The direct 728×190 surface is now created on layer stack 2 at `(0,720)`.
- The lower WindowManager HUD copy remains attached as a fail-safe instead of disappearing as
  soon as the direct bridge acknowledges a frame.
- Runtime status now reports that SurfaceFlinger accepted the frame and the exact layer stack,
  rather than claiming that the stock graphics were physically hidden without verification.

## All applications

- A long press on any item in either runtime “All applications” drawer now opens Android's
  standard package-removal confirmation.
- The drawer is closed before Package Installer appears, so the ECARX system-layer window cannot
  cover the confirmation screen.
- Protected system applications remain subject to the firmware's normal uninstall restrictions.
