# Status Widget HA1161

Package: `ru.natro.statuswidget`
Version name: `v2.8.2-ha1161`
Version code: `208021161`

## CarPlay phone presentation

- Cellular bars and LTE/3G text use one measured CarPlay-style optical gap in the status row,
  driver information tiles and their preview.
- The iPhone battery has a persistent rounded case, proportional live fill, optional percentage
  and a dedicated charging bolt.
- Battery colour precedence is exact: `<=10%` red, `<=20%` yellow, otherwise white when
  unplugged and green while external power is connected.

## Driver panel sizing

- Every regular driver button can use an exact physical height or remain in automatic mode.
- Fixed buttons no longer consume the rail's free-height distribution; untouched automatic
  siblings recalculate to fill the remaining area.
- Existing per-button top and bottom values remain internal to the button.

## Phone notification overlay

- Both phone notification variants now use one persistent CarPlay-style semantic card instead of
  three unrelated popup rows.
- The WYSIWYG editor moves and resizes avatar, app badge, sender, time, application, message and
  chevron independently on a fine grid, with live rendering in the actual overlay window.
- Avatar and application-icon rounding are independent; the default preset is already composed as
  a compact CarPlay notification.

## Stability and diagnostics

- Unchanged popup states no longer replace WindowManager trees; notification content updates in
  place and short multi-field empty transitions retain the last complete frame.
- Media artwork from the previous track is rejected until a genuinely different bitmap arrives.
- Status Widget and iPhone Helper v10 include bounded, persistent, exportable live connection
  journals. Android journal export redacts MAC addresses, secrets and notification payloads.
