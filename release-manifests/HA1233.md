## Release boundary

Natro 2.2.0 remains frozen at Android version code `208021232`. These field corrections are a
new install-compatible release, 2.2.1 / `208021233`; they do not overwrite or relabel 2.2.0.
The package name, update certificate, API 28 support, saved preferences and Bluetooth enrollment
identity remain unchanged.

## Automatic iPhone reconnect

- Routine Route A recovery no longer waits indefinitely for one particular Classic HFP state.
- An exact selected-phone Classic transition is only a liveness hint to the sole existing GATT
  route. It is never accepted as identity or authorization evidence.
- A registered-client retry uses passive `autoConnect=true` on the exact saved public LE identity;
  the first active attempt remains `autoConnect=false`.
- A manual connection check leaves an already healthy ANCS session intact and nudges only a failed
  current route. Radio loss, stale epochs and owner replacement still fail closed.

## HWGPS trigger

The navigator trigger now follows the same direct state used by HWGPS' own Find-me availability.
DR is active only for `fix_dr`, `fix_sw_dr`, `fix_sw_dr_mm` and `fix_sw_yl_safe`. `notFixed`,
`fix_ok`, `filtered`, `spoofing`, missing or malformed state remain inactive. The former
route/Yandex heuristic is removed; the automation resource is `hwgps.dr_active`.
