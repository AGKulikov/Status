# Status Widget HA1126

## Information status editor

- Keeps `Отмена` and `Сохранить` in a fixed footer inside the detailed status editor.
- Limits the scrollable form height to the physical display, so the footer remains reachable on
  the landscape ECARX screen and on displays with larger font scaling.
- Preserves the HA1125 iPhone status sources, real-time notification ticker and all existing
  Information block settings.

## Upgrade compatibility

- Built directly on HA1125 and preserves package `ru.natro.statuswidget`.
- Uses version code `208021126` and must be signed with the stable HA update certificate, so it
  installs over HA1122–HA1125 without deleting settings.
