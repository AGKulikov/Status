# Status Widget HA1131

Version name: `v2.8.2-ha1131`
Version code: `208021131`
Package: `ru.natro.statuswidget`

## Stable saved-iPhone BLE/ANCS reconnect

- Daily reconnect now follows the verified HWGPS sequence:
  - scan only for the exact saved iPhone address;
  - use low-power, first-match and aggressive matching;
  - stop the scan on the first real advertisement;
  - then create one direct `connectGatt(false, TRANSPORT_LE)` instance.
- A GATT attempt remains alive for 35 seconds, matching the stable reference lifecycle instead of
  timing out after five seconds.
- A saved-peer scan is re-registered after 180 seconds without a match and continues until the
  phone advertises or the connector is intentionally stopped.
- Duplicate scans and duplicate GATT registrations for the same saved peer are rejected.
- Saved-peer scan failures enter the existing unlimited, capped controller retry path.
- The head unit does not advertise a second Bluetooth identity: HWGPS confirms that a separate
  BLE name/pairing is neither required nor used for this connection.

## Crash fix

- Removes the stale null `statusBarNotificationsEnabled` switch dereference from
  `PhoneConnectorSettingsActivity.persistSettings()`.
- Applying phone settings no longer crashes with the HA1130 `MaterialSwitch.isChecked()` NPE.

## Smooth launcher widgets and tiles

- Resize and move gestures follow the finger pixel-for-pixel. Optional grid snapping happens once
  on release instead of during every motion event.
- Composite widget text is drawn without changing the attached source view's text size. Resizing
  can no longer relayout the hidden source hierarchy or make text and editor handles jump.
- Text keeps its configured on-screen size while the frame provides more room; it grows only from
  the widget typography settings.
- Long text uses time-based, sub-pixel marquee drawing with no integer scroll or layout mutation.
- Static widgets redraw only when their actual visual signature changes. The former periodic
  invalidation/background mutation that made Settings and neighbouring tiles blink is removed.
- Automatic tile surfaces and hidden content padding are removed. Widget content starts at the
  frame edge; user padding remains explicit and defaults to zero.
- Existing layouts migrate to free aspect-ratio frames.

## Driver information rows

- Legacy implicit item padding and the four-pixel horizontal-group gap migrate to zero.
- Named horizontal rows no longer inherit the ordinary vertical panel gap.
- Group gap, margins, padding, alignment, distribution, background and corner radius remain
  independently adjustable and can all be set to zero.
- Device values reserve five wrapped status lines with real font leading. Overflow remains
  scrollable instead of being clipped inside its tile.

## All Apps removal

- Launcher and driver-panel All Apps surfaces are fully opaque.
- Long press keeps the same grid in edit mode and shows uninstall crosses only for removable apps.
- Confirmation is shown in the same overlay above the unchanged grid.
- On the head unit's existing privileged channel, a confirmed app is removed directly for user 0.
  If the channel is unavailable, Android's standard Package Installer confirmation is used.
- Cancel, success and fallback all restore input and reload the existing drawer without dismissing
  or recreating its edit session.

## Driver Favorites and climate

- A second tap on an already-open Driver Favorites icon closes that panel and suppresses an
  immediate automation-driven reopen until the condition resets.
- Automatic climate mode again shows the live five-segment scale.
- The automatic row contains only the word `AUTO`; fan/airflow pictograms remain absent.
- Monjaro fan artwork uses clean generated scale marks, without the small dots from the cropped
  source segment.

## Included HA1130 functionality

- Retains notification automations with independently conditioned app/topic/text fields, latest
  notification replacement, configurable popup overlays and status-row output.
- Retains time, passenger-presence, other-visible-automation and smart-home-state conditions.
- Retains unlimited HOME/HUD backdrops, HUD backdrops without shadows, overlapping HOME widgets,
  arbitrary climate-icon actions and all previous OEM/HUD controls.

## Upgrade compatibility

- Preserves package `ru.natro.statuswidget`.
- Uses version name `v2.8.2-ha1131` and version code `208021131`.
- Must be signed with the stable HA update certificate SHA-256
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`, so it installs directly
  over HA1125 and later builds without deleting settings.
