## Included changes

- Completed direct Apple Notification Center Service support for the one
  explicitly selected bonded iPhone. Device identity is checked at every
  Bluetooth/GATT boundary; another phone with the same display name cannot
  supply presence, notification, message or battery data.
- Added serialized GATT operations, MTU negotiation, bounded queues,
  connection timeouts, reconnect backoff, Service Changed handling and
  protection against late/duplicated callbacks.
- Added strict fragmented ANCS parsing and per-request sequence tokens,
  including the Data Source-before-write-callback and repeated-UID races.
- The default privacy mode requests only the source application identifier.
  Notification title/body are requested only for Apple Messages and only when
  the user explicitly enables message text.
- Kept Bluetooth MAP as a live fallback without displaying duplicates while
  ANCS is ready. Recent MAP state returns immediately if ANCS disconnects.
- Added selected-iPhone battery source arbitration, charge/network/presence
  values, live diagnostics, an ANCS retry action and selected SprutHub switch
  export.
- Added application-aware vector icons and dynamic notification/message state
  in the launcher Information panel. Phone scalar values migrate cleanly from
  the HA1080 source format.
