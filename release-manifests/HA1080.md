## Included changes

- Added the Phone connector with an explicit bonded-iPhone picker. The saved
  Bluetooth address is the sole identity: another phone with the same display
  name cannot supply presence, notifications, messages, battery or network
  data.
- Added battery, charging, operator, signal, roaming and network-type values
  from the selected iPhone where its Bluetooth profiles expose them.
- Added device-qualified MAP and exact-session ANCS notification/message
  mirroring without reading Android's shared SMS database.
- Added optional selected-iPhone presence export to one chosen writable boolean
  SprutHub accessory. Disconnect, connector disable and device replacement
  explicitly export OFF.
- Added visual grids and per-item icon sizing for buttons and smart-home
  panels, with editing both on HOME and in settings.
- Added four-corner resizing and synchronized visual configuration for the
  media panel and related panel-editing fixes.
