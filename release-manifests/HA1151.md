# Status Widget v2.8.2-ha1151

## Живой редактор уведомлений iPhone

- При открытии настроек варианта без иконки или с иконкой настоящий тестовый оверлей
  автоматически появляется поверх экрана.
- Приложение, тема и текст заполняются безопасными тестовыми значениями; они не записываются
  в ANCS, журнал уведомлений или сохранённое состояние автоматизаций.
- Плитки можно перетаскивать по сетке и растягивать за углы непосредственно на оверлее.
- В заполненной сетке перетаскивание одной равной плитки на другую меняет их местами.
- Тап по плитке открывает точные настройки; предпросмотр не мигает при переходе между экранами.
- Отдельная ручка перемещает окно целиком, а размеры окна по-прежнему доступны точными
  ползунками.

## Иконка приложения

- Добавлены цвет и прозрачность подложки, внутренний отступ, выравнивание и скругление краёв.
- Загруженное изображение теперь действительно обрезается по заданному радиусу, а не только
  получает скруглённый фон.
- Новый макет с иконкой получает iPhone-подобное скругление 22,37% стороны (16 px для 72 px).
- В живом предпросмотре используется квадратная тестовая иконка «Сообщения», поэтому изменение
  радиуса сразу видно.

## Совместимость

- Пакет: `ru.natro.statuswidget`.
- Версия: `v2.8.2-ha1151`, versionCode `208021151`.
