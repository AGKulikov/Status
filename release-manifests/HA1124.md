# Status Widget HA1124

## iPhone notifications

- Replaces the legacy ANCS GATT path with the verified saved-iPhone BLE transport while leaving
  stock ECARX Classic Bluetooth profiles responsible for calls, music and network data.
- Preserves the HA1122 iPhone battery fallback: BAS `0x180F` level/power reads and subscriptions
  are serialized with ANCS, while battery-only configurations retain the legacy exact-device
  GATT path.
- Starts the phone connector from the existing sticky `WidgetService`, including phone-only and
  post-boot operation without requiring the standalone iPhone Helper.
- Accepts only live ANCS Added/Modified events from the current ready session. iOS
  `EventFlagPreExisting` replay is discarded before any attribute request, and Removed events are
  applied only to notifications delivered during that same session.
- Maps App DisplayName to application, ANCS Title to topic and ANCS Message to text without
  subtitle or bundle-ID fallbacks.
- Adds bounded queues, a 15-second monotonic real-time TTL, one fresh re-read for notifications
  modified during an active request, serialized Control Point requests, pairing/CCCD watchdogs,
  Data Source resynchronization and delayed-name expiry to prevent stale bursts and UI stalls.

## Upgrade compatibility

- Built on the complete HA1122 source, retaining its HUD layer-stack correction and long-press
  application uninstall flow.
- Keeps package `ru.natro.statuswidget`; release artifacts must be signed by the stable HA update
  certificate and use version code `208021124`.
