# Status Widget HA1127

## Stable iPhone ANCS BLE lifecycle

- Uses the same direct saved-MAC connection pattern as Hardware GPS/GPSTether:
  `connectGatt(autoConnect=false, TRANSPORT_LE)`.
- Allows only one ANCS `BluetoothGatt` at a time and keeps the legacy battery-only GATT mutually
  exclusive with the ANCS transport.
- Applies a 5-second timeout to the daily saved-peer attempt.
- Closes and discards the old GATT after every timeout, error, or clean disconnect before the
  controller retries with bounded 2/5/10/20/30/60-second backoff.
- Keeps BLE scanning and head-unit advertising disabled during normal saved-peer operation.
  The iPhone Helper scan remains a one-time bootstrap/recovery path only.

## Upgrade compatibility

- Built directly on HA1126 and preserves package `ru.natro.statuswidget`.
- Uses version code `208021127` and the stable HA update certificate, so it installs over
  HA1122–HA1126 without deleting settings.
