# Status Widget HA1169

Date: 2026-08-05
Version name: `v2.8.2-ha1169`
Version code: `208021169`

## Fresh private GATT generation

- Companion Helper v17 and Status Widget HA1169 use D2D9 generation 2 (`...2F02`) together.
- This prevents Core Bluetooth from reusing generation-1 characteristic handles after B4 gained
  notification/CCCD support; Classic Bluetooth pairing and profiles are not changed.
- Helper accepts a complete current `CBService` cache first and otherwise discovers only missing
  B2/B3/B4 characteristics.
- A saved/restored peripheral stuck in `connecting` is abandoned after 15 seconds and resolved
  again from a fresh filtered advertisement.

## Background phone telemetry

- Android publishes B4 as READ/WRITE/NOTIFY with a real Client Characteristic Configuration
  descriptor and remembers subscription state per current GATT-server peer.
- Every five seconds while subscribed, the head unit sends a one-byte wake notification. It
  carries no phone data; the Core Bluetooth event wakes Helper, which samples current public iOS
  battery/power/data-network state and writes the authenticated eight-byte frame back.
- Wake polling stops immediately on unsubscribe, disconnect, route reset or GATT-server close.

## Notification icon radius

- The icon no longer relies on a nested overlay `saveLayer`, which the KX11 Android 9 compositor
  flattened after the whole-card real clipping was introduced.
- Its final `FIT_CENTER`/`CENTER_CROP` result is rendered into an independent ARGB bitmap and then
  copied through a round-rect bitmap shader. The compositor therefore receives genuinely
  transparent corner pixels in both the editor preview and the live notification.

## Climate shortcut physical centring

- The captionless live-climate canvas is laid out against the complete painted button rectangle.
- Rail spacing may still use asymmetric internal padding, but that padding can no longer shift
  the temperature/fan artwork away from the horizontal or vertical centre of the configured
  button.

## Multi-line notification text placement

- Every sender, time, application and message element stores an independent vertical placement
  for its visible text block: top or centre.
- The option is shown next to the maximum-line and overflow controls. It is applied to the actual
  bounded line viewport, so ellipsis and automatic scrolling keep the configured line limit.
- Layout schema 4 reads existing schema 2/3 values as centred and persists the new choice across
  editor reopen and style copy.

## Unchanged behavior

- Peripheral and Central remain mutually exclusive selectable routes.
- The original iPhone-Peripheral flow and the Central current-link PAIR/B3 proof are preserved.
- ANCS authorization and selected-phone isolation remain mandatory.
- Existing notification rendering, real icon alpha rounding and exact climate-button centering
  from HA1167 remain included.
