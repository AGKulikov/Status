## Release boundary

Natro 2.2.0 and 2.2.1 remain frozen at Android version codes `208021232` and `208021233`.
These panel interaction improvements are a new install-compatible release, 2.2.2 / `208021234`;
they do not overwrite or relabel an earlier release. The package name, update certificate, API 28
support, saved preferences, Bluetooth enrollment identity and paired Helper 53 remain unchanged.

## Information typography

- Information elements in each Driver Favorites panel expose independent label and value sizes.
- Label size is adjustable from 8 to 72 sp; value size is adjustable from 8 to 96 sp.
- The same direct controls are available in the main information-panel item editor.
- Existing stored sizes remain intact and continue to render through the shared information item.

## Per-panel inactivity timeout

- Every Driver Favorites panel owns an independent inactivity timeout from 5 to 600 seconds.
- The default and explicit zero value keep automatic closing disabled for existing installations.
- Opening a panel starts its timer. Touch, scrolling and holding pause or restart only that panel's
  timer, so a panel cannot close while the finger is still down.
- An elapsed timeout closes that panel and records the same manual-close state used by the existing
  overlay controller, preventing an automation condition from reopening it immediately.

## Long-press feedback

Every existing long-press handler in the launcher, Driver Panel, Driver Favorites and panel editors
requests Android's stock click sound as soon as the hold is recognized. Android's global touch-sound
setting remains authoritative, and detached views fail safely without changing the long-press action.
