# Status Widget HA1191 + iPhone Helper v29

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1191`

Version code: `208021191`

## Proven ANCS failure

- Helper accepted `ANCS-HANDOFF`, connected phase two with `RequiresANCS=true`, and Android then
  ran its old delayed GATT-server cancel. The cancel landed after the correct second link existed.
- Helper also displayed green from `didConnect` or B4 traffic even when neither ANCS CCCD had
  succeeded. Battery/network and notifications could therefore remain absent behind a false
  connected state.

## Deterministic two-phase fix

- Android no longer force-closes the bootstrap ATT owner; Core Bluetooth owns the planned release.
- Helper rediscovers the current dynamic B3 on phase two and writes `ANCS-READY`.
- Android begins the same-link ANCS client only after that encrypted explicit proof.
- After both Notification Source and Data Source CCCDs succeed, Android writes
  `ANCS-SUBSCRIBED` to the iPhone F05/B4 relay.
- Helper remains yellow for bare `didConnect`, B4 read, or B4 subscription and turns green only
  after `ANCS-SUBSCRIBED`.

## Type-correct limiter capture

- The KX11 properties `0x8207`, `0x820C`, `0x82B6`, `0x8377`, plus the adjacent speed-warning
  fields are byte-array aggregates, not integers.
- While ActionRecorder is active, HA1191 reads them through the vendor SDK's
  `getBytesProperty(propertyId, area=1)` path every 250 ms.
- Raw baselines and changed-byte indices are emitted as `ECARX_ADAS_BINARY_BASELINE` and
  `ECARX_ADAS_BINARY_CHANGE`. The path remains passive and read-only.

## Retest

1. Install HA1191 and Helper v29 as a matched pair; select **Central** in both.
2. Wait for green only after the Helper log records `ANCS-SUBSCRIBED`.
3. Send a new iPhone notification and verify it appears on Android.
4. Record a fresh limiter session while safely performing on/off, set-speed changes, resume, and
   cancel. Export the session and compare each action to the binary changed-byte events.

Classic Bluetooth profiles, names, pairing records, vehicle settings, and controls are not
modified by this release.
