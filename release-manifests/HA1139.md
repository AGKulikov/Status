# Status Widget HA1139

Version name: `v2.8.2-ha1139`

## Исправления

- Повторное нажатие на открывающуюся с панели водителя панель теперь закрывает её:
  отложенный `ACTION_OUTSIDE` больше не успевает удалить логическое состояние до обработки
  того же физического нажатия самой кнопкой.
- Убран редкий двойной щелчок штатного климата: один принятый accessibility-жест больше не
  дублируется shell-нажатием при позднем callback `onCancelled` от ECARX.
- «Все приложения», открытые с панели водителя, занимают только область приложения и не
  перекрывают саму панель. Повторное нажатие кнопки «Все приложения» закрывает окно.
- Wi‑Fi заменён на iPhone‑индикатор: зелёные дуги заполняются по текущему RSSI с обновлением
  каждые две секунды.
- Добавлены независимые элементы «Сотовая сеть iPhone» и «Батарея iPhone» для статусной строки,
  панели водителя и визуального редактора лаунчера. Уровни и заряд передаются из живого PHONE
  коннектора; батарея белая, при 20% — жёлтая, при 10% — красная.
- Bluetooth теперь закрашивается внутри только при живом ANCS-профиле и доступном потоке
  уведомлений. Старое уведомление больше не защёлкивает индикатор; обводка сделана тоньше.
- Максимальная ширина медиа теперь настраивается до полной физической ширины строки, а не до
  прежних 80% (1408 px на KX11).

## Совместимость

- Пакет: `ru.natro.statuswidget`.
- Версия: `versionCode=208021139`.
- Сборка предназначена для установки поверх HA1135–HA1138 со стандартной подписью проекта.
