# Status Widget v2.8.2-ha1203 + KX11 ANCS Helper v39

Status Widget usability release for the Geely Monjaro/KX11 Android 9 head unit. It is based on
the complete HA1202 BLE/ANCS transport and preserves Helper v39 unchanged.

## Climate level carousels

- Every configurable three-level heating or ventilation control exposes the complete manual
  sequence, including OFF: `0 → 1 → 2 → 3` or `3 → 2 → 1 → 0`.
- The same contract covers driver and passenger seat heating, driver and passenger seat
  ventilation, and steering-wheel heating.
- Level `0` maps to the real vehicle-specific OFF option and is saved in the command carousel,
  not added as a display-only placeholder. AUTO and unknown vendor values still converge safely
  to OFF before entering the selected manual sequence.

## Vector icon gallery

- All user-selectable icon surfaces use one visual preview gallery instead of a text-only list.
- The built-in vector catalog is expanded with automotive controls and a clean front-view vehicle
  glyph, while preserving all previously stored icon keys.
- Every new built-in glyph is an Android `VectorDrawable`; no bitmap icon is introduced.

## Passive launcher backdrops

- Decorative HOME backdrops are excluded from normal click and accessibility actions and do not
  consume an empty tap.
- Backdrops remain selectable, movable, resizable and editable only while launcher layout edit
  mode is active.

## Preserved installation and transport identity

- Android package remains `ru.natro.statuswidget`.
- Android version code is `208021203` and version name is `v2.8.2-ha1203`.
- Required signing certificate SHA-256 remains
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.
- APK Signature Scheme v2 and v3 remain required for an in-place Android 9 update.
- HA1202 F04/ANCS transport and Helper v39 state machines remain unchanged.

## Release gate

- Existing HA1197 through HA1202 transport contracts must remain green.
- HA1203 climate, icon-gallery and passive-backdrop contracts must pass.
- The complete unsigned `geelyRelease` APK must assemble in GitHub Actions, then be signed with
  the stable HA update key and verified for package, version, certificate, alignment and v2/v3.
