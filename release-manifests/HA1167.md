# Status Widget HA1167

Date: 2026-08-04
Version name: `v2.8.2-ha1167`
Version code: `208021167`

## Notification application icon

- Replaces the OEM-ignored child `clipPath` with a software `saveLayer` and `DST_IN` alpha mask.
- The configured radius now cuts the actual bitmap/vector pixels in both the editor and runtime
  overlay; no black backing rectangle or outline-provider approximation is involved.
- Saved grid geometry and aspect-ratio/crop settings remain independent from the radius.

## Driver climate button

- Adds an exact-centre host shared by the live driver rail and its settings preview.
- Every layout pass remeasures the climate canvas and calculates its top from the current physical
  button height, so changing `buttonHeightPx` cannot retain the previous Android 9 child position.
- Deliberately asymmetric internal padding is still respected.

## Reverse BLE current-link recovery

- Android 9 can report the shared device as Classic `BOND_BONDED` while its private LE ATT request
  is rejected with key-size error 12 before the application callback runs.
- B3/B4 now use application-level current-peer gating instead of framework encrypted permissions;
  their payload contains only D2D9 link control and phone status telemetry.
- The first B3 read on each new physical GATT-server connection returns ATT insufficient
  authentication once. This gives Core Bluetooth an explicit opportunity to restore/start LE
  security on that connection. A retry then confirms the same current peer and starts the
  same-peer ANCS client attach.
- The Apple ANCS service remains protected by its own authorization/security requirements.
- Classic pairing is never removed or modified.

## Companion Helper v15

- Keeps Peripheral/v11 as the default unchanged route.
- Treats the first status-5 B3 response as the expected current-link challenge and retries on the
  same connection.
- Bounds persistent authentication/key-size failures and reconnects from a fresh D2D9
  advertisement with 1/2/5/10/20/30-second backoff.
- Retains unfiltered current-service discovery and stale-handle invalidation from Helper v14.

## Verification gates

- Full Java unit and release-contract suite.
- `assembleGeelyDebug` Android release build.
- Helper v15 iOS simulator compilation without signing.
- Signed APK package/version/resource/zipalign/certificate verification against the established
  Status Widget signing identity.
