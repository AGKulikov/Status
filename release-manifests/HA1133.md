# Status Widget HA1133

Version name: `v2.8.2-ha1133`
Version code: `208021133`
Package: `ru.natro.statuswidget`

## Sprut.hub reconnect recovery

- A blank hub serial remains an automatic choice on every reconnect. The connector no longer
  writes a discovered serial back into settings and accidentally pins later sessions to a stale
  cloud-relay route.
- Accounts with exactly one online hub recover from an obsolete saved serial for the current
  session. Accounts with several online hubs are never guessed.
- Sprut.hub settings provide a one-tap action to clear an older saved serial and return to
  automatic hub selection.
- `server.clientInfo` uses current and compatibility payloads, but an unsupported advisory call no
  longer prevents the authoritative room and accessory snapshot.
- The official cloud never falls back to obsolete `account.login`, which it now rejects with
  `-666001 Token not provided`. Local/custom endpoints retain that compatibility path only when
  their initial modern auth probe is unavailable. Rejected email/password answers preserve their
  real error instead of starting a second login dialogue.
- The Sprut.hub, MQTT and direct Home Assistant connectors keep the shared foreground service
  alive even when the visible status row is disabled.

## Diagnostics

- The detailed journal records privacy-filtered Sprut.hub transport, JSON-RPC command, session and
  connection-state stages, including response times and WebSocket HTTP failures.
- Passwords, tokens, payload values and complete hub serials are not written to the journal.

## Upgrade compatibility

- Preserves package `ru.natro.statuswidget`.
- Uses version name `v2.8.2-ha1133` and version code `208021133`.
- Must be signed with the stable HA update certificate SHA-256
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`,
  so it installs over HA1132 without deleting settings.
