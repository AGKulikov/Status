# Status Widget HA1159

Package: `ru.natro.statuswidget`
Version name: `v2.8.2-ha1159`

## Battery correction

- The selected iPhone's Android `BATTERY_LEVEL_CHANGED` value and standard BLE Battery Service
  percentage are again the primary displayed sources.
- A current cached Android remote-device value is read at session start when KX11 permits the
  Android 9 SystemApi.
- The stepped public `UIDevice.batteryLevel` value from Helper v10 is availability fallback only
  and cannot roll a direct `96%` reading back to `95%`.
- Helper v10 remains authoritative for external-power/charging state and radio generation.
