# Status Widget HA1129

## All applications

- A long press opens an OEM-style edit mode with red minus badges only on removable user apps.
- The shared launcher and driver-panel drawers keep their own `Готово` action and dismiss their
  overlay before Android's standard uninstall confirmation, so the package installer cannot be
  blocked by an application overlay.
- System applications and Status Widget itself never receive an uninstall badge; the catalog is
  refreshed after a package is removed.

## Driver panel information

- Information tiles can be assigned to named horizontal rows; ungrouped tiles remain independent
  vertical rows.
- Every horizontal row has member and row ordering, top/bottom placement, equal/content widths,
  horizontal and vertical alignment, inter-item gap, four external margins, four internal
  paddings, background colour and corner radius.
- The live preview uses the same horizontal grouping model as the runtime overlay.
- Device status values reserve multiline height, information sections can scroll, and the settings
  screen keeps a safe scrollable bottom area so long values and final controls are not clipped.

## HOME widgets and backdrops

- Adding media and navigation elements can no longer fail merely because their internal grid is
  full; a new element may overlap and can then be moved freely.
- Atomic widget frames no longer draw automatic underlays. Source padding is removed so text can
  meet a frame edge, while explicit per-widget padding remains available.
- Resizing scales visual content but compensates text size. Text receives the larger frame area and
  changes size only through the widget's own text setting.
- HOME now supports any number of independent decorative backdrops. They are always below widgets,
  move and resize freely, and expose fill colour/opacity, corner radius, border and shadow controls.

## HUD widgets and backdrops

- HUD widget frames follow the same transparent-surface and fixed-text-size model as HOME.
- Text uses the complete frame without a hidden four-pixel inset, and tapping an element in the
  editor opens its settings directly.
- HUD supports any number of independent backdrops with fill colour/opacity, corner radius and
  border controls. HUD backdrops are always below widgets and intentionally have no shadow.
- The stock-content mask also replays the removed ECARX `AR mode` preference through the raw
  PA33873 profile message. It changes only protobuf field 111 (`vfhudbyte0`) in the original wire
  bytes, publishes the complete message through CB33264 and verifies read-back. It deliberately
  bypasses the public profile JSON adapter because that adapter omits 65 vendor fields.
- The profile preference can be changed while the custom HUD panel is disabled; publishing the
  panel and hiding/restoring the stock AR content remain independent controls.
- If the profile route is unavailable, the same AR value is attempted only four times through the
  generic car-function API; this path is bounded and never becomes a permanent command stream.

## Included HA1128 functionality

- Retains the HA1127 saved-iPhone BLE/ANCS lifecycle modelled after Hardware GPS, with one owned
  GATT client, exact saved address, deterministic close and unlimited bounded reconnect backoff.
- Retains the full phone telemetry audit, including BAS charging state/source, external power,
  estimated charging fallback, HFP/MAP/BLE/ANCS readiness and privacy-safe call/audio states.
- Retains all ANCS category/filter controls and the live driver climate artwork extracted from the
  supplied `MonjaroPanel_2.0.5.apk`, including its independent tap action and configurable gap.

## Upgrade compatibility

- Preserves package `ru.natro.statuswidget`.
- Uses version name `v2.8.2-ha1129` and version code `208021129`.
- Must be signed with the stable HA update certificate so it installs directly over HA1125 and
  later builds without deleting settings.
