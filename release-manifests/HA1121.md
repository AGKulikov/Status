# Status Widget HA1121

HA1121 is an in-place update over HA1120. The package name and stable signing identity remain
unchanged.

## HUD system-mask startup

- Fixes `ECONNREFUSED` while starting the direct SurfaceFlinger HUD mask.
- The `app_process` bridge now runs as a foreground command on its own persistent ADB/Telnet
  transport. Closing the short command channel can no longer kill the bridge before the
  application connects to its loopback socket.
- The dedicated bridge transport does not block regular privileged commands such as key events
  and permission grants.
- Bridge connection starts as soon as the privileged transport is open and tolerates the slower
  class loading observed on the ECARX head unit.
- Early `app_process` failures are returned in the HUD runtime status instead of being discarded
  through `/dev/null`.
- The normal HUD overlay remains active until the system mask acknowledges its first full frame.

## Compatibility

- Application ID: `ru.natro.statuswidget`
- Version name: `v2.8.2-ha1121`
- Version code: `208021121`
- Minimum Android version: API 28
