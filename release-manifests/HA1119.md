# Status Widget HA1119

HA1119 continues the in-place update line after HA1118. The package name and stable signing
identity remain unchanged.

## HOME widgets

- Every tagged HOME element is rendered as an independent screen-space widget.
- The default `FIT` mode preserves geometry and shows the complete source without distortion.
- Optional `CROP` and explicit legacy `STRETCH` modes are available per widget.
- Aspect-ratio locking is enabled by default and can be disabled for an individual widget.
- A long press opens deep settings for text size, font, bold/italic style, text/icon colors,
  horizontal and vertical alignment, four independent content paddings, background, rounding and
  tap behavior.
- Any widget can retain its original action, become informational, or open a selected application.
- Favorite applications are exposed as separate widgets rather than one inseparable grid.
- The edit screen includes a widget catalog for adding actions, apps, clock/date, media,
  information, navigation, climate and vehicle data.
- Media artwork uses complete-image fitting by default, so resizing no longer crops the cover.

## Driver panel

- Driver Favorites dismiss on a tap outside their compact overlay.
- The Favorites edge touching the driver rail is square and gapless; only the free outer edge is
  rounded.
- Per-icon “close after tap” behavior is preserved.
- Informational buttons now expose label/value sizes, font, bold/italic style, horizontal and
  vertical alignment, and left/top/right/bottom padding.
- Informational tile height follows the configured typography and padding instead of clipping it
  to the old fixed 64 dp slot.

## Climate indicator

- The driver climate tile always follows the stable order: temperature, fan scale, airflow mode.
- Airflow modes use a new resolution-independent seated-person automotive pictogram.
- The AUTO badge is restored without changing the tile or scale envelope.
- Five AUTO divisions use compact contiguous gaps and wider segments; the outer scale geometry no
  longer jumps when switching between manual and AUTO.
