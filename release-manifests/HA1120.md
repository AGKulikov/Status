# Status Widget HA1120

HA1120 is an in-place update over HA1119. The package name and stable signing identity remain
unchanged.

## System HUD mask

- Fixes the permanent ECARX car and speed graphics remaining visible above the custom HUD panel.
- The supplied SurfaceFlinger dump confirms those pixels come from
  `ecarx_daemon_OverlayDisplay`, an unparented hardware-compositor layer above all regular Android
  application and Presentation windows.
- When the existing local ADB/Telnet channel is available, the app now starts a short-lived
  `app_process` bridge under the shell identity and creates a 728x190 SurfaceControl directly on
  the verified HUD layer stack.
- Complete custom HUD frames, including the opaque black mask when enabled, are sent over a
  nonce-protected loopback connection and placed above the ECARX daemon layer.
- The direct surface is hard-clipped by its physical buffer to `[0,720]-[728,910]`, so it cannot
  draw onto another display region.
- The original WindowManager overlay remains visible until the first direct frame is acknowledged.
  If shell access or SurfaceFlinger creation fails, the app automatically keeps/restores the
  previous overlay and reports the reason in HUD runtime status.
- No ECARX package is disabled, force-stopped, or modified. Closing the HUD service, losing the app
  process, or missing its heartbeat destroys the direct surface automatically.

## Compatibility

- Application ID: `ru.natro.statuswidget`
- Version name: `v2.8.2-ha1120`
- Version code: `208021120`
- Minimum Android version: API 28
- The build remains signed with the stable HA update key so it installs over HA1119.
