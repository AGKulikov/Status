# Status Widget HA1136

Version name: `v2.8.2-ha1136`
Version code: `208021136`
Package: `ru.natro.statuswidget`

## Исправления

- Восстановлен вход в Sprut.hub при облачной ошибке разбора результата
  `account.answer [-32602]`. Официальный challenge-ответ остаётся основным; узкий
  совместимый повтор выполняется только для подтверждённой ошибки parser/result и не
  срабатывает при неверном пароле.
- Повторное нажатие на ту же кнопку «Избранного» в панели водителя теперь закрывает
  уже открытое окно. Двойная доставка одного физического нажатия подавляется.
- Исправлено сохранение двух макетов всплывающего уведомления телефона: одинаковые
  живые поля разрешены в разных overlay, но по-прежнему уникальны внутри одного.
- Информационные плитки панели водителя получают реальную высоту строки и больше не
  оставляют пустое место со сдвинутыми вниз кнопками.
- Bluetooth отображается одним чистым векторным знаком: синий контур означает
  подключённый выбранный телефон, сплошной синий знак появляется только после
  фактической доставки ANCS-уведомления в текущей сессии.
- Полоса медиапрогресса измеряется по исходному отображаемому названию композиции,
  ограничивается его viewport и не учитывает длительность, контейнер строки или
  служебную копию marquee.

## Доработки из HA1135

- Иконка климата панели водителя принудительно переходит в состояние «выкл.» при
  `LOCK/OFF` зажигания и повторно подписывается на климат после включения.
- Технические рамки элементов лаунчера очищаются и после повторного присоединения
  MaterialCardView.
- При обрыве защищённого BLE/ANCS handshake пересоздаётся GATT advertiser без удаления
  штатного Classic Bluetooth pairing.
- Первое уведомление нового iPhone-приложения немедленно добавляет приложение в
  постоянный справочник и запускает загрузку иконки. При следующем уведомлении
  используется отдельно настраиваемый макет с иконкой.
- Векторные иконки берутся из Simple Icons; для неизвестных приложений предусмотрен
  fallback Apple artwork. После выдачи разрешения каталог хранится в
  `/sdcard/StatusWidget/ANCS-icons`, вне каталога приложения.
- Накопленный справочник приложений используется в настройке фильтра скрываемых
  уведомлений.
- Добавлена настройка настоящей Android SystemUI через `policy_control`, чтобы убрать
  системные часы и Bluetooth во всех приложениях без рисования маски.
