# Status Widget HA1166

Date: 2026-08-04
Version name: `v2.8.2-ha1166`

## Notification icon geometry

- The application-icon corner-radius slider now clips the real bitmap/vector draw path.
- The implementation no longer relies on a transparent `ViewOutlineProvider`, which was ignored
  by the KX11 Android 9 compositor.
- Every layout pass reapplies the saved icon cell directly to the child view, preventing Android 9
  from retaining its temporary centred/MATCH_PARENT position after the editor is reopened.
- Card children and the blue editor frames use the same fractional 48×12 grid coordinates.
- Aspect-ratio and crop settings remain independent from the configured radius.

## Driver climate button

- A live climate canvas without a caption is attached directly to the physical button with
  `Gravity.CENTER`.
- Changing `buttonHeightPx` no longer leaves the climate view at its previous measured top.
- Captioned climate buttons and all other shortcut layouts remain unchanged.

## Reverse BLE role

- A saved iOS resolvable private address is diagnostic state only; HA1166 does not pre-claim it as
  the verified peer of a new `Geely_ANCS` GATT-server generation.
- The actual incoming callback is claimed by its current `PAIR` write and is persisted only after
  encrypted `SECURE ATT OK`.
- This removes the repeating Android status-8 response seen as `Authorization is insufficient`
  in Helper v13.

## Companion Helper v14

- Keeps the v11 `iPhone Peripheral` route unchanged and selected by default.
- Discovers the complete D2D9 characteristic table without a UUID filter.
- Rejects characteristic callbacks from an older `CBService` object.
- Logs Core Bluetooth error domain/code and backs repeated failures off at
  1/2/5/10/20/30 seconds.

## Verification gates

- Full Java unit/contract test suite.
- `assembleGeelyDebug` release build.
- APK certificate comparison against the previous compatible signed release.
- APK version/package/manifest inspection after signing.
