# Status Widget HA1130

Version name: `v2.8.2-ha1130`  
Version code: `208021130`  
Package: `ru.natro.statuswidget`

## OEM HUD controls moved into the primary app

- Adds the four ECARX ProfileTransfer modes carried by CB33278:
  - `0` Guide
  - `1` Drive
  - `2` AR
  - `3` Simple
- Adds an explicit opt-in fallback which repeats only the selected mode after:
  - boot/package replacement;
  - active profile or PEN changes;
  - HUD/ADAS state transitions;
  - the observed reset when crossing 20 km/h.
- The fallback is rate-limited to five writes per minute, has a minimum four-second gap and a
  failure circuit breaker.
- The fallback never sends a visual-function mask, an all-zero vector, raw `-1`, profile save
  signal 29892, or the undocumented ProfileTransfer reboot command.
- Adds independent ECARX Settings controls for:
  - Drive Environment;
  - Safety;
  - Media;
  - Navigation;
  - Phone.
- Generic section writes report the real ECARX acceptance/read-back result instead of pretending
  an unsupported firmware setting succeeded.

## Existing safe AR path retained

- The central stock car/road AR flag still uses a complete PA33873 profile snapshot and patches
  only field 111 before CB33264.
- No unrelated profile fields are rebuilt or cleared.

## Upgrade identity

- Uses the historical application ID and the stable HA update certificate so the APK installs
  over HA1084 and HA1129 without uninstalling.
