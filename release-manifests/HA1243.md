## Android / head unit

- An enrolled Route-A cold start begins an unfiltered exact-identity presence scan after the
  first 12-second direct-connect watchdog instead of waiting through the 30/60/120-second ladder.
- A silent retained GATT owner receives one bounded 15-second same-wrapper reassertion and is then
  safely drained into a fresh exact epoch; recovery no longer depends on a Classic edge.
- The non-enrolled selected-bond route keeps its conservative 180-second retained-owner policy.
- Journal export always writes `Natro-ANCS-*.log` to the head unit's Download directory (or the
  application Documents fallback), copies the path, and only opens Share when a handler exists.

## Helper 61

- High-rate valid-C5 and HELLO diagnostics are summarized instead of producing one journal entry
  per catalog frame.
- Dashboard and Live Activity delivery is triggered by actual C5 state changes, command results,
  and complete sync boundaries; catalog streaming alone no longer floods ActivityKit updates.
- Bundle ID, App Group, restoration identifiers, C5 protocol and control catalog remain stable.

## Physical acceptance

- Cold start after more than 20 minutes away from the car must reach routine HELLO without tapping
  “Проверить подключение”; the expected bounded recovery window is approximately one minute.
- Confirm automatic reconnect after Bluetooth off/on and verify the saved log path directly on the
  ECARX file system when no share application is installed.
