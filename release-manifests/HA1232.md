## Product change

Helper is now a vehicle-control application rather than a Bluetooth diagnostic screen. Its main
surface has Climate, Seats, Media and Comfort tabs; reusable one-tap scenarios live in Comfort.
The previous route, enrollment, binding-reset and reconnect controls are retained under Settings.

All everyday commands use the already authenticated Natro Bluetooth owner. There is no Passenger
Wi-Fi server, LAN discovery, QR code or second PIN. The existing one-time C4 ECDH/SAS enrollment
remains only in Settings: removing it would turn Bluetooth address/name proximity into authority,
which is not an acceptable vehicle-control boundary.

## Bluetooth control contract

- C5 `D2D9E4C5-47F1-4E44-A8BB-A932FD5AF200` is a separate encryption-required characteristic;
  occupied C2 role switching and ANCS recovery remain unchanged.
- Route A uses Helper indication + Android write-with-response. Diagnostic Route B uses Helper
  write-with-response + Android indication. Both routes serialize C5 with their existing ATT owner.
- Only the exact authenticated CONTROL owner in the ACTIVE generation may subscribe, send or
  receive C5. Freeze, disconnect, route replacement and radio loss clear every pending frame.
- Each frame is exactly 20 bytes with version, finite control ID, transaction, monotonic sequence,
  maximum age and CRC-16/CCITT-FALSE. ECARX enum values remain exact signed `Int32`; temperature
  and percentage controls use an explicit scale of 100.
- The wire accepts only 39 reviewed registry entries. It cannot carry an arbitrary ECARX function
  ID or zone. Unknown IDs, kinds, flags, stale/replayed commands and malformed checksums fail closed.
- Android accepts at most 12 commands per second. Trunk and wiper-service commands require an
  explicit local safety confirmation in Helper and then pass through Natro's existing capability,
  read-back and vehicle-state checks.

## Available controls

- Climate: power, A/C, AUTO, both windshield modes, rear defrost, SYNC, circulation, front/rear
  fan, airflow, four temperatures, rear climate AUTO/power and rear-panel lock.
- Seats: driver/passenger heat and ventilation plus steering-wheel heat, including supported AUTO
  values without rounding the ECARX enum bits.
- Media: play/pause, previous/next, mute and current Android media volume.
- Comfort: drive mode, Auto Hold, Start/Stop, fuel save, trunk, wiper service, ambient-light power
  and brightness, passenger-screen power and day/night brightness.
- Scenarios: fast cool-down, winter morning, comfortable trip and all-off. A scene skips controls
  that the current vehicle catalog marks unavailable.

Windows, sunroof motion, massage movement/programs, fragrance and undocumented lamp writes from
the Passenger reference APK are intentionally not exposed in this release. Their raw IDs alone do
not prove a safe write domain, obstruction handling or a trustworthy read-back contract.

## Mandatory physical KX11/iPhone acceptance

1. Install Natro 2.2.0 over 2.1.4 and Helper 53 over Helper 52 without clearing either app. Confirm
   preferences, Classic pairing and the existing C4 binding survive.
2. Verify Route A reconnect, background restoration, lock/unlock, Bluetooth off/on, ACC cycle and
   20 exact reconnects. There must still be one logical phone and one GATT owner.
3. Exercise every visible control on a stationary vehicle while comparing Helper state, vehicle UI
   and read-back. Unsupported entries must remain disabled and no raw fallback may be attempted.
4. Verify scene ordering and rate limits, command expiry, replay rejection and recovery after both
   apps are killed between command and result.
5. Test trunk and wiper-service confirmation with every available safety condition. Cancel must
   produce no write; rejected vehicle state must remain rejected.
6. Confirm ANCS notifications, battery/network telemetry and media controls continue working while
   C5 is busy. C5 must not open a second GATT client or cause a reconnect storm.

Portable and hosted builds are release gates, not evidence that this physical matrix has already
passed. Do not call HA1232 physically stable until the matrix is recorded on the target KX11.
