# Status Widget HA1187 + iPhone Helper v26

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1187`

Version code: `208021187`

## Two-phase iPhone Central / ANCS handoff

- Helper v26 first opens a plain BLE connection (`RequiresANCS=false`) and performs the private
  F04 `PAIR` plus encrypted B3 current-link proof there.
- After Android accepts encrypted `ANCS-HANDOFF`, Helper intentionally closes only that bootstrap
  connection and reconnects to the same Core Bluetooth peripheral with `RequiresANCS=true`.
- No F04 service or characteristic discovery runs on the second connection. Android matches the
  bonded incoming callback and immediately attaches its ANCS GATT client.
- Android preserves the verified peer between the two links for at most 25 seconds. A foreign or
  unresolved callback cannot replace it; timeout recovery republishes the managed route.
- Pre-PAIR LE bonding has one successful owner per Android session. A rejected anonymous-device
  attempt is released so the later resolved LE peer can make the single real attempt.
- Helper's iPhone-owned F05/B4 read or subscription remains the final proof of a working ANCS
  owner and live battery/power/network telemetry.

## Expanded passive limiter capture

- While Action Recorder is active, the ECARX fallback subscribes to every runtime
  `PropertyIdString` entry whose generated zero-argument getter declares an integer-compatible
  payload, in addition to the fixed and name-selected limiter/cruise catalog.
- Runtime-discovered entries are callback-only. The health reader still polls only the fixed
  confirmed catalog, preventing the repeated `Integer` versus `byte[]` vendor exceptions seen in
  the supplied HA1186 log.
- Limiter discovery names additionally cover limiter, cruise, set-speed, speed-control, resume
  and cancel variants.
- All vehicle capture remains read-only; no ECARX setter or property write is enabled.

## Retest

1. Install HA1187 and Helper v26 as a matched pair. In both apps select **iPhone Central**.
2. Keep the existing Classic Bluetooth pairing. Open Helper once and do not force-quit it.
3. Confirm the Helper log reaches `RequiresANCS phase connected` and then a B4 read/subscription;
   confirm Android reaches `REQUIRES_ANCS LINK MATCHED` and ANCS discovery.
4. Start a fresh Action Recorder session with ignition on and operate only the speed limiter:
   enable it, change the selected speed several times, then disable it.
5. Export the journal. Relevant events are `ECARX_ADAS_CAPTURE_READY`,
   `ECARX_ADAS_BASELINE` and `ECARX_ADAS_SIGNAL_CHANGE`; the changed property ID and vendor name
   identify the limiter controls on this firmware.

These changes improve observation and transport setup only. They do not inject steering keys,
touches, ANCS notifications or vehicle-control writes.
