# Status Widget HA1163

Package: `ru.natro.statuswidget`
Version name: `v2.8.2-ha1163`
Version code: `208021163`

## Independent phone-settings and journal scrolling

- The live phone connection journal is now a nested-scrolling viewport on Android 9 instead of a
  plain `ScrollView` embedded in the settings page.
- A drag inside the journal scrolls the journal in both directions. At its top or bottom edge the
  gesture is handed back to the outer connector-settings page.
- The 500 ms diagnostics refresh no longer calls focus-moving `fullScroll(FOCUS_DOWN)`, so opening
  or reading the upper connector controls cannot be interrupted by the page jumping to the log.
- Unchanged journal text is not assigned again, avoiding unnecessary layout and selection work.

## Fixed-height Back button no longer shifts Home

- A fixed button height no longer converts untouched automatic top/bottom spacing into explicit
  zero spacing.
- Reducing the Back button therefore leaves the automatic Home button vertically centred: its
  untouched top and bottom insets remain equal and continue to share the available rail height.
- A top or bottom inset that the user explicitly sets to `0` remains a true zero and still owns
  the adjacent boundary, so the existing no-gap configuration is unchanged.

## Preserved behavior

- The selectable `Peripheral / Central` BLE roles introduced in HA1162 are unchanged.
- Phone settings, paired-device identity, ANCS state and application data remain compatible with
  the existing `ru.natro.statuswidget` installation.

## Update signature gate

The installable APK must be release-signed by alias `status-widget-ha` with signer certificate
SHA-256 `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`, matching HA1155+.
