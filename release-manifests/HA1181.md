# Status Widget HA1181 + iPhone Helper v24

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1181`

Version code: `208021181`

## Исправления интерфейса

- Полоса позиции песни принимает весь жест `DOWN/MOVE/UP` и передаёт ограниченные по частоте
  промежуточные seek-команды; при отпускании всегда отправляется точная конечная позиция.
- Поиск MediaSession включает активный контроллер, NotificationListener и совпадение с реально
  отображаемым приложением/треком.
- Щелчки штатных кнопок панели водителя восстановлены. Открытие климата использует прямой Binder
  `openHvacMain`, без имитации касания.

## Телефон

- Запускается только штатный процесс `com.ecarx.btphone`, без запуска штатного HOME.
- Очередь уведомлений меняет промежуточные карточки раз в секунду, а последняя карточка получает
  полную настроенную длительность показа.
- Опция «только когда телефон заблокирован» принимает уведомление исключительно при свежем
  `device.locked=true`; неизвестное состояние или разрыв канала ничего не показывает.

## Sprut.hub

- Облачный password-proof принимает актуальный challenge `beta.spruthub.ru` без необязательного
  поля `info`: для HKDF используется допустимый пустой контекст. Salt, challenge и параметры
  Argon2id остаются обязательными и проходят прежнюю строгую проверку.
- Пароль, токен и содержимое challenge в диагностический журнал не записываются.

## Регистратор KX11

- Во время записи подключается read-only каталог из 11 подтверждённых ECARX-сигналов руля,
  G-Pilot, адаптивного круиза и ограничителя скорости. Запись в ECARX/CAN не выполняется.
- Служба спецвозможностей фиксирует фактическое появление штатного окна `ecarx.hvac.app` и его
  display ID.
- После однократных прав `READ_LOGS` и `DUMP` регистратор автономно ведёт ограниченный
  фильтрованный системный след и снимки состояния на старте/метках.
- Пассивный root `getevent` выключен по умолчанию и, если включён вручную при уже доступном `su`,
  сохраняет только `EV_KEY`, никогда не координаты касаний.

## Однократная настройка

- macOS/Linux: `tools/grant-ha1181-diagnostics.command`.
- Windows: `tools/grant-ha1181-diagnostics.bat`.
- Те же команды доступны в приложении: «Отладка и регистратор действий» → «Выдать через
  встроенный ADB» либо «Копировать команды».
- Права переживают перезагрузку и обновление APK с прежней подписью; удаление приложения их
  сбрасывает.

## iPhone Helper v24

- D2D9-сервис запрашивается адресно по UUID, поэтому Core Bluetooth больше не теряет его после
  успешного filtered scan. B2/B3 по-прежнему ищутся одним отложенным нефильтрованным запросом,
  чтобы не возвращать `CBError.uuidNotAllowed`.
- Повтор discovery ограничен на текущем ATT link; перед разрушительным reset выполняется
  rediscovery текущего сервиса.
- B4 unsubscribe больше не отменяет уже доказанный ANCS owner.
- Блокировка iPhone остаётся флагом `0x20` восьмибайтового B4 кадра.
