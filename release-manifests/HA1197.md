# Status Widget v2.8.2-ha1197 + KX11 ANCS Helper v34

Matched release for the Geely Monjaro/KX11 Android 9 head unit and iPhone.

## Trunk control correction

- The user-supplied working `Багажник.apk` was decoded instruction by instruction.
- Its `m.tg.MainActivity` calls the stock zoned AdaptAPI function with
  `function=0x21020100`, `zone=0x20000000`, and values `0=closed`, `1=open`.
- HA1178–HA1196 used the transposed ID `0x02210100`, so the capability probe and command were
  routed to the wrong vehicle function.
- HA1197 uses the exact reference ID and retains confirmation before opening, immediate closing,
  live readback, and the existing fail-closed behavior when ECARX is unavailable.

## Bounded iPhone reconnect

- The supplied Helper log shows an ordinary disconnect at 11:02:55 followed by a retained owner
  stuck in `.connecting` until the manual reconnect button was pressed at 11:06:22.
- Helper v34 adds a 15-second watchdog for that exact state.
- On timeout it cancels only the pending RequiresANCS owner, invalidates the stale dynamic
  namespace, and waits for a fresh D2D9 advertisement before reconnecting.
- No second `CBCentralManager.connect` can overlap the cancelled owner. ANCS authorization,
  single-owner PAIR/B3/ANCS-READY, Android CCCDs, and B4 telemetry proofs remain unchanged.
