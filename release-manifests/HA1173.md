# Status Widget HA1173

Package: `ru.natro.statuswidget`
Version name: `v2.8.2-ha1173`
Version code: `208021173`
Minimum Android: 9 (API 28)

## Notification rendering regression fixed

- Restores the configured notification-card colour, opacity and border. The Android 9 overlay
  now receives a real drawable that paints the Apple-continuous fill and stroke directly.
- Removes the mutable whole-card bitmap shader that the KX11 compositor dropped in HA1172.
- Bakes the Apple-continuous application-icon mask into actual transparent bitmap pixels on a
  software canvas before the icon reaches the hardware overlay compositor.
- Keeps the existing notification layout, style settings and preference keys unchanged.

## Release verification

- Source contract tests reject a missing real background, shader-based card compositing and an
  unbaked icon mask.
- Release APK is built in GitHub Actions, then signed with the existing HA update certificate and
  verified for package, version, alignment, payload integrity and signer identity.
