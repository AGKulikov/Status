# Status Widget HA1164

Package: `ru.natro.statuswidget`
Version name: `v2.8.2-ha1164`
Version code: `208021164`

## BLE role recovery

- The original iPhone Peripheral route always starts from the explicitly selected Classic/bond
  identity again. A private LE identity learned by the reverse route can no longer redirect it.
- The reverse iPhone Central route registers Android's GATT-client role directly
  (`autoConnect=false`) after encrypted SECURE succeeds on the existing incoming link.
- A failed same-peer client registration closes only that Android GATT-client owner. The active
  GATT server, `Geely_ANCS` service and incoming iPhone link remain intact and are retried in a
  bounded sequence.
- The GATT server is republished only after its own verified incoming link is actually lost; a
  client discovery/status failure no longer produces false Service Changed invalidations.

## Helper v13

- A missing or invalidated D2D9 service and invalid ATT handles now cause one genuine disconnect,
  cache invalidation and a wait for a fresh `Geely_ANCS` advertisement.
- If encryption is not restored after a previously successful SECURE session, protected reads
  are bounded and the BLE session is reset instead of retrying stale handles for 90 seconds.
- Peripheral mode remains the v11 route and Classic Bluetooth is never renamed, disconnected,
  re-paired or otherwise controlled by either role.

## Preserved HA1163 fixes

- Phone settings and the nested connection journal remain independently scrollable.
- A fixed Back-button height does not move an automatically centred Home button.
