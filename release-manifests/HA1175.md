# Status Widget HA1175 + iPhone Helper v18

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1175`

Version code: `208021175`

## Exact notification icon circle

- The application icon is rendered inside a centred square independently of its editable grid
  rectangle.
- Source proportions are preserved; the bitmap is never stretched independently by width and
  height.
- Intermediate values retain the Apple-continuous silhouette.
- Slider value 120 is an exact circular alpha mask (`Path.addOval` on square bounds), so it cannot
  turn into the exponent-five "barrel" shape.
- The finished transparent bitmap remains the only drawable published to Android 9's ImageView.

## Reverse-route ANCS recovery

- Android preserves its same-peer ANCS GATT client when Android 9 releases the diagnostic
  GATT-server callback during the expected server-to-client handoff.
- Client discovery, subscription and its existing bounded timeout now own that transition; the
  server callback can no longer close a successfully connected ANCS client and restart the route.
- Helper v18 removes Core Bluetooth system auto-reconnect and requires a fresh filtered D2D9
  advertisement after every connection failure or disconnect.
- D2D9 generation 2 (`...2F02`), the selected Classic pairing and bundle/package identifiers are
  unchanged.
