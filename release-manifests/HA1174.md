# Status Widget HA1174

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1174`

Version code: `208021174`

## KX11 notification application icon

- Removes HA1173's mutable bitmap mask from `ImageView.onDraw()`.
- Rasterises the source drawable at the icon's final persisted grid size.
- Applies the Apple continuous mask by multiplying every source alpha byte in software.
- Publishes only the completed transparent-corner bitmap through `ImageView.setImageBitmap()`.
- Never installs the original square drawable into the visible ImageView.
- Preserves the existing icon radius and aspect-ratio settings.

The notification card background and border remain the direct drawable introduced in HA1173.
