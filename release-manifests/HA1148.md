# Status Widget HA1148

Version name: `v2.8.2-ha1148`
Version code: `208021148`
Package: `ru.natro.statuswidget`

## Исправление установки

- APK всегда собирается после полного `clean`, поэтому в пакет гарантированно входят
  `resources.arsc` и все ресурсы интерфейса. Ошибочный локальный HA1147 содержал dex-код и
  манифест, но не содержал таблицу ресурсов; Android 9 закономерно отклонял такой пакет.
- Release-проверка теперь аварийно останавливается, если отсутствует `resources.arsc`, в APK
  меньше ожидаемого количества `res/`-файлов либо `aapt` не может разобрать ресурсы и манифест.
- Проверяются пакет `ru.natro.statuswidget`, возрастающий `versionCode`, Android 9 / API 28,
  выравнивание APK и стабильный сертификат обновлений SHA-256
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.

## Сохранённая функциональность

- Включены все изменения HA1146 по стабильному жизненному циклу ANCS и переподключению.
- Включены изменения HA1147 по прямому чтению состояния внешнего питания iPhone через GATT,
  без расчёта зарядки по изменению процентов.
