# Status Widget HA1165

Package: `ru.natro.statuswidget`
Version name: `v2.8.2-ha1165`
Version code: `208021165`

## Phone notification editor

- The notification card now owns the only visible surface in its translucent overlay window.
  Its rounded path clips the complete child tree, so transparent corners are real and no opaque
  black parent rectangle can imitate the radius.
- Optional border width and colour are rendered by the same rounded drawable.
- Hidden fields disappear from both the card and the draggable grid in the upper editor.
- Every configurable text field stores its maximum visible line count and chooses either an end
  ellipsis or bounded automatic scrolling for overflow. The preview deliberately uses long text.
- The application icon stores and reapplies its aspect-ratio mode on every render.
- The no-icon layout can copy visual style and typography from the icon layout without replacing
  its independent geometry or making the avatar/icon visible.
- Horizontal and vertical screen centring are independent persistent window settings.
- Position persistence writes X/Y before the stale-editor catalogue guard, preventing reopened
  settings from restoring an earlier geometry.

## Driver climate button

- The internal climate content now fills the exact configured button rectangle and uses the
  content container's centre gravity. Changing button height therefore keeps temperature, fan
  scale and AUTO centred when top and bottom padding remain in automatic mode.
- Explicit asymmetric top or bottom padding still shifts the centred content predictably.

## Preserved fixes

- HA1164 selectable iPhone Peripheral/Central roles, isolated BLE identities and stale-handle
  recovery remain unchanged.
- Classic Bluetooth pairing, names and profiles are never modified by BLE recovery.
