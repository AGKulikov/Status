# Status Widget v2.8.2-ha1204 + KX11 ANCS Helper v39

Visual-quality and driver-panel compatibility release for the Geely Monjaro/KX11 Android 9
head unit. It is based on HA1203 and preserves the HA1202 BLE/ANCS transport and Helper v39.

## Live climate presentation

- The live climate icon is again a presentation choice for every interactive driver-panel
  button; it is not tied to the button action.
- Changing an application, built-in action, vehicle command or rule preserves the user's live
  climate choice. Selecting the stock climate action may enable it by default but is not required.
- A live tile remains the sole dynamic presentation; CAR and RULE buttons do not leave a stale
  state-label placeholder underneath it.

## Modern vector icon pack

- The automotive gallery uses Google Material Symbols Rounded as its primary coherent vector
  family, with a small number of function-specific Pictogrammers Material Design Icons where the
  Google set has no equivalent automotive symbol.
- Stable icon keys and resource names remain unchanged, so existing launcher and driver-panel
  layouts keep their selected icons after the update.
- All imported symbols remain local Android `VectorDrawable` resources. No bitmap, font,
  file, URI or network icon source is introduced.
- Third-party sources, versions, original glyph names and Apache-2.0 license texts are recorded
  under `third_party/`.
- The existing dedicated open/closed trunk pair remains semantically explicit instead of being
  replaced by an unrelated building-door symbol.

## Preserved HA1203 behavior

- Climate controls retain the complete `0 → 1 → 2 → 3` and `3 → 2 → 1 → 0` carousels,
  including steering-wheel heating.
- Every configurable icon surface retains the visual preview grid.
- Decorative launcher backdrops remain touch-through outside layout edit mode.

## Installation identity

- Android package remains `ru.natro.statuswidget`.
- Android version code is `208021204` and version name is `v2.8.2-ha1204`.
- Required signing certificate SHA-256 remains
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.
- APK Signature Scheme v2 and v3 remain required for an in-place Android 9 update.
- Helper remains v39; no iOS or BLE transport source is changed in this release.

## Release gate

- Existing HA1197 through HA1203 transport and behavior contracts must remain green.
- HA1204 live-climate independence, icon provenance, vector-resource and catalog-stability
  contracts must pass.
- The complete unsigned `geelyRelease` APK must assemble in GitHub Actions, then be signed with
  the stable HA update key and verified for package, version, certificate, alignment and v2/v3.
