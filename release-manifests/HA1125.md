# Status Widget HA1125

## iPhone statuses and status row

- Adds a configurable `iPhone statuses` brick backed by the existing exact-device PHONE
  connector. Connection, battery, charging, cellular availability/operator/type/signal/roaming,
  notification/message counters and connector diagnostics can be selected independently.
- Adds a static PHONE catalog to the Information source picker, so phone values can be configured
  while the iPhone is disconnected. The latest notification is exposed as three independent
  fields: application, topic and text; existing `app_name` bindings remain compatible.
- Optionally shows each new real-time ANCS notification in the status row by temporarily reusing
  the Now Playing rows. Application/topic/text fields and a 1–120 second display duration are
  configurable. Media playback and MediaSession tracking continue, and the current track is
  restored when the timer expires.
- Does not replay archived iPhone notifications: the HA1124 `PreExisting` filter and current-session
  ANCS cache remain the only source for the temporary notification presentation.
- Keeps one BLE/GATT owner inside `WidgetService`; the status brick and notification renderer are
  read-only projections of the existing connector registry.

## Upgrade compatibility

- Built directly on HA1124 and preserves package `ru.natro.statuswidget`.
- Uses version code `208021125` and must be signed with the same stable HA update certificate, so
  it installs over HA1122/HA1124 without deleting settings.
