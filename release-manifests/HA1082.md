## Included changes

- Added the configurable old-style Monjaro driver rail as a continuous full-height overlay.
- Added up to ten independently sized buttons, ordering, labels, vector presets, colors and panel
  appearance controls with a live settings preview.
- Added Home, Back, all-apps and a movable stock-climate proxy button. The proxy temporarily makes
  the rail input-transparent and taps the fixed OEM climate coordinate under it.
- Added a resolution-independent live climate icon. It displays driver temperature with one
  decimal, a nine-segment manual fan scale or a five-segment automatic-mode intensity scale,
  without an `AUTO` caption. When climate is off it displays only the centered muted temperature.
- Reused the confirmed `climate.fan` routing and freshness policy from the existing climate panel,
  including the vehicle-specific two- and three-profile AUTO families. No independent mode guess
  or stale boot value is used.
- Added a complete installed-app catalog including system, disabled and non-launcher packages.
  Non-launchable packages remain visible and are explicitly identified.
- Kept the all-apps drawer on the same successful ECARX system layer as the rail so it appears
  above application and floating-navigation windows.
- Added boot restoration, ECARX navigation-bar lifecycle handling and direct settings navigation.
