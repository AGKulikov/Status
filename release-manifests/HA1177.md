# Status Widget HA1177 + iPhone Helper v19

Package: `ru.natro.statuswidget`

Version name: `v2.8.2-ha1177`

Version code: `208021177`

## Responsive launcher media controls

- The independent music-position and volume widgets use the complete width and height assigned
  in the HOME editor instead of retaining the source grid cell's fixed thickness.
- Rounded track ends are recalculated in physical screen coordinates after non-uniform frame
  scaling, so a taller widget remains a clean capsule rather than a distorted bitmap.
- The volume thumb grows with track height but remains circular; the audio glyph retains its
  aspect ratio.
- The music-position track is touch-controlled like volume and seeks the exact active player.
  It intentionally has no thumb.

## Phone-notification presentation

- The phone-notification layout editor exposes the persisted popup-position lock used by the live
  overlay controller.
- A notification arriving while another card is visible waits one second. Every subsequent item
  is retained FIFO and receives its own one-second slot until the burst queue is empty.
- Field state is published only when its queued card is actually presented, so the visible card
  cannot show text from a later delivery.

## Compatibility

- Helper v19 and the HA1176 ANCS-owner telemetry relay remain unchanged.
- Classic Bluetooth, the selected iPhone identity and the system LE bond are preserved.
