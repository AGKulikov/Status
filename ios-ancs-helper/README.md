# KX11 ANCS Helper for iPhone

Маленькое тестовое приложение для iPhone. Оно находит диагностический BLE-сервис
магнитолы и подключается к нему с системной опцией
`CBConnectPeripheralOptionRequiresANCS: true`.

Это отличается от обычного подключения через LightBlue: iOS получает явное
указание, что подключаемому аксессуару требуется Apple Notification Center
Service.

## Установка с Mac

1. Откройте `KX11ANCSHelper.xcodeproj` в Xcode.
2. Подключите iPhone кабелем и выберите его как Run Destination.
3. В `Signing & Capabilities` выберите свою команду в поле Team.
4. Нажмите Run. При первом запуске подтвердите Developer Mode/доверие приложению,
   если iPhone попросит.

## Тест

1. На магнитоле установите KX11 ANCS Test v2 и нажмите **Ждать iPhone**.
2. Откройте KX11 ANCS Helper на iPhone и разрешите Bluetooth.
3. Приложение само найдёт магнитолу, подключится с `RequiresANCS`, запишет команду
   `PAIR` и прочитает защищённую характеристику.
4. Подтвердите системные запросы сопряжения и доступа к уведомлениям.
5. Сравните журнал на iPhone с журналом магнитолы:
   - `WRITE ... OK` — iPhone подтвердил себя через CONTROL;
   - `SECURE ATT OK` — BLE-канал действительно зашифрован;
   - `ANCS authorization changed: true` — iOS разрешила ANCS этому аксессуару.

Проект не читает уведомления на самом iPhone. Уведомления должен читать ANCS-клиент
на магнитоле после успешного BLE-сопряжения и авторизации.
