Зацепки по приборной панели и HUD
1. В ресурсах GMCSoft явно есть настройки вывода музыки на приборку,
   навигации на приборку и HUD, режима AR/упрощённого HUD, названий улиц
   и транслитерации. Выбранные строки сохранены в
   analysis_evidence/GMCSoft_dashboard_HUD_strings.json.
2. Восстановлены onNotificationPosted/Removed в NaviService (VM 18/19).
   Вход в цепочку проходит проверку авторизации, выбирает парсер по пакету
   (Яндекс Навигатор, Яндекс Карты, Навител), обновляет минутный таймер.
   Удаление подходящего уведомления либо таймер вызывают цепочку остановки
   навигации/очистки HUD. Также подтверждён вход в обработчики музыки.
3. Virbox хранит основной DEX в блоке VBPD после короткого DEX-загрузчика.
   Алгоритм RC4 + Zstandard восстановлен из x64-библиотеки; оба приложения
   успешно распакованы без их запуска. Музыка на приборку передаётся через
   MediaCenterAPI; HUD получает отдельные broadcast-сообщения. Подробнее
   и точные ссылки на реконструированные классы — в VIRBOX_FINDINGS.txt.
4. В XCSettings2 найден CustomVehicle: для функции 260 он записывает
   display_on_dashboard = no/normal и уведомляет ContentResolver через
   content://ecarx.settings/map/display_on_dashboard.
   Это конкретный путь настройки проекции, но не доказательство команды
   открытия «крыльев» DIM и не инструкция для запуска на автомобиле.
5. В CarService есть InstrumentClusterService и CarPropertyService.
   Строка конфигурации renderer:
   android.car.cluster.sample/.SampleClusterServiceImpl.
   Наличие Android-интерфейса не доказывает реальный путь к QNX/DIM.

Ограничения разбора
Механизм «крыльев» и низкоуровневый формат сообщений DIM пока не установлены.
Известны Android-отправители HUD, но не принимающая сторона и её связь с DIM.
CarService декомпилирован; для XCSettings2 JADX сообщил о 21 ошибке, для
восстановленного GMCSoft — о 38, GPSProvider — о 6. В Java остаются
ошибочно декомпилированные методы. Java — реконструкция,
не исходники автора. Ключевые отправители GMCSoft сверены с DEX-инструкциями.
Совместимость пакета с текущей версией машины не проверялась.

Важно: только для анализа
Не запускайте эти скрипты на компьютере или автомобиле. Скрипт clean
при наличии маркера clean/clean.txt на USB содержит удаление /data;
first_start содержит удаление DCIM. Установочный сценарий меняет
системные компоненты. Ни один APK, native-модуль или скрипт не запускался.
