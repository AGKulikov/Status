# Полный постраничный индекс интерфейсов Geely / ECARX

Все **4440 записей исходного каталога v1.0** сохранены в `entries/`, включая исходные `entry_key`, поля, схемы и указатели. Страницы имеют размер не более 300000 байт UTF-8. `entries_manifest.json` фиксирует количество, границы, размер и SHA-256 каждой страницы.

Это фиксированный исходный набор, а не полный перечень всех функций автомобиля или всех значений SDK. Он не включает позднее найденные декларации, пропущенные исходным извлечением, в том числе некоторые поля с неявным нулевым значением. Дополнительные аудиты учитываются отдельно.

Локальный поиск проверяет хэши всех страниц, применяет обязательные [семантические исправления](SEMANTIC_ERRATA_RU.md) и не связывается с автомобилем. В `--json` исходная роль сохраняется как `baseline_declaration_role`, исправленная — как `declaration_role`; сами страницы не изменяются. Пропущенные нулевые константы пока искать отдельно в `supplemental_zero_constants.json`:

```bash
python3 lookup_interfaces.py PAC_ACTIVATION
python3 lookup_interfaces.py EpbSoftSwtCtrlSt --json
python3 lookup_interfaces.py 0x2140728D --limit 0
```

Детерминированное создание страниц из исходного `entry_index.json`:

```bash
python3 publish_interface_pages.py /path/to/entry_index.json /path/to/published
```

Точное восстановление исходных записей: прочитать страницы в порядке `pages` из manifest и соединить массивы `entries`. `PAGES_VALIDATION.json` подтверждает полное равенство исходному массиву, исходный порядок и побайтово идентичное повторное создание страниц.

Статическая доступность SDK метода и разрешение VHAL не доказывают применимость комплектации, разрешение приложению или физическое исполнение команды.

[Дополнительный аудит неявных нулевых значений](ZERO_CONSTANTS_AUDIT_RU.md) и его [машиночитаемые результаты](supplemental_zero_constants.json) учитываются отдельно от страниц baseline.
