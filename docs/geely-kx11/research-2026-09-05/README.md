Начать с матрицы, затем открыть тематическую карточку и точные доказательства. Прежние каталоги и отчёты v1.0 доступны [в исходном комплекте](../README.md); относительные source paths вида `firmware/...`, `display/...`, `cruise/...` в JSON обозначают этот комплект. Архивные `member`, DEX offsets и ELF addresses обозначают исходное доказательство, а не отсутствующий публичный файл. Полные чужие декомпиляты остаются исключёнными по REL-008.

В JSON путь `evidence_record.file` разрешается относительно этой папки; `json_pointer` — внутри указанного файла. Для прежних source pointers сохраняются SHA оригинала и исходный namespace. Внешние ссылки на `Geely_KX11_Knowledge_v1.0/...` не следует автоматически переписывать на новый отчёт с иным хэшем.

94 карточки — области исследования с пересечениями, а не число ECU. 4440 деклараций — сохранённый исходный набор, а не все функции автомобиля. В этой итерации физические тесты не выполнялись, APK не собирался. Текущие требования Natro 2.7.7, NOTIF-009 и открытые GATE-046/GATE-048 сохраняются.
