## Нативный маршрут30.3.0

Stock voice button через appkit/map/l1 вызывает public app.x3.x с BUTTON,
null текстами и mask6. MapActivity.u() возвращает public injects.d (app.x3).
Собственный адаптер вызывает именно эту точку: сохраняются штатные проверки
доступности Алисы/микрофона. Private-field scan и startActivity отсутствуют.
Первоначальная идея callOnClick заменена прямой штатной точкой: Rx-подписка
скрытого/отсоединённого контрола может быть уже снята.

MapActivity.onCreate привязывает maps_activity_alice_container к router w;
public r() возвращает его. x3.x проверяет пустой stack f(), затем x3.a
добавляет AliceController/QuarkAliceController. Router.g() — фактический размер
того же backstack. Поэтому transition0→1→0 отслеживает диалог, а не видимость
Activity или паузу в речи. Состояние читается каждые100ms; до первого открытия
10s timeout, общий предел30min. Потеря Activity/ошибка/timeout — ABORTED,
не FINISHED и не разрешение включать музыку. Остаточная FIELD неопределённость:
фактическое голосовое обслуживание в фоне и жизненный цикл штатной Алисы.

## Новый протокол

Dynamic receiver dd.call_alice живёт в процессе после onStop. Регистрация
из существующего MapActivity hook, signature permission отправителя, package,
случайный request id, elapsedRealtime deadline, dedup32. Probe/ACK подтверждают
получение команды, ResultReceiver отдельно сообщает STARTED/FINISHED/ABORTED.
ACK сам по себе не означает голосовой ответ. При работающем/неизвестном процессе
Activity не запускается. Только полная shell ps-проверка отсутствия разрешает
один обычный cold launch; затем ожидается READY, а не fixed1500ms.

До любого cold launch Natro снимает snapshot реально PLAYING MediaSession.
После подтверждённого закрытия диалога планируется PLAY через2000ms. Только
сохранённый session token, только PAUSED; новая/исчезнувшая сессия, уже играющая
музыка, другой играющий плеер и ручной transport отменяют автоматический PLAY.
Нет исходного PLAYING — нет PLAY. OEM Binder чтения/команды вне MAIN. Таймер
задержки/токены существуют только RAM, не восстанавливаются из backup.

SOURCE candidate; TEST/APK/PUBLISH ожидают текущий полный CI и подпись.
FIELD gates: фон→фон, окно→то же окно, экран→экран, cold start; реальный голос;
длинный диалог/отмена/ошибка; music playing→pause→finish+2s, initial paused→paused,
manual player switch/повторное нажатие/уничтожение Activity. Требуется новый
приватный Navigator APK вместе с Natro3.3.8; Helper прежний.

API источники: [ResultReceiver](https://developer.android.com/reference/android/os/ResultReceiver),
[MediaController](https://developer.android.com/reference/android/media/session/MediaController),
[broadcast permissions](https://developer.android.com/develop/background-work/background-tasks/broadcasts).

Уточнение SOURCE: manual-generation permit фиксируется ещё до асинхронного
снятия PLAYING, поэтому ручная пауза во время capture/cold launch отменяет
будущее продолжение даже до создания music guard. Проверяется перед самим PLAY.
