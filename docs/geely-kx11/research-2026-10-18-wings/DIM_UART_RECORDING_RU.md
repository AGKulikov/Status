# Непрерывная запись DIM — 18.10.2026

SOURCE: добавлен отдельный явный запуск/остановка из диагностики. Читается только
существующий `logcat -b all -v threadtime -T 1 linoverlvds:V *:S` через отдельную
ADB-сессию. Прямого открытия ttydim, подписки HIDL, root и vehicle setters нет.
Начало сохраняет wall time, uptime, boot ID, fingerprint и software NaviMode.
Фоновый поток пишет полученные байты непосредственно в файл с fsync; нет очереди
неограниченного размера и буфера целой записи в RAM. Ограничения: 20 минут,
64 МиБ на сессию, три сессии. Старые записи не удаляются новым запуском: после
трёх требуется явная выгрузка и удаление. Это ограниченный непрерывный интервал,
не круглосуточный регистратор.

Выход с экрана не останавливает отдельного process owner. Гибель процесса/питания
останавливает запись; foreground service не добавлен. Последний незавершённый
системный write/fsync не гарантирован. Сохранённый running marker означает
`running_or_interrupted`, никогда не запускает команды. ZIP всех трёх сессий можно
получить после следующего запуска приложения; без terminal это частичная запись.
Состояние завершения различает user_stop, size_limit, storage_failure,
transport_or_deadline и stream_ended_unconfirmed. При сбое записи самого terminal
исходный running marker сохраняет неопределённость. Logcat может не выдавать UART
из-за прав, уровня логирования или переполнения системного кольца; отсутствие
строк не доказывает отсутствие обмена. Первые строки могут относиться к прошлому.

Экспорт содержит SHA-256 и размеры, исключает symlink, не перезаписывает исходные
журналы. Экспорт/удаление запрещены во время активного сбора; общий mutex исключает
параллельный полный дамп. Хранятся два последних временных ZIP. Запись не
возобновляется автоматически после восстановления полной резервной копии.
Файлы входят в прежнюю архивную группу `files/diagnostics`; настройки/defaults
и версия приложения не изменены. Сырые журналы передаются лично, не в публичный Git.
