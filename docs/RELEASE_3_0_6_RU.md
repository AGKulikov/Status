# Natro 3.0.6 — пассажирский автозапуск и настройки

Версия 3.0.6, versionCode 208021339. Обновление предназначено для установки
поверх 3.0.5 с сохранением данных и прежней подписью. Проверки конкретного APK
фиксируются в `3.0.6-release-report.json` после подписи.

## Изменения

- В настройках пассажирского лаунчера добавлен выключенный по умолчанию
  автозапуск при старте основного процесса Natro после разблокировки.
  Путь: Настройки → Главный экран → Лаунчер пассажира → Основное.
  После включения нажать «Применить». Срабатывает при следующем запуске Natro,
  только на пассажирском дисплее 3. Возврат из чужого приложения и изменение
  настроек повторно не открывают HOME. Отмена черновика не запускает окно.
- Убрана повторная обёртка главного каталога настроек, вызывавшая двойное
  «Основное». Вложенные редакторы сохраняют «Применить» и «Отмена».
- Поздно загруженные карточки списка приложений получают текущую тему и шрифт
  до показа. Высота переключателей адаптируется к крупному шрифту.
- Закрытие старого обработчика ввода при собственном переподключении больше
  не записывается как авария; настоящие ошибки текущего обработчика сохраняются.

## Границы результата

Белая вспышка не менялась: пользователь подтвердил её исчезновение.
Отдельная штатная белая полоса, VA/кнопки после обновления, восстановление музыки
и падение процесса остаются открытыми. Этот выпуск не объявляет их устранёнными.
Физическая проверка на KX11 требуется; автоматические тесты её не заменяют.
Navigator и Helper в этом выпуске не изменены, их переустановка не требуется.
