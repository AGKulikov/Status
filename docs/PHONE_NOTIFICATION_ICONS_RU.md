# Иконки приложений телефона

03.10.2026. SOURCE/LOCAL TEST; APK и проверка Android/KX11 не выполнялись.

Отдельный экран «Иконки приложений телефона» доступен из настроек уведомлений
и общего каталога/поиска. Список содержит название, точный идентификатор ANCS,
превью и состояние: автоматическая, своя, отсутствующая. Приложения без найденной
иконки остаются в списке. Поиск работает по названию и ID. Можно вручную добавить
ещё не наблюдавшееся приложение по его точному ID и выбрать PNG/JPEG.

Выбор файла не зависит от расширения: декодер проверяет PNG/JPEG, размер до 8 МБ,
до 40 Мп; изображение уменьшается с сохранением пропорций до 512 пикселей по
большей стороне и сохраняется как PNG. Прозрачность PNG сохраняется. Исходный
документ после импорта не нужен. Отмена выбора не меняет данные. EXIF-поворот
JPEG пока отдельно не обрабатывается; при необходимости подготовить файл уже
с нужной ориентацией. Обрезка/редактор изображения в этот этап не входят.

Сопоставления пользователя и нормализованные файлы хранятся в
files/phone-icon-overrides/catalog.json и UUID.png. Каталог имеет schema=1;
типизированный объект содержит id/name/file. Новая иконка записывается и
перечитывается перед атомарной заменой каталога. Ошибка не заменяет прежнюю
запись. Старые версии PNG пока сохраняются. Автоматическая загрузка пишет в
прежний ANCS-icons; она не заменяет пользовательскую иконку. В следующих
уведомлениях общий drawable-путь выбирает пользовательский файл первым.
Уже видимая карточка не перестраивается автоматически.

Действие «Вернуть автоматическую иконку» снимает пользовательский приоритет,
но сохраняет вручную добавленное приложение в списке. Если автоматического
файла нет, начинается поиск. Файлы пользователя не удаляются из сохранённых
версий. Все наблюдавшиеся приложения берутся из существующего каталога;
это не перечень всех установленных приложений iPhone (ANCS такого перечня не даёт).

## Полная копия и повторное скачивание

Требование пользователя: включать перечень всех ранее сопоставленных иконок,
чтобы после восстановления загрузка начиналась без новых уведомлений.

Автоматический catalog.json теперь сохраняет source_url рядом с id/name,
icon_file/icon_type. Старые каталоги совместимы: при отсутствии source_url
используется прежний поиск по ID/названию. automaticDownloadManifest() формирует
отдельный версионированный перечень для будущего архиватора. Сохранённый URL
повторно используется только для разрешённых HTTPS-источников Simple Icons/
Apple artwork. Отсутствующий/пустой файл входит в повторную загрузку при создании
store, затем попытка повторяется каждые 15 минут, также есть кнопка ручного повтора.
Работа выполняется на фоновом потоке. Каталог остаётся списком требуемых иконок
при отсутствии сети; успешные файлы повторно не скачиваются.

Будущий полный архив ОБЯЗАН включать:
- исходный автоматический каталог и перечень повторной загрузки;
- скачанные доступные файлы для немедленного офлайн-показа;
- весь пользовательский каталог, его файлы и приоритеты;
- явный отчёт об отсутствующих своих файлах (их нельзя заменить сетью молча).

После проверки и активации восстановленного набора требуется перезапуск владельца
каталога или явное перечитывание в новом поколении; только после активации разрешён
старт сетевой очереди. Изолированная проверка копии не скачивает файлы. Восстановление
недоступной иконки из сети не гарантируется: исходный сервис может удалить ресурс.
Полнота самих настроек сопоставления проверяется независимо от успешности сети.

Это подготовленный источник/потребитель будущего архива. Старый JSON-экспорт
не включает эти новые файлы; интеграция с ещё не реализованным полным архиватором
не заявляется завершённой.

## Проверка

JVM-компиляция и исполнение production PhoneIconOverrides с Android org.json:
запись/повторное открытие, замена, сброс приоритета с сохранением приложения,
отклонение некорректного ID/пустого названия, отказ замены каталога, повреждённый
каталог без перезаписи. Пройдено. Синтаксис шести Java-файлов проверен javac parser.
Это не Android type-check и не UI-тест. Нужны Android/KX11: выбор из провайдера,
PNG/JPEG, перезапуск/поворот Activity во время выбора, гонка с загрузкой, показ в
уведомлениях, отсутствие сети и возврат соединения, фактическая резервная копия.

Дополнительно исполнены извлечённые production-методы очереди и download manifest:
запуск по каталогу без уведомлений, отсутствие дублей, пропуск своих/готовых
иконок, повтор после неудачи и сохранение id/name/source_url. Проверка пройдена.
