## Причины и изменения

| Симптом | Подтверждение | Изменение |
|---|---|---|
| Приборка зависит от Settings | HUD attach 14:28:00.149; Settings resume 14:29:22.377; первая cluster lease 14:29:22.748, attach 14:29:23.017. В host-пути WidgetService пропущен automatic reconcile приборки. | Запуск из фонового host при инициализации и завершении lifecycle reconcile. Существующие enabled/autostart, идемпотентный прямой launcher и рабочий поток DIM сохранены. |
| ANCS бесконечно повторяет один GATT | В сессии 2.7.7 с 14:28:05 до конца 14:30:05 нет READY. Положительное доказательство регистрации clientIf есть. Быстрые advertisements прерывают таймер восстановления и не увеличивают sameOwnerReassertions. | Фактически выданные повторные connect на том же wrapper учитываются и для advertisements, и для Classic prompt. После ограниченного числа попыток закрывается только доказанно зарегистрированный владелец; новая регистрация разрешается после teardown. Таймер без доказательства регистрации не закрывает владельца. |
| При обычном retry якобы исчезает enrollment | В ещё старой сессии 2.7.5 после ошибки C4 14:25:22.582 следующее соединение 14:25:23.037 требует enrollment; новая epoch загружает запись и достигает READY в 14:25:50.106. Код reset общий с 2.7.7. | Сброс handshake не удаляет уже проверенный snapshot enrollment текущей epoch. Новая epoch и dispose по-прежнему очищают его, следующая epoch загружает запись вне main thread. |
| Пропал штатный синий знак | Hello `3fe7` не содержит `CAP_MANEUVER_ARTWORK=0x4000`. Версия 30.3.0 сама по себе не различает моды. Предыдущая выдача 2.7.7 содержала только Natro. | Выдаётся совместимая пара; проверка готового classes19.dex отклоняет старый мод без artwork IPC. Hello пишет понятную диагностику несовместимости. Стрелка по semantic action не рисуется. |
| Плитки пропадают после «Домой» | В коде проверка proxy-видимости могла завершиться до дочернего layout; layout при прежних bounds workspace не давал гарантированного повторного пересчёта. | После каждого реального layout пересчитывается видимость; источники, ещё не получившие первую геометрию, повторно связываются. Список без изменений не перестраивается. Диагностика содержит configured/routeActive/frames/visible без названий точек. |

## Локальная регрессия до сборки

JUnit 4.13.2 / Java 17: **36 тестов AndroidCentralRoute**.
Те же новые тесты на исходном reducer из предыдущего HEAD: 2 падения — advertisement и
Classic prompt оставляют WAIT_SYSTEM_CONNECTION вместо RETRY_DRAINING. На исправленном:
36/36 PASS. Отдельно проверены stale callback, повторный advertisement, отсутствие второго
владельца до teardown и 12 циклов без права закрыть unproven owner.

Проверка реального `Navigator-30.3.0-Natro-2.7.5-signed.apk` новым release gate:
ожидаемый отказ из-за отсутствия `maneuver_artwork` в classes19.dex. Это проверка бинарной
совместимости, не доказательство отрисовки штатного знака на физическом KX11.

## Обязательная приёмка на KX11

Установить оба APK поверх существующих. Без открытия настроек проверить холодный старт,
обновление пакета и пробуждение: приборка, HUD, READY ANCS и новое уведомление. Сопоставить
штатную синюю карточку головного Navigator и HUD/DIM (GATE-041/043). Проверить 20 возвратов
«Домой», включая неподвижные bounds и отсутствие маршрута: все избранные плитки и подписи
сохраняются (GATE-044). Активный маршрут продолжает штатно переключать общий блок на навигацию.
Полный список требований и открытых ворот находится в основном реестре.
