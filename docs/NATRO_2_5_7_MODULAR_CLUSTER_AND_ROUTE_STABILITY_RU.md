# Natro 2.5.7: модульная приборная панель и стабильное ведение

## Что изменено

- Старые экспериментальные компоновки приборной панели заменены пятью вариантами: Slate
  Horizon, Glacier Map, Aerowave, Steel Vector и Continuum.
- Каждый вариант хранит собственную конфигурацию модулей: видимость, положение, размер, слой,
  стиль и состав элемента. Переключение на другой вариант больше не сбрасывает уже настроенный.
- Аналоговый прибор позволяет отдельно скрывать фон, шкалу, цифры шкалы, стрелку, цифровое
  значение и единицу измерения. Цифровые элементы позволяют отключать фон, единицу и линию
  значения.
- Информационный блок содержит три независимо выбираемые строки. Навигационный блок отдельно
  управляет названием улицы и остатком пути/времени.
- Фон панели настраивается независимо: чистая чёрная верхняя зона, нижний цвет градиента и
  полностью прозрачный режим.
- Для карты добавлены цвет дорог без маршрута и пробок и режим названий улиц только на маршруте.
- Курсор обеих дополнительных карт использует привязанную к маршруту позицию MapKit, как
  основной Навигатор, вместо сырой точки GPS при активном маршруте.
- Видимая линия маршрута каждый раз строится от текущей позиции курсора. Если GPS временно
  перенёс позицию вперёд, а затем MapKit вернул её назад, скрытый участок маршрута восстанавливается
  сразу и без подтверждающих отсчётов.

## Установка

Natro 2.5.7 и модифицированный Яндекс Навигатор 30.3.0 образуют одну совместимую пару. Оба APK
нужно устанавливать поверх текущих приложений без удаления данных:

```bash
adb install -r Natro-2.5.7-signed.apk
adb install -r YN_30.3.0_Natro-HUD-v2-signed.apk
```

## Проверка на ECARX KX11

1. Последовательно открыть все пять вариантов, изменить модуль в каждом и проверить, что после
   полного цикла каждый вариант восстановил именно свою настройку.
2. В Continuum отключить спидометр и включить левый информационный блок.
3. В Slate Horizon отключить цифровое значение внутри аналогового спидометра.
4. Включить режим названий улиц только на маршруте и задать заметный цвет дорог без маршрута и
   пробок.
5. Проехать участок с параллельной дорогой: курсор основной карты и приборной панели должен
   оставаться на одной привязанной к маршруту позиции.
6. При кратковременном скачке GPS вперёд проверить, что после возврата курсора линия маршрута
   снова начинается от него, а ранее скрытый участок немедленно появляется.

Статические проверки сборки не заменяют дорожный тест GPS/MapKit на головном устройстве.
