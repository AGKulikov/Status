# Natro 3.0.2 — проверочная пара APK, 04.10.2026

Подписаны Natro 3.0.2 / 208021335 и совместимый Navigator 30.3.0.
Устанавливать оба APK поверх прежних приложений, без удаления и очистки данных.
Пакеты и прежний сертификат сохранены. Пара нужна для нового протокола копирования
собственной геометрии окна Навигатора.

## Что входит

- Отдельный HOME пассажира на display 3, собственные настройки и компоновка,
  действие «Домой пассажир» в назначениях и физических кнопках; прежний PHOME сохранён.
- Пассажирская боковая панель, избранное и меню приложений с отдельными настройками.
- Восстановление подписок кнопок после обновления; разгруженный путь MEDIA и диагностика задержек.
- Принудительная ночь карт HUD/приборки и защита стартового кадра. MAIN сохраняет свой режим.
- Сопоставление и ручная замена иконок уведомлений телефона, повтор скачивания недостающих.
- Быстрые шаги selector режимов вождения, разделение ожидаемого и подтверждённого режима,
  первый щелчок для открытия меню и задержка скрытия.
- 11 разделов настроек, общие светлая/тёмная/системная темы и размер текста,
  сохранение поиска/прокрутки, поиск по 833 подписям параметров, указатель шести разделов редактора.
- Зашифрованная резервная копия с предварительной проверкой, переносом настроек/ресурсов/секретов,
  точкой отката, журналом прерывания и собственными настройками окна Навигатора.
- HUD/LCA-патчер через встроенный ADB: точная проверка модуля, оригинал и режимы
  Simple/IntellGuide/AR, проверка результата и возврат. Применение и перезагрузка явные.

## Что не объявляется завершённым

Это проверочная сборка, а не закрытие всех требований выпуска. SETUI-003 выполнен
в части навигационного указателя; полная переработка каждого сложного редактора,
всех диалогов и их Apply/Cancel ещё не подтверждена. Поиск по подписи может открыть
редактор без автоматического раскрытия вложенного диалога.

Реальный полный backup/restore, эффективные defaults всех отдельных владельцев,
включение внешнего системного оригинала HUD/LCA и перенос на другое устройство
не прошли сквозную приёмку. Архив пока принимает только свою версию defaultsSchema;
системные разрешения, HOME-роль и Bluetooth-сопряжения не переносятся. Старый JSON неполный.

KX11: оба HOME и дисплей 3, все назначения физических кнопок, фактическая задержка
MEDIA, отсутствие белого кадра, внешний вид всех редакторов, backup/restore и эффект
HUD/LCA остаются открытыми. Испытания JVM и подпись не заменяют эти проверки.
