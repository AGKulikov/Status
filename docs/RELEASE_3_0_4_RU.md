# Natro 3.0.4 — продолжение незавершённых работ, 04.10.2026

Этот выпуск продолжает поручение «Продолжай доделывать то что не сделал» после
3.0.3. Ниже отдельно указаны реализованные изменения и открытая приёмка на
магнитоле/iPhone. Общая причина полевого отказа VA и белой полосы не установлена.

## Установка и совместимость

Natro **3.0.4 / 208021337** предназначен для обновления поверх выданного Natro
3.0.3 / 208021336. Устанавливать поверх приложения, без удаления и очистки данных.
Package `ru.natro.statuswidget`, label Natro, min/target SDK 28 сохранены.
Подпись и метаданные обновления проверены против фактического APK 3.0.3;
успешная установка на реальном KX11 до проверки пользователем не заявляется.

Совместимый Navigator — **30.3.0 из подписанной пары Natro 3.0.2**. Его исходники
не менялись. Повторное использование допускается только при точном совпадении
скомпилированного `classes19.dex` с этой парой. Если она уже установлена,
переустановка Навигатора не требуется. Само название 30.3.0 не определяет мод.
SHA-256 совместимого APK:
`958832329aa5d938d735e18b27d658c608082253a256b10937d6acc73c5c7058`.

Helper v70 в этой ревизии не менялся; Android APK не обновляет приложение iPhone.
Его дерево `d2a300a7683f158aec739d22f3bf7d200f1fcbde` совпадает с ранее проверенным.
[Swift-регрессия восстановления после тайм-аута и сборка с Apple SDK](https://github.com/AGKulikov/Status/actions/runs/37184234544)
успешны. Реальное восстановление после фоновой приостановки iPhone ещё не принято.

## Что реализовано

- **Пассажирский HOME:** полный общий renderer HOME работает через отдельную
  overlay Presentation на display 3. Водительская задача не переносится;
  вложенные окна принадлежат пассажирскому экрану. При выключении/изменении
  display сохраняется черновик, старые окна и подписки освобождаются. После
  явного запуска внешнего приложения HOME не возвращается поверх него сам.
- **Редакторы:** настройки MQTT, HA, Sprut, телефона, APNs, кнопок и сценариев
  используют Apply/Cancel без выполнения команд из черновика. Вложенный Apply
  не запускает соединения до итогового Apply. Некорректный ввод блокирует
  применение; APNs-файл и его metadata проходят одну журналируемую операцию.
  Сохраняются неактивные назначения кнопок и независимое runtime-состояние.
- **Интерфейс:** расширена Android-матрица до 36 экранов в двух темах при
  1760×656 и 26sp. Исправлены найденные пересечения, доступность «Назад»,
  разделы настроек телефона и предпросмотр уведомления. 48 исходников
  редакторов/253 формы в инвентаре не называются 48 независимыми экранами.
- **Резервная копия:** общий барьер записи охватывает main/geely preferences,
  новые XML и очередь runtime-записей. Добавлена явная миграция defaults копий
  3.0.2/3.0.3 в 3.0.4. Доступные системные оригиналы сохраняются как частные
  файлы с отчётом наличия и SHA-256; восстановление их не устанавливает.
  Импортированные флаги системных патчей требуют отдельного явного применения.
  Исполняемый round-trip удаляет исходные тестовые Keystore-ключи и восстанавливает
  секреты/APNs, CE/DE-файлы, URI-ресурсы и неизвестные typed keys с новыми ключами.
- **DIM/HUD:** регистрация, контрольное чтение и освобождение vendor callback
  вынесены из MAIN; есть ограниченное переподключение и отсечение поздних
  callbacks. Исправлена работа reflection proxy в Set/Map. Это не доказательство
  общей причины сбоя VA/полосы и не гарантия оживления зависшего Binder.
- **Проверка «машинки»:** в журнал добавлены этапы проверки HUD/LCA, код выхода,
  признак усечения и класс ошибки. Raw shell output и секреты не записываются.
  Allowlist модуля, его байты/смещения и условия допуска установки не расширены.

Встроенный выбор файлов иконок без DocumentsUI и исправления 3.0.3 сохранены.
Подробный состав хранения и пределы переносимости:
[контракт полной резервной копии](backup/FULL_BACKUP_CONTRACT_RU.md).

## Открытые проверки

- FIELD-002/003: общая причина повторного отказа VA и белой полосы не установлена.
  Нужен результат на KX11 с этой версией; успешный dispatch не доказывает эффект.
- FIELD-005: причина прежнего отказа конкретного HUD/LCA-модуля не подтверждена.
  Новый запуск встроенной проверки и журнал должны показать, на каком этапе отказ.
- HOME на display 3, физические кнопки и все сценарии интерфейса требуют приёмки
  ECARX. Robolectric не подменяет реальный compositor, SDK и владельцев окон.
- Runtime backup/restore требует многопроцессной приёмки Natro/Navigator на KX11,
  включая прерывание. Тестовый Keystore round-trip не доказывает свойства аппаратного
  Keystore. Root, Bluetooth-сопряжения, действительность внешних токенов и эффекты
  системных патчей не гарантируются архивом.
- Фоновое восстановление Helper требует проверки на iPhone.

Прежние записи «не реализовано» для HOME/редакторов/миграции backup заменены
описанием исходников и программных проверок этого выпуска; физические gates
не закрыты автоматически.
