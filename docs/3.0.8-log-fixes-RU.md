# Natro 3.0.8 — ошибки журнала 7 октября

Версия 3.0.8 / 208021341, база 3.0.7, прежний package и сертификат.

| Наблюдение | Изменение | Проверка / ограничение |
|---|---|---|
| apply HUD/LCA заканчивается IOException; белая полоса ждёт AdbConnection.open | В adblib 1.3 ранний OKAY мог произойти перед безусловным wait; введён постоянный predicate. OPEN/root service 10 с, обычный shell 15 с, консоль 60 с; точный socket закрывается, команда не повторяется | Детерминированный ранний OKAY/CLSE, deadline и повторное использование worker. Сам IOException не доказывает, что эта гонка была единственной причиной apply |
| adbd уже root | Проверить id -u до root:; при нужном UID не перезапускать daemon | Replay одного root request, отказа, потери ответа и уже root |
| ANCS: подключение состоялось, Service Changed status14 привёл к закрытию | До двух повторов CCCD через1/3с на том же owner после завершённого transient callback | Stale token, success→peer proof, исчерпание и stop. GATT133 сам по себе не устранён |
| Ранний архив 3.0.6: после STOP_TIMEOUT повторные INGRESS_FREEZE_FAILED | Restoration adapter нельзя повторно использовать с другой switch epoch: закрыть старый и заново получить zero-owner reservation | Replay timeout→новый adapter→drain→READY, без обхода proof |
| HUD main-thread AtomicFile.finishWrite/fsync | Один асинхронный coalescing writer | Блокированный диск не блокирует submit, сохраняется последний snapshot |
| Browser bind failed, точной сессии ещё нет | Два ограниченных rebind только того же сервиса и при действующем permit | Если PLAY уже передан, этот путь его не повторяет. Время до звука требует автомобиля/плеера |
| Восстановление копий 3.0.6/3.0.7 не принималось текущим allowlist | Разрешены рассмотренные схемы335…340→341; формат/defaults прежние | Сохранение явных значений, отказ неизвестной/будущей схемы |
| SprutHub SSL/DNS transient, затем ONLINE246 | Существующий reconnect сохранил работоспособность | Сетевую первопричину эти логи не устанавливают; протокол и секреты не менялись |

Журнал содержит несколько сессий: актуальная 3.0.7 начинается18:00МСК;
ранние сообщения 3.0.6 не выдаются за новые ошибки. Сырые логи не публикуются.
Изменений автомобильных IDs/offsets/allowlist нет. Машинка скрывается только после
успешного применения точного поддержанного файла и предусмотренного перезапуска,
а не после одной инспекции. В этом выпуске изменён транспорт и диагностика операции.
Физическая проверка скрытия, ANCS без radio toggle, музыки и белой полосы открыта.
Navigator и Helper не меняются; сборка проверяет совместимость Navigator3.0.2.

Повторы Service Changed используют отдельный RAM-счётчик, не расходуют разрешённое
восстановление авторизации. Дополнительный replay: два transient→AUTH_REQUIRED→
явное authorizationChanged→одна разрешённая попытка без нового GATT.

Первый полный CI выполнил2104 теста: один старый тест CausalDiagnostics считал
operation_overdue также внутри асинхронного incident snapshot (STATES/RECENT),
получая1 либо3 в зависимости от порядка записи. Проверка теперь требует ровно
одно исходное causal-событие точного span и его last_stage; production-журнал
не менялся, проверки не отключены. Повторный полный CI обязателен.
