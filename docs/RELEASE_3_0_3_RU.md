# Natro 3.0.3 — сборка обновления, 04.10.2026

APK собран по прямой команде пользователя и подписан прежним ключом Natro.
Серверные проверки и проверка установочного файла пройдены. Это не приёмка всего
незавершённого состава FIELD/SETUI; ограничения перечислены ниже.

## Установка и состав

Natro 3.0.3 / 208021336 предназначен для обновления поверх Natro 3.0.2 / 208021335.
Устанавливать APK поверх приложения, без удаления и очистки данных. Package
`ru.natro.statuswidget`, label Natro, min/target SDK 28 и прежний сертификат сохранены.
Реальная установка на KX11 до проверки пользователем не заявляется.

В этом обновлении:

- встроенный выбор файлов иконок и резервных копий на ГУ без DocumentsUI;
- исправления Применить/Отмена и вложенных настроек, освобождение закрытых редакторов;
- читаемые подписи переключателей в светлой теме, исправление найденных перекрытий;
- подробная read-only диагностика HUD/LCA; запись разрешена только после проверки
  точного известного модуля, прежние SHA/байты/смещение не расширены;
- дополнительная диагностика пути обработки VA для поиска полевой неисправности.

Совместимый Navigator — **30.3.0 из пары Natro 3.0.2**. Его исходники не менялись;
сборка 3.0.3 разрешает повторное использование только при побайтном совпадении
скомпилированного `classes19.dex`. Если эта пара уже установлена, повторная установка
Навигатора не требуется. Общее название 30.3.0 само по себе не определяет версию мода.
SHA-256 совместимого APK: `958832329aa5d938d735e18b27d658c608082253a256b10937d6acc73c5c7058`.

Исправление восстановления Helper после тайм-аута находится в отдельном iPhone-проекте
`ios/KX11-iPhone-ANCS-Helper-v70-personal`; Android APK не обновляет Helper.
[Проверка Swift и сборка с Apple SDK](https://github.com/AGKulikov/Status/actions/runs/37184234544)
успешны; дерево Helper совпадает с проверенным 98e68647. Проверка на iPhone открыта.

## Оставшиеся ограничения

- Полноценный HOME пассажира через overlay ещё не реализован.
- Полная переработка каждого сложного редактора SETUI-005…007 ещё не завершена;
  успешная матрица 34 вариантов не означает охвата всех 48 источников редакторов.
- Общая причина одновременного сбоя VA и белой полосы не установлена.
- Причина отказа конкретного HUD/LCA-модуля на ГУ ещё не подтверждена.
- Полнота резервной копии и восстановление в реальной многопроцессной среде,
  Keystore/Navigator и после прерывания требуют сквозной приёмки.
- Копии пока принимают только свою `defaultsSchema`; миграция копий между 3.0.2
  и 3.0.3 не реализована. Обычное обновление приложения сохраняет его хранилища;
  это отдельный путь от импорта резервной копии.
- Физические проверки KX11 и iPhone остаются открытыми.
