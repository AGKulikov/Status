# Natro 2.5.4: приборная панель, светофоры и события маршрута

## Что исправлено

- Приборная панель вынесена в отдельную Android-задачу. Запуск повторяет параметры MConfig для
  KX11: DIM mode 3, wake-пакет `2/8/8`, паузы `100/200/50 мс`, Display ID 2, windowing mode 5 и
  `SplitScreenShownPosition=0`. Вместо остановки всего пакета Natro сбрасывается только старая
  задача приборной панели, поэтому ANCS, музыка, bridge и фоновые карты продолжают работать.
- Для штатного слоя дорожных событий добавлен фильтр каждого объекта через MapKit
  `RoadEventStylingProperties.isOnRoute()`. Режим «Только по маршруту» больше не означает
  включение всех событий вокруг карты. Штатный provider Навигатора остаётся владельцем значков,
  типов камер и данных направления.
- `Guidance` теперь явно выдаёт до 8 ближайших светофоров. Сигналы берутся из
  `Windshield.getTrafficLightsWithSignal()` один раз и используются обеими независимыми картами;
  дополнительных навигационных сессий и циклов опроса не создаётся.
- Серые светофоры без сигнала, устаревшие данные, повороты и полосы вне активного маршрута
  по-прежнему не отображаются.

## Что нужно подтвердить на автомобиле

1. При запуске панели на приборном экране не появляется вопрос «Открыть это приложение на
   текущем экране?», а центральный экран Natro остаётся в своей задаче.
2. На активном маршруте событие с параллельной улицы скрыто при режиме «Только по маршруту».
3. Камера на маршруте имеет тот же тип и направление, что на основном экране Навигатора.
4. Светофор появляется только при наличии свежего сигнала и секундного отсчёта и исчезает не
   позднее трёх секунд после прекращения данных или завершения маршрута.
