## Охват и ограничения

Полный структурный проход по 6450 строкам исходного реестра:289 заголовков,497 различных ID,448 уникальных канонических строк требований без дублей;49 ID встречаются только в повествовании. Это не 497 независимых подтверждённых функций. [Индекс](REQUIREMENT_INDEX_2026_11_24.csv) сохраняет все ID и номера строк нового реестра.

Содержательно сверены текущий выпуск, правила подписи/версий, навигационная карточка, обновления, отмена ручного доступа, статусы файлового менеджера и Музыки. Для остальных областей сохранены ограничения и отсутствие нового FIELD. Не проведены повторная проверка всех 448 требований по реализации, повторное исследование прошивки, реальные испытания автомобиля и проверка доступности каждой исторической внешней ссылки. Старые ссылки на Actions artifacts могут истекать; они сохранены как история, а текущая установка ведёт на опубликованный release.

Требования ANCS, медиакнопок, крыльев, runtime backup/restore и круиза нельзя объявить устаревшими лишь потому, что записи старые. Для их закрытия нужны соответствующие доказательства. Ни один аппаратный gate этой редакцией не закрыт.
