# Natro3.4.1 — окончание разговора Алисы

SOURCE candidate, TEST/APK/FIELD OPEN. Предыдущая stable3.4.0 остаётся доступна.

Единая обработка для голосовой активации, штатной кнопки Навигатора и команд Natro.
Снимок игравшего плеера перед нативным запросом аудиофокуса; native idle определяет
окончание разговора независимо от закрытия окна.2s ожидание перезапускается при
новом слушании. Media token/manual generation/другой активный плеер проверяются
перед PLAY, включая очередь Binder. Heartbeat ограничивает право на автоматическое
продолжение при потере процесса Навигатора.

Обязательна новая пара Natro3.4.1 + Navigator30.3.0/Natro3.4.1. Helper не меняется.
В Navigator изменяются только classes11.dex, classes15.dex, classes19.dex на точном
приватном baseline3.3.9; исходники собственного патчера опубликованы, чужой APK нет.
Ожидание pre-focus snapshot ограничено300ms; при timeout возврат музыки не разрешается,
обычная работа Алисы продолжается. Quark и AliceKit проверяются отдельно на KX11.

Аппаратная приёмка: голос/штатная кнопка/руль, короткий ответ/уточнение/повторная
реплика в течение2s, ручная пауза/смена плеера, initial paused, фон/оконный режим,
ошибка/нет речи, смерть процесса до PLAY. SOURCE и симулятор не заменяют эту проверку.
