# Natro 3.3.4 — выгрузка записей DIM

Кандидат, ещё не опубликованный APK. Ветка release/natro-3.3.4.

Диагностика больше не разбивается автоматическим редактором на вкладки:
кнопки DIM и результат находятся на одном экране. Выгрузка показывает начало,
готовность ZIP и ошибки; готовый ZIP можно отправить или явно скопировать в
Download/Natro. События записи/выгрузки включены в общий журнал.

Нормализуется доверенный путь Android getFilesDir до проверки каталогов записей.
Ссылки внутри записей по-прежнему запрещены. Данные формата3.3.3 сохраняются.
Причина отказа на конкретном автомобиле пока не установлена: предоставленные
TXT/ZIP не содержали событий DIM-export и файлов uart.log/session.txt.

SOURCE: изменения подготовлены. TEST: pending. APK: pending. FIELD: OPEN.
Независимое скрытие крыльев не реализовано. Navigator и Helper без изменений.
