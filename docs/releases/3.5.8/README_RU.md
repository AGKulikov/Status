# Подготовка пары Natro и Навигатора 3.5.8

База выпуска 3.5.7 имеет коммит 63a7f55f762221f63b3d9ba6d7bc03a9524d186b. Исходники исправлений табличек и SprutHub проверены на локальном коммите 8821a72. Данные поездки и результаты воспроизведения сохранены в [разборе HUD](../../HUD_TURN_CARD_2026_11_26_RU.md) и [разборе SprutHub](../../SPRUTHUB_START_2026_11_26_RU.md).

Для подготовки обновления применяются CARD-017…020/026, MAP-033/054, NATRO-031, BASE-001/004/006, REL-001…011/013…015/017, GATE-058/060 и правила переноса резервных копий. Номера кандидатов — Natro 208021391 и Навигатор 739564639. Проверяются подпись пакета при доступе к ресурсам, сохранение старых настроек при восстановлении, граница поддержки следующего неизвестного пакета, геометрия HUD и восстановление SprutHub. Проверку совместимости на Android 9 и фактическую установку на KX11 учитывать отдельно.

Проверка неподписанного кандидата Навигатора прошла локально. SHA-256 исходной подписанной 3.5.7 совпал с манифестом канала. В манифесте кандидата поменялись только версия и её числовой код. Среди файлов пакета изменились AndroidManifest.xml и classes19.dex. Для остальных 17 225 записей совпали имена и SHA-256 содержимого. Проверка выравнивания 16 КиБ прошла. SHA-256 classes19.dex: 75deae9e7d7954fa5bc5e678cc97d5e9bb52a3882c45e5537fb1379344a4c629.

Владелец подтвердил переход на авторизованный ADB. Проведён разбор ADB-002, REL-002/005/011/017 и владельцев локального кэша. Критерии включают обе службы, игнорирование старого Telnet после обновления и восстановления копии, отказ при отсутствии авторизации и возможность обычного подтверждения ключа из консоли. В журнале dfd-2f61 для всех 203 завершившихся обращений указан ADB. Установка пары поверх 3.5.7 и полевые проверки остаются открытыми. Канал обновлений содержит прежний выпуск.

Полный локальный прогон после удаления обоих путей Telnet. Android Geely — 2373 теста, ошибок 0, падений 0, пропусков 0. Набор инструментов — 323 теста без ошибок или пропусков. Отдельно проверены реестр требований (449 строк), 99 владельцев данных и перечень редакторов настроек (48 классов, 253 формы). Прогон использовал тестовую среду и подписанный образец для проверки механизма обновлений. Физическая установка на ECARX в этот прогон не входит.

На локальном стенде проверены авторизованный ключ, отказ фоновому подключению с неизвестным ключом, отказ при отсутствии проверки ключа и подтверждение нового ключа в открытой пользователем консоли. В старом журнале 203 успешных обращения помечены как ADB. Для этих обращений режим проверки ключа на магнитоле в журнал не записывался. Отдельный тест проверяет отказ при неверной длине запроса до использования закрытого ключа.

Собран неподписанный Natro Geely с кодом 208021391. Проверены пакет, версия, CRC, выравнивание 16 КиБ и отсутствие обеих реализаций Telnet в DEX. Отдельная функция полного сбора файлов QNX использует службу приборки через Android. Авторизация Android не подтверждает отдельную авторизацию на приборке. Решение о составе сборщика для устанавливаемого выпуска остаётся открытым.
