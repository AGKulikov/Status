# Natro 3.5.8 и Навигатор 30.3.0 Natro 3.5.8

HUD и приборка показывают подсказку у текущего поворота, когда для неё есть место. Если метку нельзя разместить, актуальный манёвр остаётся в основной карточке на выбранном месте. Дополнительная карточка в левом нижнем углу убрана. Стрелка, расстояние, улица и полосы берутся из одной подсказки. При неполных данных используется штатная команда основной карточки.

SprutHub повторяет запрос каталога в действующем соединении, если связь с облаком сохранилась. В журнале видны этапы входа и восстановления связи.

В разделе «Диагностика → Доступ к QNX» появилась отдельная проверка соединения с приборкой. Сбор файлов сохранён. Для него нужны настроенный SSH-доступ к приборке и подтверждение ключей сервера и клиента. Системные команды Android используют авторизованный ADB.

Установите поверх 3.5.7 сначала Natro, затем Навигатор. У обоих приложений прежний сертификат. Сборка прошла 2 380 Android-тестов. Подписи и метаданные совместимы с Android 9. Установка, отрисовка табличек, подключение SprutHub и доступ к конкретной приборке требуют проверки на KX11.
