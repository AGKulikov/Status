# Natro и Навигатор 3.5.6

23.11.2026 пара [опубликована в stable/latest](https://github.com/AGKulikov/Status/releases/tag/natro-v3.5.6).
Для изменений табличек обновить **оба приложения** из раздела обновлений Natro.
Музыка и Helper для этого выпуска не меняются.

| Приложение | Версия | Код | Размер APK |
|---|---|---|---|
| Natro | 3.5.6 | 208021389 | 30 009 952 байта |
| Навигатор | 30.3.0 Natro 3.5.6 | 739564637 | 156 505 706 байт |

Внесены нормализация размера стрелок полной и короткой табличек, выбор размещения
по собственным границам HUD/приборки и замена изображения после готовности новой
текстуры. Когда полная табличка ещё вне кадра либо не помещается у манёвра, она
закрепляется в левом нижнем углу карты без географического указателя.
Источник данных по-прежнему требует свежего подтверждения на основной карте.
[Разбор и ограничения](../../NAVIGATOR_SIGN_VIEWPORT_2026_11_23_RU.md).
