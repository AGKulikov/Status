# Natro 3.5.6 и Навигатор 30.3.0 Natro 3.5.6

Изменён расчёт размеров стрелок полной таблички и отдельного знака полос: оба используют одну единицу масштаба целевого экрана.

HUD и приборка выбирают размещение полной таблички по собственным границам и проекции карты. Пока табличка у манёвра не помещается целиком, её полная подсказка закрепляется внутри карты внизу слева без географического указателя. При появлении свободного места она возвращается к манёвру. Старая текстура сохраняется до готовности новой.

Для этого изменения обновите оба приложения — Natro и Навигатор. Пара подписана прежним сертификатом и подготовлена для установки поверх 3.5.5 с сохранением настроек.

Исходники: `2eb80ca017ca5c036deb6ca4df52135550eecef4`, дерево `6d32b88e99b1d632bec72da58ce364c837263329`.

Проверка на реальном ECARX KX11 остаётся открытой: нужно сравнить размеры стрелок, переход закреплённой таблички к манёвру и размещение у краёв при разных масштабах HUD и приборки. Подтверждение данных по-прежнему поступает от основной карты Навигатора.
