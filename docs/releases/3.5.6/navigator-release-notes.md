# Навигатор 30.3.0 Natro 3.5.6

Общий расчёт масштаба стрелок для короткого и полного знаков. Размещение полной таблички учитывает собственный viewport HUD и приборки. Если корпус не помещается у манёвра, полная подсказка остаётся закреплённой внутри карты без указателя; новая текстура заменяет старую после готовности.

Установить вместе с Natro 3.5.6. Реальная проверка на KX11 ожидается.
