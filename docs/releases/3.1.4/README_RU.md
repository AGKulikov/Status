## Установка и проверка

Установить Navigator-30.3.0-Natro-3.1.4-signed.apk, затем Natro-3.1.4-signed.apk
поверх прежних приложений, без удаления и очистки данных. Подписи одинаковые со
стабильными выпусками; metadata Natro проверены против3.1.3/code208021346.
Это проверка артефактов, не выполненная установка на самой магнитоле.

Для телефона: включить «Буфер обмена и файлы», открыть показанный адрес в Safari,
ввести код, открыть «Загрузки / Natro». При отказе файлового доступа разрешить
его кнопкой на магнитоле. Обновить список и скачать файл; при запросе iOS
выбрать «Сохранить в Файлы». Использовать доверенную сеть, HTTP не шифруется.

Для дампа: Журнал → «Дамп системных файлов» → дождаться результата →
«В Загрузки/Natro» → подтвердить. Частичный ZIP имеет явные причины пропусков.
Это не полный образ прошивки и не изменение поведения приборки. Дамп не публиковать.

Физические gates OPEN: отсутствие прежнего падения на KX11, доступ ADB/su,
реальный состав дампа, разрешение Download/Natro и загрузка через Safari.
Новый код не считается доказанным исправлением задержек eMMC/музыки/ANCS или
исчезновения крыльев. Отчёты подписи/хешей: natro-report.json, navigator-report.json.
