# Natro 3.4.2

Повторные вызовы Алисы заново согласуют возврат музыки. После окончания разговора
сохраняется задержка 2 секунды; новая реплика отменяет предыдущий таймер. При потере
процесса Навигатора зависшая сессия отменяется. В экспортируемом журнале появились
этапы подготовки, события голосового движка, таймер и результат команды PLAY.

Для этой логики требуется парный Navigator 30.3.0 / Natro 3.4.2, переданный отдельно.
Обновления только Natro недостаточно. Фоновый и оконный режим Навигатора сохраняются.

Добавлена поддержка мода Яндекс Музыки 2026.10.2 / Natro 1: подготовка штатной
медиасессии без открытия плеера, проверка готовности и адресный PLAY. Временное
отклонение подключения при запуске повторяется в ограниченном интервале. Ручное
управление отменяет отложенный автозапуск. Музыка передаётся отдельно; настройки
учётной записи, подписки и очереди остаются штатными.

Natro устанавливается поверх 3.4.1 с прежней подписью и сохранением данных.
Navigator также сохраняет прежнюю подпись. Мод Музыки подписан ключом Natro,
который отличается от подписи присланного APK: установка поверх исходной Музыки
невозможна. До замены следует сохранить нужные данные; может потребоваться
повторный вход и загрузка офлайн-треков. Автоматическое удаление не выполняется.

Проверки исходников и APK не заменяют проверку на магнитоле. Для приёмки нужны
повторные разговоры разными способами, ручная пауза, фон/окно Навигатора и холодная
загрузка магнитолы с фактическим возобновлением трека. Работа «раз и навсегда»
не объявляется подтверждённой без этих проверок. Helper не изменён.
