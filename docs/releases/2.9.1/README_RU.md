# Natro 2.9.1 — события маршрута и журнал кнопок

Пара: **Natro 2.9.1 / 208021324** и совместимый мод Навигатора **30.3.0 / 739564630**. Установка поверх прежней пары тем же стабильным сертификатом; удаление приложений и очистка данных не нужны. Сначала обновляется Навигатор, затем Natro.

В реальном APK 30.3.0 отсутствует метод setRoadEventsOnRoute, на который ошибочно рассчитывала 2.9.0. Теперь все события DrivingRoute передаются в отдельную коллекцию MapKit через проверенные API. Значки предоставляет штатный r74.c; настройка каждого типа, режим «только на маршруте», разные профили HUD/приборки и отдельные камеры сохранены. Нет ограничения 8/32 событий. Отсутствующее описание не удаляет корректное ДТП. Журнал различает исходные, повторные, некорректные, скрытые, переданные MapKit события и замены камер; передача MapKit ещё не доказывает видимость на автомобильном экране.

Разделы `steering-input` и `steering-media` содержат входящие медиакнопки DOWN/UP/repeat, результат перехвата/fallback, времена event/down/callback/queue/dispatch/completion и изменения ревизии метаданных. Обычная клавиатура и текст треков не записываются. Нажатия не ждут дискового журнала. Корреляция команды публикуется до Binder, поэтому ранний callback не получает ошибочный предыдущий номер. Одинаковые playback callbacks агрегируются; функциональная обработка плеера сохраняется.

Watchdog фиксирует зависания от двух секунд и всегда ставит стек main первым. Первое обновление поверхности карты получает отдельный timing без нового ожидания ACK или чтения пикселей.

Подтверждено локально: реплей всех 22 типов и 80 событий, два профиля, смешанные категории, завершение маршрута, отказ штатного стиля, отсутствие описания и повтор после ошибки sink; полный локальный набор tools (113 тестов, один набор требует JSON jar из CI); 23 декларации API реального APK. Полная сборка и Android/JVM tests выполняются обязательным release workflow; окончательные commit/tree, проверки APK и подписи находятся в release-report.json и signature-reports.txt выдаваемого артефакта.

Открыто на KX11: причина белого старта, длительная задержка физических кнопок, полнота ДТП в реальной поездке. Источник штатной «Поездки 2» пока не подтверждён; PA/расчётные значения не подставляются за штатные показания. Эти пункты не объявляются исправленными.

Для следующего журнала включить подробный журнал Natro до воспроизведения. Достаточно нескольких нажатий «следующий/предыдущий/пауза» с заметной задержкой и экспорта журнала после поездки. Числовое `input_delay_ms` отделяет задержку доставки Android от очереди Natro и длительности вызова плеера; callback — наблюдение состояния, не доказательство момента слышимого переключения.
