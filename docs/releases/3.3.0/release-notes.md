# Natro 3.3.0

Добавлена отдельная «Диагностика крыльев» в разделе диагностики Natro.
Она использует встроенный ADB, собирает сведения о слоях/процессах/режиме
и доступные снимки дисплеев. Компьютер не требуется.

На стоянке соберите два ZIP: «Обычная приборка» и «Крылья видны».
Во время каждого сбора сделайте фото приборки, сохраняя её состояние.
Архивы можно сохранить кнопкой «В Загрузки/Natro» и скачать на iPhone.
Отменённый/частичный архив остаётся доступен после повторного открытия.

Это диагностический выпуск: независимое скрытие крыльев ещё не найдено.
Режимы и службы автомобиля сборщик не переключает. Снимок Android может
не включать аппаратные слои — поэтому фото приборки нужны вместе с ZIP.
Navigator и Helper обновлять не требуется. Подпись Natro прежняя;
метаданные обновления поверх3.2.9 проверены, установка на KX11 ожидается.
