## Проверки

- **1897 unit-тестов / 372 suite** в обоих CI: ошибок, отказов и пропусков нет.
- **176 проверок инструментов**, включая 100 Java policy/source случаев: без ошибок/пропусков.
- Natro, Navigator DEX и HUD Speed Bridge скомпилированы; контракт Helper v70 пройден.
- CI проверил подписи v2/v3, одного прежнего подписанта, CRC, zipalign, baseline boundary и KX11 static gates.
- Скачанный ZIP совпал с digest GitHub; все файлы совпали с SHA256SUMS и release-report.
- Локально проверены package/version/label, сертификаты v2/v3 и 18 групп фактических DEX-методов,
  включая диагностику обеих карт, очередь watchdog, timeline, холодную сессию и новые географические якоря.
- Сравнение с фактической парой 2.9.7: пакет/сертификат Natro прежние, versionCode увеличен на один.
  В Navigator изменился только **classes19.dex**; **17030 остальных payload entries** совпали,
  META-INF подписей исключён. Сравнение с оригинальным baseline отдельно выполнено в CI.

Проверки не отключались; неуспешный кандидат пользователю не выдавался.

## Проверка в автомобиле

Для захвата холодного белого старта включить обычный журнал Natro заранее, затем воспроизвести
событие и экспортировать этот журнал. Образцы HUD и приборки наблюдаются независимо;
результат чтения пикселей не блокирует показ карты.

Не объявлены устранёнными: исходная задержка кнопок до входа Natro, роль MConfig,
белый старт, первопричина системной регистрации Bluetooth и источник штатной «Поездки 2».
Аппаратная приёмка GATE-096…100 остаётся открытой.
