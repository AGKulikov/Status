# Natro 2.9.8 — стабильность и диагностика карт

Кандидат 16.09.2026. Natro 2.9.8 / 208021331 и совместимый Navigator 30.3.0 / 739564630.
Полная сборка, прежняя подпись и проверка конечных файлов фиксируются после успешного CI.
Этот предварительный документ не подтверждает существование готового APK.

## Сверка последних поручений

| Поручение | Что включено в исходники | Граница готовности |
|---|---|---|
| ANCS после обновления, влияние на Bluetooth | Отдельный общий worker Route A; ограничены частые повторы OWNER_UNPROVABLE, сохранён единственный GATT-владелец и поздние callbacks. | Не доказано устранение системного отказа регистрации; GATE-096. |
| Зависание главного потока | Watchdog PendingIntent/AlarmManager вынесены в последовательную очередь с объединением запросов и сохранением последней отмены. | Конкретный стек блокировки обработан в коде; проверка KX11 остаётся. |
| Единый плеер и время трека | Мягкое сравнение заголовка/исполнителя без обязательного album; запрет наследования длительности при смене token/media ID; неизвестная длительность отображается отдельно. | Общая архитектура 2.9.7 сохранена; GATE-097. |
| Автозапуск по mSaver 2.8.1 | Адресный bootstrap и одно PLAY в STATE_NONE после него; MediaBrowser на отдельном worker, отмена позднего PLAY после ручной команды. | Без Activity, без глобальных media keys; подтверждение требует STATE_PLAYING и KX11. |
| «Действия Natro» | Явная кнопка в редакторе каждого поддержанного назначения, выбор сразу переключает тип действия, сохранённое назначение подписано. | Прежние вкладки/параметры MConfig и отсутствие жестов MEDIA сохранены; GATE-098. |
| Альтернативные таблички | Точка примерно в 300 м вдоль собственной ветки после подтверждённой развилки; более близкие варианты для короткой/невидимой ветки, проверка тела и занятых мест. | Штатное содержимое и native collision сохранены; визуальная приёмка GATE-099. |
| Размещение объектов и цветные точки | Общий порядок размещения перепроверен; placemark скрывается до назначения текстуры, диагностируются причины отказа выноски. | Координаты реальных дорожных объектов не изменены; происхождение каждой замеченной точки требует сравнения на KX11. |
| Полное логирование белого старта HUD и приборки | Этапы producer/IPC/TextureView, generation и trace ID, свойства видимости, ограниченные PixelCopy-образцы вне UI, ошибки/таймауты/итог. | Диагностика не меняет показ и не возвращает ACK/readback gate. Сам белый экран остаётся открытым; GATE-100. |
