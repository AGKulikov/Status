# Подписанная пара Natro 2.8.5

11.09.2026 по прямой команде пользователя собраны и подписаны Natro
**2.8.5 / 208021318** и совместимый Navigator **30.3.0 / 739564630**.
Установка выполняется поверх нашей предыдущей пары без удаления приложений и данных:
сначала Navigator этой пары, затем Natro. Метаданные обновления и общий сертификат
проверены; установка и визуальная приёмка на физическом KX11 пока не подтверждены.

## Что входит

- NAV-016: карта HUD и приборки скрывает начальный системный буфер до первого готового
  кадра текущего producer lease; изменение размера живой поверхности не возвращает холодный gate.
- MAP-057/058: названия улиц снова рисует штатный MapKit вдоль дорог. Альтернативы проходят
  проверку identity и точек развилки, не дублируют общий префикс и активный маршрут, всегда
  получают стабильную выноску; нулевая дельта выводится как «то же время».
- CARD-022/023/024: четыре текстовые области синей карточки имеют независимый запрет
  переноса с конечным многоточием. Редактор показывает максимальный состав карточки.
  Независимые «Автоширина» и «Автовысота» сохраняют левый верхний угол; ширина ограничена
  заданным максимумом, рост происходит только вправо и вниз.
- NATRO-022: пробег и время текущей поездки читаются одной свежей парой из
  `PA_TS_OdometerTripMeter2` и `PA_TS_EDT_time2`; общий одометр через
  `ITripData.IDrivingInfo` для этих двух элементов больше не используется.
- NATRO-023: устранена повторная CPU/allocation-работа в измерении карточки, подготовке
  выносок, сканировании неизменных alternatives/events, clipping, одинаковой HUD-телеметрии
  и Trip 2 callback без потребителя. Разрешение, предел FPS, сглаживание, частоты данных и
  функциональный состав не снижались. Числовой выигрыш CPU не заявляется до GATE-075 на KX11.

проверены. Подписаны точный Natro APK и `classes19.dex` из этого запуска.

[Защищённый запуск подписи 34560271547, попытка 2](https://github.com/AGKulikov/Status/actions/runs/34560271547)

пару в артефакте `navigation-hud-v2-signed-2.8.5-267`.

`6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.

API 26–27 и v3 на API 28. В каждом случае подписант ровно один. Оба APK прошли
16-КиБ `zipalign` и полную проверку CRC.

ABI-нейтральность и увеличивает versionCode предыдущей 2.8.4 ровно на один.

739564630, min/target API 26/29 и ABI arm64-v8a.

Все **17 222 защищённые записи** оригинального Navigator сохранены побайтно. Относительно
подписанного Navigator пары 2.8.4 изменился только payload `classes19.dex`; остальные
**17 226 общих ZIP-payload** совпадают. Встроенный `classes19.dex` точно совпадает с CI
