# Natro 3.5.2 и Навигатор 30.3.0 Natro 3.5.2

В разделе «Файлы → Недавние» отображаются выбранные типы файлов за 31 день. Служебные JSON и базы данных отфильтрованы. Карточки объединяют файлы из одной папки по типу и времени, показывают до четырёх миниатюр и открывают полную группу по нажатию на заголовок. Поиск охватывает всю группу.

Синяя табличка поддерживает привязку к конкретному манёвру. На приборке и HUD передаются полосы, расстояние и улица при подтверждённом отображении в Навигаторе. Для этой функции установите оба обновления из раздела «Обновления приложений».

Автоматическая настройка доступа соответствует версии 3.5.0. Настройки и резервные копии переносятся с 3.5.1.

Переключение таблички и поведение раздела «Недавние» на реальном ECARX KX11 ожидают проверки владельцем.
