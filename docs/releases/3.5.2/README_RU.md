# Natro 3.5.2

Код версии Natro — `208021385`. Для синей таблички добавлена совместимость с установленным Навигатором 30.3.0 Natro 3.5.2, код `739564633`. Перед загрузкой его ресурсов Natro сверяет подпись пакета. Данные манёвра читаются в прежнем формате.

Когда на основной карте полная табличка привязана к повороту и её положение подтверждено, приборка и HUD могут показать у этого манёвра полосы, расстояние и улицу. Если подтверждение потеряно, вновь отображается штатный знак полос. Переключение между режимами на ECARX KX11 ожидает проверки. [Условия отображения таблички](../../NAVIGATOR_TURN_BALLOON_2026_11_19_RU.md).

В разделе «Файлы → Недавние» учитываются файлы выбранных типов, изменённые за 31 день. На карточке видны до четырёх миниатюр и общее число элементов. Нажатие на заголовок открывает всю группу. Выбранные типы и прочие настройки можно восстановить из копии Natro 3.5.1 (`208021384`). [Правила отбора и группировки](../../FILE_MANAGER_RECENTS_ES_RU.md).

**Статус.** Изменения внесены в исходники. Проверка подписанных APK 3.5.2, получение обновлений из публичного канала и проверка на реальном автомобиле открыты. Ранее для пары 3.5.1 оба APK прошли проверку, но GitHub вернул HTTP 403 при создании релиза. [Последняя попытка публикации 3.5.1](https://github.com/AGKulikov/Status/actions/runs/44524202133/job/135563337116).

Автоматическая настройка доступа работает по логике опубликованной 3.5.0. Соответствующие классы сверены с её исходным коммитом.
