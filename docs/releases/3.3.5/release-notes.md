# Natro 3.3.5 — медиакнопки и светофоры

Добавлен активный приём медиакнопок на отдельном потоке с общим контролем повторов.
Диагностика различает оба входа доставки. Снижено число повторных уведомлений
светофоров; изменения показаний передаются сразу. Защита от просроченных команд сохранена.

Устанавливайте поверх 3.3.4, без удаления приложения. Прежняя подпись и метаданные
обновления проверены. Для этого выпуска переустановка Navigator и iPhone Helper не требуется.

2192 Android-теста и 269 tool/replay tests прошли без ошибок и пропусков.
Подпись v2/v3/API 28, versionCode +1, выравнивание и совпадение payload с CI проверены.
Исходники APK: ed846b2b7f6514a2b6a1a9392d5769eeb2efe686.
