# Natro 3.5.5 и Навигатор 30.3.0 Natro 3.5.5

Обновите оба приложения через «Обновления приложений»: общая проверка, затем «Обновить» у Natro и Навигатора. Пара подготовлена для установки поверх 3.5.4 с прежним сертификатом и сохранением данных.

В этой версии изменена обработка редкого моргания таблички у поворота:
- Результат считывания видимого знака сохраняется, если за время считывания обновились метры у того же штатного объекта.
- Пока графический процессор ещё показывает предыдущую текстуру, она повторно проверяется по видимым пикселям.
- Разные ревизии одного знака в одной точке считаются одним объектом; совпадения у разных поворотов остаются неоднозначными.
- В журнал Natro добавлены причины скрытия таблички, возраст последнего подтверждения и номер текстуры.

Проезд, пересчёт, отмена маршрута, смена штатного объекта, неоднозначность и скрытие основной карты сохраняют прежние правила очистки. Без нового подтверждения срок удержания не превышает 1500 мс. Для определения новой привязки требуется видимая основная карта Навигатора. Общие настройки оформления полос и табличек для HUD и приборки сохранены.
