# Natro 3.3.7 — лайк и Алиса на кнопках

В общий список «Действия Natro» добавлены:
- «Лайк / убрать лайк» — переключение отметки текущего плеера через его MediaSession или действие уведомления. Если плеер не предоставляет команду, Natro сообщает об этом.
- «Алиса в Навигаторе» — адресный вызов Алисы через Яндекс Навигатор.

Назначение: «Кнопки» → нужная кнопка и жест → «Действия Natro». Действия доступны также в меню водителя и на HOME. Настройка сохраняется общей резервной копией.

Включены изменения 3.3.6: одиночные, двойные, тройные и длительные нажатия медиакнопок. Для новых действий Navigator и Helper переустанавливать не требуется.

Программные проверки и проверка APK не заменяют проверку на автомобиле: лайк/снятие лайка в конкретном плеере и открытие голосового интерфейса Алисы остаются FIELD OPEN.
