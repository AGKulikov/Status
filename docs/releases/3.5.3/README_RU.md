# Natro 3.5.3 и Навигатор 30.3.0 Natro 3.5.3

Устранён сброс подтверждённой таблички при движении карты и повторной отрисовке того же изображения. Полная табличка у поворота использует общие настройки полос своего экрана — размер, фон, стрелки и текст, обводку и скругление.

Обновите оба приложения в разделе «Обновления приложений». Код версии Natro — 208021386, Навигатора — 739564634. Обновление использует прежнюю подпись.

Проверка плавности переключения на реальной магнитоле ECARX KX11 открыта.

Исходники готовятся в ветке release/natro-3.5.3. Тесты и подпись выпуска проверяются отдельно от поездки. Приложение использует действующую автоматическую настройку доступа, подтверждённую владельцем 19 ноября 2026 года.

Общие параметры полос берутся из существующих профилей HUD и приборки. Копии 3.5.2 принимаются миграцией 3.5.3. Соседние знаки сохраняют маршрутную привязку.
