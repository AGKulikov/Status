# Natro 3.2.7

Обновление сборщика QNX для докачки недостающих файлов. Устанавливается поверх
предыдущей Natro с прежней подписью и сохранением данных приложения.

- Встроены исключения 977 проверенных файлов из переданных полного и частичного
  дампов. Совпадение пути и размера исключает повторное чтение; SHA содержимого
  на автомобиле заново не проверяется. Свежие журналы и mappings собираются снова.
- Добавлено чтение целей символических ссылок через metadata-only протокол qconn
  этой прошивки. Известные цели не скачиваются повторно под другим именем.
- Исправлен пропуск разных каталогов QNX с одинаковыми dev/inode.
- Улучшены канальные снимки до/после сбора и диагностика Connection refused.
  Закрытый listener этим не запускается.
- Сохранено исправление Android 9 updater из 3.2.6.

В Диагностике или на LAN-странице нажать «Доскачать QNX и каналы связи».
Сохранить оба прежних архива: новый ZIP содержит дополнение. Для нового полного
снимка, включая файлы с изменённым содержимым при прежнем размере, выбрать
«Повторить всё» на магнитоле или «Повторить весь QNX» на LAN-странице.
