# Natro3.3.1 /208021364 — переключение приборки и адресная диагностика

Кандидат обновления поверх3.3.0, пакет ru.natro.statuswidget, API28.
Стабильная подпись обязательна; Helper/Navigator не меняются.

Исправлены запоздавшие действия OFF при повторном ON, ограничена старая
авторизация панели, добавлены проверка владельца дисплея и симметричный DIM[0]
после mode1/readback1. Другое приложение сохраняет режим. При неизвестном владельце
панель закрывается, а неподтверждённый возврат штатного режима сообщается в UI.
Процесс Natro/HUD/ANCS не останавливается. Добавлена диагностика неподтверждённого
запуска/закрытия. [Подробности](../../geely-kx11/research-2026-10-18-wings/SWITCH_CLOSE_FIX_RU.md).

Collector принимает полный известный OEM screencap help с exit1, сохраняя
оригинальный результат в manifest. Это исправляет выбор адресных built-in PNG.
Неизвестный/усечённый ответ не разрешает угадывать display namespace.
