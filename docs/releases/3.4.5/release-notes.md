# Natro 3.4.5

Изменён порядок автозапуска Яндекс Музыки: Natro ожидает завершения подготовки
плеера перед командой воспроизведения. Появление медиасессии и истечение таймаута
сами по себе больше не разрешают преждевременный PLAY. Сохранены ограниченные
повторные попытки, отмена при ручном управлении и защита от повторных ответов.

Обновляется только Natro. Уже установленная Яндекс Музыка Natro 2 совместима;
новая сборка Музыки не требуется. Навигатор Natro 3.4.2 и Helper остаются прежними.
Прежние пакет и подпись; обновление поверх 3.4.4 без удаления приложения.

Проверены 2283 теста приложения, 285 проверок инструментов, подписи v2/v3,
точный Android API 28, версия +1 и неизменность проверенного CI payload после
подписи. Холодный запуск на ECARX ещё требует проверки. Устранение всех возможных
взаимных блокировок внутри штатного плеера не заявляется.
