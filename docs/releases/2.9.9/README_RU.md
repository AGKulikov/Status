## Проверки и ограничения

- **1906 JUnit-тестов / 374 suite**, отказов, ошибок и пропусков нет;
  **193 проверки инструментов** успешны. Отдельный профильный CI также успешен.
- Скачанный CI-архив совпал с digest GitHub. Все **1459 payload entries** unsigned APK
  сохранились после подписи; проверены CRC, 11 ключевых новых class definitions с
  class data в фактических DEX, точное совпадение трёх LAN-assets с исходниками и helper APK.
- Профильный набор: 14 проверок ADB, LAN, восстановления и селектора. ADB/Android
  зависимости моделируются test doubles; TCP, файловая система и shell исполняются реально.
- 200 гонок закрытия ADB-сеанса; отказ root не считается успехом, потеря ответа не
  вызывает повторной команды. При закрытии экрана останавливается поиск сервисных портов.
- HTTP: Host/Origin/CSRF, ограничения заголовков/длины, остановка клиентов и потоков.
  Файлы: UTF-8, квоты, traversal/symlink, обрыв и очистка только собственных partial-файлов.
- Сопряжение: срок PIN/токенов, лимит попыток/клиентов, отзыв доступа; удалённые команды
  выключены по умолчанию и никогда не выполняются из-за одной вставки текста.
- Четыре проверки финальной упаковки: точные копии/происхождение, запрет публикации
  после отказа тестов или отсутствия обязательного asset, потоковый SHA-256 на Python 3.10.
- Cloud Browser не получил доступ к локальному UI-стенду (`ERR_BLOCKED_BY_CLIENT`).
  Визуальный/browser прогон не состоялся; он не засчитывается как успешный.
- Ранние кандидаты выявили ошибки компиляции/контрактов и упаковки; они исправлены,
  проверки не отключались. Успешная компиляция сама по себе не является аппаратной приёмкой.

## Установка и первые проверки

Только на стоянке установить Natro поверх нашей 2.9.8, без удаления и очистки данных.
Navigator из комплекта 2.9.8 **не менялся**: ни его payload, ни мост Natro не затронуты;
новая сборка Navigator не требуется. iPhone Helper и HUD Speed отдельно обновлять не нужно.
В Natro добавлен отдельный WeChat-compat asset; он устанавливается только по явному
действию и не должен заменять уже установленный настоящий WeChat.

1. Открыть ADB, проверить соединение обычным `id`. Для root явно вызвать `root`,
   дождаться результата и `id -u = 0`. Наличие соединения без UID 0 не доказывает root.
2. Включить локальный обмен, открыть на iPhone показанный `http://IP:8765` и ввести PIN.
   Сначала проверить текст и небольшой файл; затем отдельно повторить в другой топологии
   (Personal Hotspot / общая Wi-Fi LAN). При изменении IP открыть новый показанный адрес.
3. В разделе режимов настроить список; в прежнем меню кнопок выбрать готовое действие
   Natro. Начать с «Показать»: автомобиль не должен переключаться при предпросмотре.
4. Перед скрытием приложений в сервисном режиме задать свой PIN, проверить разрешения
   и список исключений. Не начинать массовое скрытие до проверки пути восстановления.
   Резервный явный запуск `dezz.status.widget.SettingsHubActivity` остаётся доступен.

Сервисный режим отключает выбранные приложения через Android PackageManager; это не
ECU-диагностика, не удаление данных и не гарантия отсутствия следов. Собственный пакет
Natro не отключается; все его HOME/поверхности автоматически не останавливаются.
PIN через штатную звонилку и восстановление после OEM force-stop требуют проверки.
Никакие приложения на автомобиле в ходе разработки не отключались и команды не отправлялись.

GATE-101…106 остаются открытыми в указанных аппаратных/визуальных частях. Выпуск также
не объявляет закрытыми прежние GATE-096…100 и причины белого старта карт/системного BLE.
