# Natro 3.5.0

## Синяя табличка манёвра

Natro принимает штатные ресурсы для HUD и приборной панели от подписанных
Навигаторов 30.3.0 с модом Natro 3.4.2 и 3.4.9. Версия 3.4.9 в канале
обновлений сохранила графику и формат кадра предыдущей сборки. Установить
нужно обновление Natro.

## Недавние файлы

Откройте «Файлы» → «Недавние» в правой части верхней строки. В списке до 200
файлов из общей памяти и доступных USB/SD. Учитываются недавние загрузки,
изменения и открытия через Natro. Файлы сгруппированы по датам. Фильтр ищет
по имени. Касание открывает файл. Через ⋮ или долгое нажатие можно поделиться
файлом или перейти в его папку, где он уже выбран для копирования и других
действий.

## Установка и проверка

В Natro откройте «Обновления приложений», нажмите «Проверить обновления», затем нажмите
«Обновить» в строке Natro. Версия 3.5.0 имеет код 208021383. APK подписан
прежним сертификатом. Проверены подписи v2/v3, в том числе на точном API 28,
содержимое APK после подписи, совместимость установки поверх 3.4.9 по
метаданным и соответствие манифеста обновлений.

Пройдено 2332 тестов приложения. Проверены выбор ресурсов обоих
Навигаторов, открытие исходной папки свежего APK из «Недавних» и его выбор
для копирования. На реальном KX11 предстоит проверить появление таблички
при манёвре на обоих экранах и работу списка с подключённой флешкой.
