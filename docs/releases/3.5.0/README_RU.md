# Natro 3.5.0

Исправлен выбор ресурсов штатной таблички манёвра для подписанных Навигаторов
3.4.2 и 3.4.9. После проверки версии и подписи HUD и приборка могут использовать
те же рисунки и подписи. Обновляется Natro, код версии 208021383.

В верхней строке файлового менеджера появилась кнопка «Недавние». До 200 файлов
из общей памяти устройства и доступных локальных USB/SD упорядочены по времени
добавления, изменения или открытия через Natro. Файлы можно отфильтровать,
открыть, передать или найти в исходной папке через кнопку рядом с именем.
Скачанные на устройство файлы Яндекс Диска также участвуют в списке.

На KX11 остаётся проверить синюю табличку на фактическом манёвре на обоих
экранах и работу списка с подключением и отключением USB.
