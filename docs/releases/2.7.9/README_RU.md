# Подписанная пара Natro 2.7.9

05.09.2026. Natro **2.7.9 / 208021312** и Navigator **30.3.0 / 739564630** с нашим обновлённым
модом. Устанавливаются оба APK поверх предыдущей пары, без удаления данных: Navigator,
затем Natro. Одно обновление Natro не меняет выбор координат внутри Navigator.

Исходник: `9f2b7bd52e847ed3424ac6c7a2fe2149f20e7c9b`,
дерево: `9d8145ab4728a7bd9075665eaf1bd3fdcacdee49`.
[Успешный CI](https://github.com/AGKulikov/Status/actions/runs/33971716682):
1831 тест приложения в 364 suites, 32 проверки инструментов; ошибок и пропусков нет.
Последующая публикация добавляет только итоговые документы и статусы, исполняемые исходники
и workflow соответствуют указанному дереву CI.

В mHUD очищение медиа связано с `is_playing=false`. Когда звонок ставит музыку на паузу,
обложка, тексты и таймер скрываются; Natro использует тот же подтверждённый принцип.
Самостоятельное распознавание любого вызова по одному playback-флагу не заявляется.
Новые команды воспроизведения при завершении звонка не отправляются.

## Проверки готовых APK

- Одна стабильная подпись Natro:
  `6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.
  Natro v2/v3, Navigator v3 по действующему контракту Android 9; zipalign пройден.
- Natro сохраняет пакет `ru.natro.statuswidget`, versionCode ровно +1 относительно 2.7.8;
  оба пакета и сертификаты совместимы по метаданным с предыдущей подписанной парой.
  Физическая установка на KX11 здесь не выполнялась.
- Navigator содержит ровно classes19 из успешного CI, capability `0x7fe7` в исполняемом
  sendHello включает штатный artwork `0x4000`. Наличие вызова новой политики координат
  подтверждено по дизассемблированию нашего DEX.
- 17223 защищённых записи Navigator, в том числе resources.arsc/res и native-библиотеки,
  совпадают с закреплённым baseline. Разрешены только manifest theme, hooks classes4/classes12
  и наш classes19. Исходный APK и чужие декомпиляты в Git не публикуются.
