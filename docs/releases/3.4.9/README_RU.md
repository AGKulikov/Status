# Natro 3.4.9 — обновления приложений

Одна общая проверка и три кнопки «Обновить» для Natro, Навигатора и Музыки. Нажатие скачивает, проверяет APK и открывает Android installer. Подтверждение Android сохраняется. Отказ разрешения, отмена установщика и обрыв загрузки допускают явный повтор без автозапуска.

Navigator получает versionCode739564631 и versionName30.3.0 Natro3.4.9; код мода повторно используется из проверенного3.4.2, новый номер нужен для сравнения обновлений. MusicNatro4 прежняя. Новые независимые manifest channels должны быть опубликованы до выдачи.

SOURCE в работе; TEST/APK/PUBLISH/FIELD OPEN. Обновление на KX11 не проверено.
