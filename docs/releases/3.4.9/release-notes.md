# Natro 3.4.9 — обновления трёх приложений

Настройки → Приложение и обслуживание → Обновления приложений.
Одна общая кнопка «Проверить обновления» и по одной «Обновить» для Natro,
Навигатора и Музыки. «Обновить» скачивает APK, проверяет его и открывает
системный установщик. Отдельных кнопок скачивания и установки больше нет.
Показаны установленная/доступная версии, прогресс и ошибки каждого приложения.

После выдачи разрешения на установку операция продолжается при возврате.
Отмена установщика не вызывает его повторно; повторное нажатие использует
уже проверенный APK. После обрыва загрузки можно повторить той же кнопкой.
Проверка большого APK выполняется в фоне без блокировки интерфейса.
Никаких проверок/установок при загрузке магнитолы; подтверждение Android сохранено.

Natro устанавливается поверх3.4.8, code208021382, подпись прежняя. Для обновлений
используются только наши подписанные моды с тем же пакетом и большим versionCode.
Navigator3.4.9 получает code739564631 и versionName30.3.0 Natro3.4.9:
его код/ресурсы идентичны3.4.2, меняются только два поля версии для сравнения обновлений.
MusicNatro4 и iPhone Helper прежние. Старый Navigator3.4.2 остаётся совместим.

2325 Android-тестов и289 проверок инструментов PASS. Проверены API28, подписьv2/v3,
zipalign16KiB, install-over metadata, точное соответствие APK исходникам/CI.
Работа установщика и обновления на ECARX KX11 ещё не проверена.
