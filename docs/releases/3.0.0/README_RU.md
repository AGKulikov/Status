# Natro 3.0.0 / 208021333

Номер 3.0.0 задан пользователем 16.09.2026 вместо ещё не выпущенной 2.10.0.
VersionCode 208021333 продолжает 2.9.9 / 208021332, подпись и пакет сохраняются.
Выпуск содержит обязательную пару Natro + Navigator 30.3.0.

Изменения: сохранение живого HUD при повторном reconcile, прозрачный начальный
буфер карты, инкрементальные знаки без штатных синих placemark, поиск видимой
альтернативной ветки с предпочтением 100 м и полным временем/разницей расстояния,
временная шкала музыки с ⓘ перед названием, собственный пункт Natro для скрытия
значка/HOME с восстановлением, подавление штатных действий всех поддерживаемых
кнопок с проверкой фактического состояния patch.

[Подробный разбор изменений и критерии](../../FIELD_FIXES_2_10_0_RU.md),
[музыка и отличие от mSaver](../../MEDIA_NOTICE_MSAVER_2026_09_16_RU.md).
Зависания самого MConfig исключены из задачи по последнему указанию пользователя.

На момент переименования: локальные проверки успешны; Android-код скомпилирован,
первый CI обнаружил один устаревший source-contract (проверял удалённый комментарий),
он обновлён и дополнен исполнением сценария. Окончательная сборка под номером 3.0.0,
подпись и проверка установочной пары выполняются следующим этапом.
Аппаратные GATE-107…112 открыты. Успешная сборка не доказывает исчезновение всех
симптомов на KX11; команды на автомобиль при разработке не выполнялись.
