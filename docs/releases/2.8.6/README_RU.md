# Кандидат пары Natro 2.8.6

11.09.2026 по прямому поручению пользователя готовится Natro
**2.8.6 / 208021319** и совместимый Navigator **30.3.0 / 739564630**.
Рабочая ветка — `feature/natro-2.8.6-trip-ui-media`. Исходниковый commit
`1c70ca3cb73db221eb853523ae0ffc0598a98738`, дерево
`ea6136a400d11e4cf11f64d9110b4d7fc3adc8f6`. Обычные CI-прогоны
`34612692293` (специализированный 2.8.6) и `34612692371` / run 268
(общий Navigator HUD v2) завершены успешно. Подпись и готовые APK будут внесены
только после фактической защищённой проверки. Аппаратные критерии KX11 остаются
открытыми.

## Что исправлено

- `NATRO-024`: ошибочные PA-поля 2.8.5 полностью исключены. Пробег Trip 2 читается
  из `DstTrvld2`, средняя скорость и её единица — из штатных приборных CarSignal.
  Время выводится из той же свежей пары завершёнными минутами; эталон пользователя
  `17,4 км / 24 км/ч` даёт `00:43`. Стабильные ID элементов сохранены.
- `CARD-025`: кэш автоширины/автовысоты зависит от фактического размерообразующего
  содержимого, поэтому карточка HUD и приборки не только уменьшается, но и снова растёт.
  Изменение одной скорости не вызывает лишний layout.
- `MAP-059`: полилиния каждой валидной альтернативы создаётся независимо от выноски.
  Неполные fork/name/delta данные больше не скрывают линию; выноска использует доступную
  точку и резервный текст `Вариант N`. Ошибка регионального `hide(Subpolyline)` сохраняет
  полную линию.
- `MUSIC-014`: новый key press не становится за Binder проигрывателя, зависшим дольше
  750 мс, а возвращается штатному Android media dispatcher; stale route обновляется.
  Active sessions дополнительно сверяются раз в 2 минуты на resolver-потоке.
- `NATRO-023`: без снижения разрешения, FPS, сглаживания, частоты данных или состава
  слоёв убраны snapshot-identity layout churn, синхронный boot preference fsync и
  PackageManager/icon work из `AppsAdapter.getView`.
