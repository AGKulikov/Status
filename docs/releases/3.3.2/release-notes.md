# Natro 3.3.2 / 208021365

Обновление поверх Natro 3.3.1 с прежней подписью. Navigator и iPhone Helper переустанавливать не требуется.

В выпуск включены:
- запуск собственной панели приборки через публичный API одного пакета запусков: этот путь в предоставленной прошивке не вызывает пакетный OEM-преддиалог переноса;
- ожидание завершения закрытия собственной панели и повторная проверка владельца экрана по полному свежему ответу;
- ограниченное число повторов при переходном состоянии, отмена старого выключения новым включением;
- сохранение процесса Natro и задачи настроек; чужая задача не закрывается, неизвестный владелец не считается свободным;
- миграция прежних defaults с сохранением пользовательских значений.

Проверки: 2189 Android-тестов без ошибок и пропусков; полный набор проверок инструментов прошёл в CI. Подтверждены происхождение APK, прежний сертификат, v2/v3, Android 9/API 28, выравнивание, версия/пакет и метаданные установки поверх 3.3.1. Содержимое подписанного APK совпадает с проверенным кандидатом.
