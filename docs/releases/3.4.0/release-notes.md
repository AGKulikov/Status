# Natro3.4.0

Файловый менеджер: две панели, память устройства и USB/SD, копирование,
перенос, переименование, удаление, поиск, сортировка, закладки и ZIP.
Подключение Яндекс Диска через аккаунт: скачивание и загрузка файлов/папок,
публичные ссылки. При совпадении имён сохраняются оба файла.

Открыть: Настройки → Телефон и обмен → Файловый менеджер.
Можно добавить встроенный ярлык в лаунчер или панель.
Устанавливать поверх предыдущего Natro, без удаления данных.
Navigator и Helper для этой функции переустанавливать не требуется.
Реальный вход, USB и работа на KX11 ещё требуют проверки.
