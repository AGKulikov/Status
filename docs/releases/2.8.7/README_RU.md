# Кандидат Natro 2.8.7

11.09.2026 по прямому поручению пользователя готовится Natro
**2.8.7 / 208021320** и совместимый Navigator **30.3.0 / 739564630**.
Рабочая ветка — `feature/natro-2.8.7-map-bootstrap-reader`. Этот документ пока
фиксирует только состав исходного кандидата: commit, CI, подпись и SHA-256 APK будут
добавлены после фактической проверки. Аппаратные критерии `GATE-080/081` открыты.

## Что исправлено

- `NAV-017`: HUD и приборная панель больше не считают сам
  `onSurfaceTextureUpdated()` доказательством готовности карты. Пока `TextureView`
  скрыт, Natro читает уменьшенный образец текущего producer-буфера и не показывает
  однородный белый bootstrap-кадр Android 9/KX11. Проверка применяется независимо к
  обеим картам и прекращается после первого содержательного кадра.
- `NATRO-025`: неизменившиеся списки полос, светофоров, участков пробок и дорожных
  указателей больше не оборачиваются повторно на каждом 10-Гц снимке навигации.
  Одна неизменяемая копия переиспользуется по identity, поэтому цепочка делегатов
  `UnmodifiableCollection.isEmpty()` не растёт и не переполняет стек reader-потока.

## Доказательства и границы проверки

| Требование | Проверка исходника | KX11 |
|---|---|---|
| NAV-017 | pixel-policy для белого bootstrap и одинаковый gate в HUD/приборке | GATE-080 открыт |
| NATRO-025 | 20 000 одинаковых snapshot и identity-reuse четырёх непустых списков | GATE-081 открыт |

рекурсивный путь и в опубликованном дереве 2.8.6.

## Сборка и подпись

Ожидаемый сертификат обоих APK — прежний общий SHA-256
`6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.
До завершения обычного и защищённого CI здесь намеренно нет номера запуска, commit,
дерева, SHA-256 APK или заявления о готовой подписи. Выпуск проверит package/version,
min/target SDK 28, ABI-neutral Natro, v2/v3, одного подписанта, CRC, zipalign, точный
Navigator baseline и строго возрастающий `versionCode`.

Успешные unit/static-тесты не доказывают отсутствие свечения и падения на физической
KX11. Для аппаратной приёмки нужны покадровые холодные запуски обеих карт по
`GATE-080` и два 30-минутных навигационных прогона по `GATE-081`.
