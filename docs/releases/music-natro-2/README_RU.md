## Установка и приёмка

Обновляется только мод Музыки: `Yandex-Music-2026.10.2-Natro-2-signed.apk`,
package `ru.yandex.music`, versionCode `24026523`, versionName
`2026.10.2 #169gpr Natro 2`. Установленные Natro 3.4.4 и Navigator Natro 3.4.2
подходят: протокол prepare_v1 не меняется. Helper также не меняется.

Предыдущая Natro 1 проверяется по pinned SHA256
`0ff7d3fceb0a7abb12f98917dcf9f649996368b6c2c23c8fa9b6725fba5ab371`.
Новая версия должна устанавливаться поверх неё без удаления приложения или данных;
фактическая установка на магнитоле ещё не проверена. Это не утверждение
совместимости с исходной Музыкой, подписанной другим сертификатом.

После обновления проверить два холодных запуска: получение token, адресный PLAY
после заданной задержки и устойчивое состояние PLAYING. UI Музыки не должен
сам открываться; ручная пауза и разрешения Natro сохраняют приоритет.
Архив диагностики должен отличать отсутствие кандидатов от отказа подключения.
Компиляция и подпись не подтверждают устранение дефекта на магнитоле.
