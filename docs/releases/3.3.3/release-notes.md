# Natro 3.3.3 — запись обмена DIM

Добавлена непрерывная запись существующего журнала DIM: явные запуск и остановка,
сохранение полученных данных при обрыве связи и выгрузка после перезагрузки.
В разделе диагностики выберите «Запись обмена DIM: начать / остановить».
После воспроизведения остановите запись и нажмите «Выгрузить сохранённые записи DIM».
После перезагрузки запись сама не возобновляется; сохранённое можно выгрузить.
Лимиты:20минут или64МиБ на запись, до3записей. Старые записи удаляются только явно.
Проверку выполняйте на стоянке, ZIP передавайте лично.

Обновление поверх3.3.2 с прежним пакетом и подписью; данные приложения сохраняются.
Navigator и iPhone Helper менять не требуется (DEX совпал с предыдущим выпуском).
Это диагностическое обновление. Независимое скрытие крыльев ещё не реализовано.
