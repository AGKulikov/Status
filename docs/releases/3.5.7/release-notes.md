# Natro 3.5.7 и Навигатор 30.3.0 Natro 3.5.7

Изменена передача видимости подсказки между закреплённой карточкой и знаком у манёвра. HUD и приборка принимают решение отдельно: текущая карточка сохраняется, пока на конкретном экране не готова замена для того же манёвра. Соседний знак полос и другой поворот не считаются заменой.

Обновления расстояния больше не отменяют незавершённую актуальную загрузку изображения. При смене текстуры сохраняется предыдущая подтверждённая подсказка. Размещение учитывает полную площадь изображения и границы экрана; при недоступной проекции остаётся закреплённая карточка.

Добавлены отдельные диагностические события источника и готовности знака для HUD и приборки.

Обновить нужно оба приложения: сначала Natro, затем Навигатор. Используется прежний сертификат; версия подготовлена для установки поверх 3.5.6 с сохранением настроек.

Исходники: `d7d22321ff68c49d5f1da52db08ce94c568a9679`, дерево `93e14a98832b7cb07cd05604807c08d9a28a146e`.

Проверка на реальном ECARX KX11 остаётся открытой. Старый журнал не позволяет установить точную причину конкретного кадра. Маршрутная привязка по-прежнему требует свежего подтверждения штатной таблички на основной карте; при его отсутствии сохраняется текущая закреплённая подсказка.
