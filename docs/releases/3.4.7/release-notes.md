# Natro 3.4.7 — запуск музыки после задержки и подключения Wi-Fi

После заданной задержки Natro проверяет подключение Wi-Fi. Если его нет,
ожидает подключение и запускает музыку без повторного отсчёта задержки.
Ожидание не расходует попытки запуска. Ручное управление отменяет ожидающий запуск.
Проверяется подключение Wi-Fi, а не доступность интернета. При отсутствии Wi-Fi автозапуск ждёт.

Установка поверх Natro3.4.6 без удаления. Музыка Natro3, Navigator3.4.2 и Helper прежние.
