# Natro 3.3.8 — Алиса и восстановление автозапуска

- Вызов Алисы передаётся адресным `dd.call_alice` в новый приёмник нашего Навигатора. Работающий Навигатор сохраняет фон/окно; обычный запуск разрешён только после подтверждения отсутствия процесса.
- Если до вызова играла музыка, Natro запоминает её сессию и запрашивает PLAY через 2 секунды после подтверждённого закрытия диалога Алисы. Исходная пауза, ручное управление или другой уже играющий плеер не запускают старую музыку.
- При загрузке музыка получает ограниченные повторные команды, если запасной MediaBrowser недоступен. Сервис ищется только среди разрешённых компонентов установленного ru.yandex.music.
- HOME сохраняет ограниченное наблюдение за запуском Навигатора при временном уходе с экрана и может повторить неудавшийся запуск после возврата фокуса.
- Исправлена совместимость восстановления резервных копий 3.3.7 в 3.3.8.

Для новой функции Алисы установите оба APK: Natro 3.3.8 и парный Navigator-30.3.0-Natro-3.3.8. Navigator передаётся пользователю приватно; Helper прежний.

В журнале 3.3.7 подтверждены ANR/завершение процесса Навигатора и недоступность запасного музыкального сервиса. Стек ANR отсутствует, его первопричина не установлена. Реальный холодный старт, голос в фоне, сохранение окна и возобновление звука через 2 секунды требуют проверки на ECARX KX11; автоматические тесты не являются аппаратной приёмкой.
