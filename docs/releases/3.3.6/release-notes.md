# Natro 3.3.6 — назначения медиакнопок

В «Кнопки → MEDIA» для «Предыдущий трек», «Пуск / пауза» и «Следующий трек»
добавлены назначения на одиночное, двойное, тройное и длительное нажатие.
Используются те же действия и сохранение настроек, что у остальных кнопок.

Для новых назначений включите MEDIA и «Отключить действие по умолчанию».
Окно серии — 600 мс. Удержание распознаётся от 1 секунды; фактический отклик
зависит от подтверждения штатной прошивки. Без новых назначений сохраняется
прежняя обработка. После длинного короткое действие не выполняется.

Устанавливайте поверх 3.3.5 без удаления Natro. Переустанавливать Navigator
и iPhone Helper для этого изменения не требуется.

Работа жестов на магнитоле, длительные сессии, звонки и сохранение настроек
при физическом обновлении ещё требуют проверки на KX11.

2194 Android-теста и 279 дополнительных тестов прошли без ошибок и пропусков.
Прежняя подпись v2/v3/API 28, код версии +1 и точный payload CI проверены.
