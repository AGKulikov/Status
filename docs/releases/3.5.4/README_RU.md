# Natro / Навигатор 3.5.4

Natro: `ru.natro.statuswidget`, версия 3.5.4, код 208021387.
Навигатор: `ru.yandex.yandexnavi`, версия 30.3.0 Natro 3.5.4, код 739564635.
Обновляются оба приложения поверх 3.5.3, прежним ключом. Музыка и Helper прежние.

## Исправления

- Подтверждённая табличка сохраняется при смене метров/текстуры того же штатного
  объекта. Новый объект, маршрут, проезд и неоднозначность не наследуют привязку.
- Проверка изображения учитывает измеренное движение карты между запросом и
  callback. Все конкурирующие точки участвуют; поиск ограничен 24 физическими
  пикселями и суммарными 512 Ki pixels. Один пропуск кадра или ошибка PixelCopy
  не снимает знак. Два подтверждённых отсутствия снимают; старое подтверждение
  не живёт более 1500 мс, timeout отдельного захвата — 900 мс.
- Новое изображение загружается в скрытый placemark; старое остаётся до готовности
  новой текстуры. Поздний callback после очистки или истечения срока игнорируется.
- Оба штатных вида — объединённый с полосами и отдельный — используют общий
  профиль фона, текста/стрелок, рамки, углов и масштаба соответствующего экрана.
  Цветные DirectionSignView сохраняют свой цвет.
- Native draw commands записываются в Picture и выводятся сразу в целевом размере.
  Масштаб основного экрана не умножается повторно; готовый bitmap не увеличивается.
- Natro принимает проверенные ресурсы Navigator 739564635 и копии до 3.5.3.
  Системные права и автоматический bootstrap соответствуют 3.5.3/3.5.0.

## Проверка в автомобиле

Маршрут с двумя близкими поворотами: проверить смену метров, переход из верхнего
угла к повороту и обратно, проезд, пересчёт и отмену. Сравнить табличку с полосами
и без полос при 50/100/150/250% и разных профилях HUD/приборки; затем вернуть
исходные настройки. Общие настройки находятся в существующем редакторе полос.
При скрытом основном окне новая привязка не создаётся — исходная карта нужна
для точного подтверждения места штатной таблички. Это ограничение сохранено.
