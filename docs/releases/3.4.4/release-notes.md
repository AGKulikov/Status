# Natro 3.4.4

Исправлена блокировка повторной подготовки Яндекс Музыки после истечения первого запроса. Холодный запуск процесса и подготовка медиасессии получают отдельные сроки внутри общего ограниченного ожидания. Повторы ограничены; ручное управление отменяет автоматическое воспроизведение, поздние и повторные ответы не должны давать дополнительный PLAY.

Восстановление Навигатора проверяется сразу после получения свежего состояния окна, а не только по секундному таймеру. Сохраняются ограничения по активности лаунчера, отсутствию окна, ручному вмешательству и числу попыток. Добавлены причины ожидания и отмены в журнал.

Прежняя подпись и пакет Natro; обновление поверх3.4.3. Уже установленные Navigator3.4.2, мод Музыки и Helper менять не требуется. Исправления проверены сборкой и тестами; холодный запуск на ECARX требует проверки. Причина задержек диска внутри запуска штатных библиотек Навигатора не объявляется устранённой.
