# Natro 3.2.0 / 208021353

Расширенный сбор для поиска владельца крыльев и контейнера навигации.

- Полные SurfaceFlinger и окна Android до/после сбора, до1МиБ на вывод.
- Существующие графические slog2 QNX: динамические PID, до12 файлов,
  1МиБ на файл и8МиБ суммарно; только чтение, без запуска logger/export adapter.
- Трассировка блоков proc: смещение, размер запроса/ответа, SHA256 и control reply.
- Частичные файлы сохраняются с причинами отказа/усечения; живые snapshots
  не считаются атомарными. Неверные mappings отмечаются read_content_invalid.

Как собрать: обновить Natro поверх3.1.9, открыть диагностику → дамп системных
файлов, выбрать фактическое состояние приборки и выполнить сбор. Сохранить ZIP
и записать, видны ли крылья в этот момент. Для сравнения полезны отдельные сборы
в штатном режиме и в режиме навигации на стоящем автомобиле.

Владелец крыльев и первопричина порчи mappings пока не установлены. Этот выпуск
расширяет наблюдение; исправление отрисовки крыльев не заявляется.

Статус:12 локальных host tests прошли; Android CI, подпись и install-over
проверяются перед выдачей APK. FIELD на KX11 остаётся OPEN.
Navigator/Helper не менялись.
