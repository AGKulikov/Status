## Что изменено

- **MEDIA:** раздел «Автоматизация → Кнопки руля · MEDIA». Два независимых переключателя,
  исходные DOWN/UP/repeat, AudioManager и системный выбор Android-плеера — по выбранной
  вкладке оригинального MConfig+ v46.1. Отдельный NEDIA адрес исключает параллельный
  IEDIA bridge оставшегося установленным MConfig. Новые функции по умолчанию выключены.
  Это не перенос назначений остальных вкладок SRC / WeChat, *, VA.
- **Панель приборов → Штатные элементы:** скрытие штатного знака ограничения скорости
  через TSR и белой полосы через условный AppOp dimmenu в режиме навигации. Есть
  подтверждение системным чтением и восстановление при выключении. TSR меняет штатную
  настройку; AppOp затрагивает наложения dimmenu, а не рисует маску поверх экрана.
- **Альтернативы:** проверка пересечений использует тело таблички. Общий конец хвостика
  и прозрачное поле больше не отклоняют все восемь положений у знака полос/светофора.
  Штатный текст, точка развилки, viewport и нативные collision rules MapKit сохранены.
  Журнал различает создание, blocked и submitted; последнее не является pixel ACK.

## Как сравнить без компьютера

1. В MConfig отключить оба переключателя MEDIA и соответствующие две штатные настройки
   перед включением их в Natro. Не оставлять два активных владельца одной функции.
2. В Natro для обычного Android-плеера включить «Включить» и «Отключить действие по
   умолчанию». «Штатный источник SRC» оставить выключенным. Дождаться результата
   применения; настройка использует встроенный привилегированный канал Natro.
3. Новые настройки приборки включать отдельно и проверять их выключение. При скрытии
   белой полосы сравнить навигацию и выход из неё; TSR проверять по реальному экрану.
4. В привычных условиях навигации сравнить реакцию MEDIA в течение не менее 30 минут.
   Если задержка повторяется, после остановки экспортировать журнал и отметить время.
   Сам факт переноса MEDIA не доказывает виновность MConfig и не исключает нагрузку Navigator.
5. Сравнить альтернативы на основном экране, приборке и HUD: «То же время», быстрее,
   медленнее, несколько развилок/масштабов. После сбоя передать фото обоих экранов и журнал.
