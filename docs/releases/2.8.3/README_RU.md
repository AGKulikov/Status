# Подписанная пара Natro 2.8.3

08.09.2026 пользователь прямо поручил пересобрать новую пару с подготовленными изменениями.
Собраны и подписаны Natro **2.8.3 / 208021316** и Navigator **30.3.0 / 739564630**.
Установка — поверх наших приложений без удаления и очистки данных: сначала Navigator
этой пары, затем Natro. Метаданные обновления проверены; установка на KX11 пока не подтверждена.

## Что входит

- ANCS-014: закрытый канал на этапе STARTING переводится в существующее восстановление
  через освобождение владельца GATT, drain и новую эпоху. Проверены потеря Bluetooth
  во время подключения и его возврат до/после terminal, ручной повтор и поздние callbacks.
- В начало журнала ANCS добавлены версия и код Natro из BuildConfig.
- Сохранены изменения 2.8.2: запуск всей приборки без завершения Natro, восстановление
  реального окна, оформление исходных синей таблички и знака полос, визуальные палитры.
- Navigator собран заново с тем же функциональным кодом, что в 2.8.2. К прежней
  подписи v3 добавлена v2, тем же стабильным ключом. Это совместимость упаковки,
  а не установленная причина пользовательского отказа.

## Что остаётся непроверенным

Пользователь подтвердил, что на магнитоле установлен Navigator из пары 2.8.1 и открывался
основной APK 2.8.2. Присланный файл цел и совпадает с выпущенным; подпись и метаданные
совпадают с сохранённой 2.8.1. Точные DEX обеих версий прошли ART verifier API 28.
Причина сообщения «Приложение не установлено» **не установлена**; новая упаковка не
объявляется её исправлением. Установка поверх на KX11 требует проверки пользователя.

GATE-061 (восстановление ANCS на устройстве), первичные ошибки C4/Helper/GATT 133,
GATE-043/059/060 и прежние аппаратные критерии остаются открытыми. Helper 70 не меняется.
Версия Natro увеличена ровно на 1 относительно 2.8.2; пакет и стабильный сертификат
сохраняются. Оригинальные APK, сторонние исходники и ключи в публичный Git не помещаются.
