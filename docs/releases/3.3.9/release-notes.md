# Natro 3.3.9 — исправление вызова Алисы

Исправлена передача обратного канала между Natro и Навигатором: отправляется
стандартный Android ResultReceiver вместо подкласса, которого нет в другом APK.
Добавлена защита приёмника Навигатора от некорректных данных команды.

Установите Natro3.3.9 и парный Navigator30.3.0-Natro3.3.9 поверх прежних версий,
без удаления приложений. Navigator передаётся отдельно, не входит в публичный
релиз. Helper обновлять не нужно. Прежняя подпись и настройки сохраняются.

Требуемая логика сохранена: работающий Навигатор не переносится из фона/окна;
запуск допускается только при подтверждённом отсутствии процесса. Музыка,
игравшая до вызова, возобновляется через2секунды после подтверждённого закрытия
диалога; ручное управление отменяет продолжение.

API28 тесты воспроизводят отказ старого callback и проверяют чтение нового
другим загрузчиком классов, возврат событий, отказ malformed command.
Аппаратная проверка голоса, фона/окна, finish+2s и холодного запуска остаётся
открытой. Стек прежнего завершения Навигатора в пользовательском архиве
отсутствует; исправление IPC не объявляется устранением всех native ANR.
