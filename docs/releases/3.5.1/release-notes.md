# Natro 3.5.1

В «Файлы» → «Недавние» свежие загрузки и документы теперь видны среди изменений за 31 день. Служебные JSON и базы данных отсеиваются. По умолчанию включены изображения, видео, музыка, APK, архивы, Word, Excel, PowerPoint и PDF. TXT и «Другие документы» можно включить через «Типы файлов». Выбор сохраняется.

Карточка показывает папку, тип и общее число файлов. Например, восемь снимков из одной папки за одну минуту дадут карточку с четырьмя миниатюрами. Нажмите заголовок, чтобы открыть все восемь. Поиск работает и по файлам за пределами предпросмотра. Через меню файла можно перейти в исходную папку, где файл будет выбран.

Для синей таблички у поворота на приборке и HUD нужна пара Natro 3.5.1 и Навигатор 30.3.0 Natro 3.5.1. Обновление Навигатора имеет отдельную строку в разделе «Обновления приложений».
