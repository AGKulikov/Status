# Навигатор 30.3.0 Natro 3.5.1

Когда основной Навигатор переносит синюю табличку из верхнего угла к повороту, мод проверяет её изображение на карте и переносит к тому же месту на приборке и HUD. На объединённой табличке сохраняются штатные стрелки, расстояние и название улицы. Пока она видна, короткий знак полос у этого манёвра скрывается. Указание полос для другого перекрёстка сохраняется. Для переноса требуется открытая и видимая основная карта Навигатора с табличкой целиком в кадре.

Для обновления нужны Навигатор 30.3.0 Natro 3.5.1 и Natro 3.5.1. Работу перехода между режимами на ECARX KX11 предстоит подтвердить в поездке.
