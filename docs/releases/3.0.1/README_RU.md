# Natro 3.0.1 / 208021334

Исправления по вечернему журналу 16.09.2026 и поручению «Давай, исправляй все что нашел».
Настройки и резервное копирование остаются отдельной, отложенной задачей.

* Кнопки подписываются раньше, независимо от готовности интерфейса. Сохранённые
  маршруты MEDIA/SRC, VA, DM и POWER восстанавливаются одной транзакцией с одним
  запросом перезапуска XSF. Ошибка одного маршрута не отменяет остальные.
* Частые изменения состояния объединяются и сохраняются через commit в отдельной
  очереди, без apply-finisher на главном потоке. Просроченная команда селектора
  отбрасывается после очереди UI/сервиса и до изменения режима автомобиля.
* Скрытие штатной полосы использует актуальный getNaviMode непосредственно перед
  выполнением команды. Серия уведомлений не отодвигает проверку бесконечно;
  readback AppOp каждые 5 секунд выявляет внешний сброс разрешения. При реальном
  выходе из режима навигации штатное разрешение восстанавливается.
* Первый показ карты имеет отдельную защиту от практически сплошного непрозрачного
  белого кадра: минимум 200 мс, две разные метки кадра одной Surface, анализ малого
  образца. Независимый предел 800 мс раскрывает поверхность при отказе или зависании
  PixelCopy. Нет ожидания тайлов/ACK, уже показанная карта повторно не скрывается.
* Добавлены три native broadcast-маршрута VA из ранее предоставленного XSF APK.
  Новый вариант разрешён только при точном SHA-256 системного APK, полном наборе
  маршрутов и идентифицированном классе. Неизвестная прошивка не патчится этим
  вариантом; прежние варианты сохранены. Подробности в технической базе KX11.
