# Подписанная пара Natro 2.8.0

05.09.2026. Natro **2.8.0 / 208021313**, совместимый Navigator **30.3.0 / 739564630**.
Обновляются оба APK поверх 2.7.9, без удаления данных: сначала Navigator, затем Natro.
Фильтр событий и обновление штатного artwork находятся внутри мода Navigator;
одно обновление Natro этих изменений не устанавливает.

Исполняемый исходник `4fc148925e66d0c8e019e29fc8cf06bff4c80762`,
дерево `782ab3a68c0a85626313d0d14fd0b49b1bb87db8`.
[Успешный CI](https://github.com/AGKulikov/Status/actions/runs/33978715779):
1836 тестов приложения в 365 suites и 42 проверки инструментов, без ошибок/пропусков.
Итоговая публикация меняет только документы/статусы, код и workflow совпадают с деревом CI.

## Изменения

| Требование | Изменение | Проверка | KX11 |
|---|---|---|---|
| MAP-014/053 | ROUTE_ONLY проверяет native isOnRoute каждого события; настройки и кэш стилей разделены по MapWindow | 5 replay через production StyleProvider: соседняя дорога, два профиля, live edit, конец маршрута, mixed tags | GATE-057 открыт |
| CARD-016 | Artwork сравнивается по реальным пикселям, изменение внутри того же Drawable обновляет bitmap/revision | 5 replay ownership/cache; вызов capture/sameAs проверен в DEX | GATE-055/041 открыты |
| NATRO-019 | Один виджет «Поворотники», две стрелки в общей рамке и общей фазе мигания | 4 проверки видимости/фаз + сериализация нового и старых типов; общий Android CI | GATE-056 открыт |

Поворотники добавляются через «Добавить на HUD → Автомобиль · Поворотники». Ширина общей
области раздвигает стрелки, высота задаёт размер. Старые отдельные элементы не удалены из
сохранённых раскладок: после размещения общей пары их можно убрать в редакторе.

На IMG_8290 дефект виден на приборке; отсутствие значков на HUD могло зависеть от масштаба,
но это не доказано. Штатный фильтр общий, профили независимы. HUD Speed имеет собственное
включение и payload без native membership Яндекса; источник каждой камеры на фото не
установлен. Полная аппаратная проверка обоих источников остаётся открытой. Если standalone
MapKit не помечает реальное маршрутное событие, его исчезновение также считается провалом
GATE-057. Возврата аварийного Automotive NavigationLayer нет.

На IMG_8288 неполная стрелка; разница дистанций двух фотографий по уточнению пользователя
не является ошибкой. Обновлён доказанный дефект кэша, но причинность конкретного снимка
требует сравнения реального штатного ImageView и HUD. Самостоятельно стрелка не дорисовывается.
