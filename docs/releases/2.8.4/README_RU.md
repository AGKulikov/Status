# Подписанная пара Natro 2.8.4

10.09.2026 по прямой команде пользователя собраны и подписаны Natro
**2.8.4 / 208021317** и совместимый Navigator **30.3.0 / 739564630**.
Установка выполняется поверх нашей предыдущей пары без удаления приложений и данных:
сначала Navigator этой пары, затем Natro. Метаданные обновления и общий сертификат
проверены; установка и визуальная приёмка на физическом KX11 пока не подтверждены.

## Что входит

- CARD-021: независимые цвета дополнительной области синей карточки и фиксированные
  размеры шрифта улицы, номера съезда/указателя и дополнительной информации. При тесной
  компоновке уменьшаются знак и промежуток, а не выбранный размер текста.
- MAP-055: отдельный отключаемый слой альтернативных маршрутов для HUD и приборки.
  Он выводит дополнительные полилинии и выносные таблички с дельтами времени/расстояния;
  их цвета берутся из живого оформления Navigator. Цвет/толщина линии, геометрия, фон,
  обводка и текст таблички настраиваются раздельно, а размещение участвует в общей системе
  коллизий знаков и не скрывает саму полилинию.
- MAP-053/056: точный положительный список дорожных событий активного маршрута и отдельный
  режим названий улиц только по геометрии его полилинии, независимо для HUD и приборки.
- CLUSTER-025/026: отдельная синяя карточка и остальные независимые навигационные элементы
  доступны в каталоге приборки; включение, перенос, повторное открытие и выключение панели
  имеют симметричную границу поколения по модели mNavi.
- NATRO-021: в HUD и приборке добавлены независимые пробег, длительность, средний расход
  и средняя скорость именно текущей поездки с общей политикой свежести.
- MUSIC-013: медиакнопки режима MConfig обслуживаются отдельными ограниченными очередями
  приёма, команды MediaSession и диагностики; просроченные команды и старое поколение
  отбрасываются.

## Проверка выпуска

Исполняемый исходник `6f79db61fc9c2bcc0b4be07d61c3eda296f8c4ca`, дерево
`2790aba52e74447d45e6de6c9051a2022b67927c`.
[CI 34438474171](https://github.com/AGKulikov/Status/actions/runs/34438474171)
успешен: **1 874 теста приложения** в 368 наборах и **51 проверка инструментов**,
без ошибок и пропусков. SHA-256 архива CI и все 387 файлов его контрольного манифеста
проверены. Подписаны точный Natro APK и `classes19.dex` из этого запуска.

У обоих APK один прежний сертификат SHA-256:
`6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`.
Для Natro отдельно проверены v2 на API 24–27 и v3 на API 28; для Navigator — v2 на
API 26–27 и v3 на API 28. В каждом случае подписант ровно один. Оба APK прошли
16-КиБ `zipalign`; архив Navigator прошёл полную проверку CRC.

Natro сохраняет пакет `ru.natro.statuswidget`, label `Natro`, min/target API 28,
ABI-нейтральность и увеличивает versionCode предыдущей 2.8.3 ровно на один.
Navigator сохраняет пакет `ru.yandex.yandexnavi`, versionName 30.3.0, versionCode
739564630, min/target API 26/29 и ABI arm64-v8a.

Все **17 222 защищённые записи** оригинального Navigator сохранены побайтно. Относительно
подписанного Navigator пары 2.8.3 изменился только payload `classes19.dex`; остальные
**17 226 общих ZIP-payload** совпадают. Встроенный `classes19.dex` точно совпадает с CI
(`576b0047e697a2659684a76c4be78b802f15acec473995562e972b18ff105dfb`).
Проверка пары подтверждает hello `0xbfe7`, обязательную capability `0x8000`, schema 1,
14 штатных обёрток карточки и новые маршруты карты.
