## Причины и локальные изменения

| Узел | Дефект | Изменение / границы |
|---|---|---|
| MapFirstFrameDetector + обе TextureView | Пустой прозрачный/тёмный кадр проходил pixel-only gate, а последующие кадры не проверялись | ACK настроенной карты с render objects, текущая сессия/generation, три последовательные проверки содержимого. Однородные и плавные нейтральные загрузочные буферы отклоняются. Resize снова закрывает gate. |
| HudMapRenderer / IPC | Callback поверхности не доказывал готовность MapKit | MapLoadedListener привязан к конкретному map object/generation и удерживается до teardown. Сообщения 21/22, capability 0x10000. Старый Navigator без capability не получает новые leases; в журнале явное требование обновить пару. |
| Камеры | Windshield active-list ограничивал видимость следующих объектов; существовал дополнительный лимит 32 | DrivingRoute.getEvents — инвентарь всех маршрутных контролей; Windshield только обогащает совпавшие ID. Проверяются диапазон и прогресс по сегменту; убраны лимиты 8/32 для маршрутного источника. Внешний IPC остаётся ограниченным. |
| Дубли и режимы событий | Разные близкие ID сливались; включение speed-control скрывало весь набор штатных тегов | Same-source слияние только по непустому ID, cross-source один-к-одному. Индивидуальные режимы тегов применяются к custom-слою; native ALWAYS вне маршрута сохраняется, при отсутствии инвентаря сохраняется native fallback. |
| Альтернативы | Собственные имя/дистанция, округление, произвольный fallback-якорь, общий префикс при неуспешном hide, принудительный конфликт | Валидация обеих fork positions на конкретных route ID; никакой привязки к четверти полилинии. | Хвост светофора | Дополнительная независимо рассчитанная ножка поверх stock/fallback-текстуры | Одна текстура со штатным anchor; stock уже содержит свою ножку. Fallback объединяет тело/хвост по реальному кругу без таймера либо pill с таймером; 0 секунд не приравниваются к отсутствию таймера. |
| Другие дополнения | Старый frame мог использоваться при смене route epoch; соседний plain-светофор скрывался по близости 24 м | Старые live-светофоры/камеры/полосы/стрелки очищаются перед новым кадром; renderer отвергает другую epoch. Известная несовпадающая позиция светофора не заменяется проверкой близости. |

## Открытые границы

1. Поддерживаемый источник именно штатной «Поездки 2» и его единицы не установлен.
   Повторный просмотр interfaces-0004/0014 подтвердил: не только DstTrvld2 30878, но
   и average 30957, unit 30956 каждый имеют 10 экспортов / 10 событий / 0 изменений,
   только raw=-1. Диагностика теперь отдельно сохраняет строку unit 30956 даже при
   отсутствии sample. Совпадение примера 17,4/24→00:43
   не доказывает ни источник, ни точное время из округлённой средней скорости.
2. Полное совпадение штатного содержимого альтернативы и нашей компоновки проверяется
   синхронно на KX11, включая разные типы значков, day/night и «то же время».
   Статическая проверка baseline и API-shape replay не заменяют этот результат.
3. Нет аппаратной приёмки GATE-082…086: проверить отсутствие вспышки **и появление
   самой карты**, все последующие камеры, геометрию/коллизии и поездку на KX11.
