# Natro 2.5.9: слои карты, маршрутный блок и камеры HUD Speed

## Автоматическое разрешение наложений

- Пользовательский HUD и карта панели приборов теперь создают отдельные корневые слои MapKit,
  а не дочерние коллекции без разрешения конфликтов.
- По умолчанию включён автоматический режим: порядок внутренних слоёв Яндекса не изменяется,
  а пользовательские объекты используют нативные режимы `MINOR`, `EQUAL`, `MAJOR` и `IGNORE`.
  Знак движения по полосам и курсор имеют обязательный приоритет, подпись улицы может быть
  скрыта, если места недостаточно, камеры и светофоры взаимно разводятся движком MapKit.
- Переключатель «Ручной порядок слоёв» включает сохранённые ползунки приоритетов. Большее
  значение располагает слой выше. При выключении ручного режима независимое окно MapKit
  пересоздаётся, поэтому полностью восстанавливается внутренний сценарий слоёв Яндекса.
- В ручной порядок включены камеры, остальные дорожные события, маршрут, конечная точка,
  светофоры с секундами, названия улиц на маршруте, знаки движения по полосам и курсор.

## Размеры и оформление карты

Для HUD и панели приборов независимо сохраняются размеры:

- курсора;
- знаков движения по полосам;
- камер и их информационных значков;
- светофоров и плашки секунд;
- названий улиц на маршруте;
- остальных дорожных событий;
- конечной точки маршрута;
- толщины маршрута и улиц без маршрута.

Светофоры формируются штатным `TrafficLightViewImpl` Яндекс Навигатора. Знаки движения по
полосам формируются штатным `LaneSignBalloon`, поэтому направления и подсветка полос берутся
из исходного объекта Яндекса. Названия улиц привязаны к проверенным точкам активного маршрута.

## Камеры Яндекса и HUD Speed

- Natro может читать ограниченный список уже загруженных в память камер из предоставленной
  сборки HUD Speed 76.0-L13 через отдельный read-only Messenger-сервис.
- Обе стороны проверяют точный пакет, UID и сертификат. База камер, учётные данные, лицензия и
  настройки HUD Speed не экспортируются.
- Камеры HUD Speed имеют отдельный фиолетово-жёлтый знак и выигрывают при объединении близких
  дублей с камерой Яндекса.
- Скорость и дополнительные виды контроля показываются только тогда, когда соответствующий
  источник их передал. Направление рисуется полупрозрачным сектором только при наличии
  направления; без него остаётся один знак камеры без кругового сектора.
- После запуска Natro мост проверяет HUD Speed в контрольные моменты 0, 5, 15, 30, 60 и 120
  секунд и, только если его основной сервис не работает, безопасно запрашивает фоновый запуск.
  Серия ограничена этими шестью контрольными моментами и никогда не открывает окно HUD Speed.
- HUD Speed остаётся необязательным источником: отсутствие приложения, запрет фонового запуска,
  сбой его сервиса или обрыв Binder очищают только его камеры. Камеры Яндекса и остальные
  функции навигации продолжают работать независимо.

Оригинальный закрытый ключ HUD Speed отсутствует. Поэтому подписанная ключом Natro сборка HUD
Speed не может установиться обновлением поверх оригинала с другим сертификатом. Перед её
установкой потребуется сохранить нужные настройки/лицензионные данные и удалить прежнюю
установку HUD Speed. Natro и Навигатор по-прежнему обновляются без удаления.

## Маршрутный блок панели приборов

- Убрана кнопка завершения маршрута.
- Отдельно отображаются оставшееся расстояние, расчётное время прибытия и оставшееся время.
- Полоса всего маршрута окрашивается фактическими сегментами пробок; пройденная часть затемнена,
  а текущая позиция отмечена указателем.
- Сегменты и прогресс используют одну шкалу физических метров, поэтому отметка не смещается из-за
  разной плотности точек геометрии маршрута.

## Установка на ECARX KX11

```bash
adb install -r Natro-2.5.9-signed.apk
adb install -r YN_30.3.0_Natro-HUD-v2-signed.apk
```

Не удаляйте Natro или Навигатор: их подписанная пара сохраняет прежнюю линию обновлений.

Для опционального моста HUD Speed, если установлен APK с другим сертификатом:

```bash
adb uninstall air.StrelkaHUDFREE
adb install HUD-Speed-76.0-L13-NatroBridge-signed.apk
```

Удаление HUD Speed может удалить его локальные данные. Этот шаг нужен только для камер HUD
Speed; камеры Яндекса и все остальные функции Natro работают без него.

## Проверка

1. В выключенном ручном режиме проехать участок со знаком полос, камерой и светофором: элементы
   должны разводиться автоматически, знак полос не должен перекрываться сектором камеры.
2. Включить ручной режим, поменять два приоритета, сохранить и перезапустить Natro/Навигатор.
   Порядок и значения должны сохраниться.
3. Изменить каждый размер слоя, цвета пробок, дорог и рамки; после перезапуска сравнить значения.
4. Проверить светофор с секундами, знак полос с подсвеченными разрешёнными полосами и название
   улицы на активном маршруте.
5. Имитировать скачок GPS вперёд и возврат: курсор и начало линии маршрута должны вернуться вместе.
6. При установленном мосте HUD Speed проверить отдельный знак, приоритет дубля, скорость, виды
   контроля и отсутствие сектора у камеры без направления.

Статические проверки и сборка DEX не заменяют дорожный тест Windshield/MapKit на головном
устройстве.
