# Natro 2.5.3: hotfix падения Навигатора

## Наблюдение на KX11

В журнале от 2026-08-30 оба запуска новой пары повторили одну последовательность:

1. bridge Навигатора успешно подключался и проходил аутентификацию;
2. независимый HUD `OffscreenMapWindow` получал Surface;
3. automotive `NavigationLayer` для route-only дорожных событий создавался с отключённой камерой;
4. через 7–10 секунд bridge завершался, а окно Навигатора исчезало.

Java exception в экспорт Natro не попал, поэтому точный native backtrace отсутствует. Однако
единственный новый нативный объект непосредственно перед обоими завершениями был одинаковым,
а предыдущая 2.4.7 работала с той же Surface и без этой конфигурации слоя.

## Исправление

- Automotive `NavigationLayerFactory` полностью исключён из независимых карт.
- Камера, маршрут и курсор по-прежнему имеют одного владельца, поэтому точный наклон и масштаб
  не откатываются.
- Штатные значки дорожных событий остаются через стабильный `RoadEventsLayer`.
- `ALWAYS` видим постоянно; `ROUTE_ONLY` включает соответствующий тег только при свежем активном
  маршруте. Ограничение стабильного API: он может показать ближайшие события, а не только события
  непосредственно на геометрии маршрута.
- Светофоры, полосы, повороты, маршрут, пробки и фоновой MapKit lease этим hotfix не отключаются.

## Критерий аппаратной проверки

После установки открыть Навигатор с включённой HUD-картой и оставить на две минуты сначала без
маршрута, затем на активном маршруте. Bridge не должен завершаться, окно не должно исчезать.
После этого открыть другое приложение ещё на две минуты и проверить продолжение движения карты.
