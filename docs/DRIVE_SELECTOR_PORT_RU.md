# Режимы вождения и готовые действия кнопок

Источник: [DezzK/monjaro-selector v1.0.0](https://github.com/DezzK/monjaro-selector/tree/2c6c8c010aae6a7eb47c886db4dbd7d76132e959),
commit `2c6c8c010aae6a7eb47c886db4dbd7d76132e959`. Автор Dezz, © 2026,
GPL-3.0-or-later. Оригинальные XML-иконки сохранены без изменений; Java/UI адаптированы
с сохранением авторства. В Natro не переносится отдельный владелец ECARX SDK.

## Сопоставление

| Возможность | Natro |
|---|---|
| Отдельный экран настроек | «Панели → Режимы вождения», исходный Material-экран с возвратом назад |
| Активные режимы / доступные режимы | Список с перетаскиванием, удаление ×, добавление chips, 24 пункта каталога |
| Сброс порядка / поиск поддерживаемых | Сохранены; поиск только читает runtime-каталог, не переключает режимы пробными записями |
| Карусель | Исходный оверлей, центрирование иконки, виртуальное повторение списка |
| Таймер показа / переключения | По умолчанию 5 / 3 секунды, настройка 1,5–10 секунд |
| Тач, свайп, закрытие, day/night | Исходные обработчики и ресурсы; тап меняет режим, свободная прокрутка — нет |
| SHOW | Предпросмотр, без записи в автомобиль и без выдуманного активного режима при неизвестном состоянии |
| PREV_1/2/3, NEXT_1/2/3 | Семь готовых пунктов вместе с SHOW в существующем меню кнопок; IDs 101–107 |
| Многократное переключение | Число — шаги списка, не количество физических нажатий; одна итоговая команда, затем анимация |
| ISSHOWING | Только уведомление о видимости; собственное состояние Natro, не пункт действий |
| Работа без чужого приложения | Прямой запуск собственного non-exported сервиса, без broadcast в monjaro-selector |
| Внешняя смена режима / boot | Явный дополнительный переключатель наблюдения, по умолчанию выключен при обновлении |

Назначения кнопок и предпросмотр работают независимо от автоматического наблюдения.
Прежние ручные назначения не меняются автоматически. При повторном открытии точного
старого broadcast-пресета показывается готовое действие; только явное сохранение переводит
его на собственный обработчик Natro. Дополнительные пользовательские extras не стираются.

## Общие иконки

Один `DriveModeCatalog` + `DriveModeIcons` используется в селекторе, пульте автомобиля,
выборе режима, назначениях кнопок и настройке стартового режима, лаунчере HOME,
панелях водителя, DIM-меню и общих редакторах иконок. Для действия SET показывается
иконка назначенного режима; для просмотра/цикла — известного текущего, иначе generic.
Цветные исходные иконки не перекрашиваются общей тонировкой кнопки; силуэты используют
акцент источника. Явное «без иконки» сохраняется. В текущих HUD/приборке отдельного
прямого отрисовщика drive-mode не найдено: общие меню используют LauncherIconResolver.

## Защита и границы приёмки

- Никаких raw CAN/PA записей. Публичные enum-значения сверены с поставляемым
  `ecarx-adaptapi.jar`; фактическая команда проходит через существующий
  `CarIntegration.executeControl(vehicle.drive_mode, SET)` с проверкой/read-back.
- Поддержка enum в общем каталоге не означает поддержку конкретным KX11. Вручную
  добавить иконку/режим можно; отказ автомобиля не скрывается и не считается успехом.
- В отличие от оптимистического выделения источника, активная иконка и анимация после
  команды обновляются только после подтверждения состояния. Неизвестное значение не
  заменяется первым пунктом. Повторная команда во время выполнения не ставится в бесконечную очередь.
- Источник объявляет `disable_native_ui` и `debug_log_intents`, но не подключает их к
  исполняемой логике/элементам экрана v1.0.0. Natro не показывает фиктивные работающие настройки.
  Отключение штатного DM остаётся в существующем разделе кнопок Natro.
- Движение автомобиля, конфликт с OEM/MConfig, физический селектор и геометрия 1760×720
  требуют отдельной приёмки GATE-104/105. Статические проверки не закрывают аппаратный gate.
