Исходные стрелки, состав строк и условия видимости сохраняются.

В исходном APK проверены `LaneSignBalloonTextureFactory`, `BalloonParams`,
`SingleViewBalloonTextureFactory`, `BalloonTexture`, `DayNightRes` и `ImageProvider`.
Проверено также, что оригинальная подложка — shape/GradientDrawable.
Проверенный артефакт: `Navigator-30.3.0-Natro-2.8.1-signed.apk`, SHA-256
`a0dac58a1799a718fdf3bfdd9374745c55c9e7a1990b9beca6d72fc753ffdbce`.
Байты APK и декомпилированный сторонний код не добавлены в репозиторий.

`LaneGuidanceAppearance` передаёт цвета в штатные day/night параметры фабрики до
создания исходных полос. Рекомендованные направления и ослабление остальных остаются
в штатном LaneSignContainerBuilder. При настройке скругления меняются согласованно
BalloonParams и исходная подложка. Для полупрозрачного фона исключено повторное
наложение заливки подложки поверх штатной заливки тела/указателя.

Обводка использует возвращённые самим Navigator пути тела и указателя. Объединение
этих путей не оставляет линию поперёк основания указателя. Обводка находится внутри
исходного контура, поэтому размеры изображения, восемь положений указателя,
привязка к маршруту и расчёт перекрытий остаются штатными. Оформление применяется
также при перемещении таблички в другое положение. Изменение настроек инвалидирует
изображение, а не пересоздаёт всю карту. При несовместимости оформительского API
остаётся исходный знак с диагностической записью.

Для синей карточки необязательные переопределения знаков применяются через маску
исходного Drawable; crop-маски не перекрашиваются. Alpha и различие активных/неактивных
полос сохраняются. Старый путь окраски без переопределения оставлен прежним.
Настройки текста расстояния и дороги остаются в основных полях текста/единиц;
цвет текста дорожных указателей задаётся отдельно и может остаться штатным.
У отдельного знака полос нет текстовой строки: его цветовой элемент — стрелки.

Новые поля редактируют черновик формы. Отмена палитры возвращает прежнее значение,
отмена формы не записывает эти поля. «Применить» сохраняет профиль штатным путём.
Для исходных цветов имеется выбор «Штатный цвет», для скругления — отдельный
переключатель, отключающий ручной ползунок.

Аппаратный GATE-060 открыт: требуется посмотреть оба экрана днём/ночью, проверить
поворот и съезд, разные рекомендованные полосы, все положения указателя, крайние
масштабы/скругления/обводку, прозрачность, сохранение после перезапуска и отмену.
Автозапуск всей приборки проверяется отдельно по GATE-043/059.
Текущая установленная пара остаётся 2.8.1; новый APK в этой работе не собирается.
