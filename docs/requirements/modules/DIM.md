# DIM: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| DIM-001 | Отдельная настраиваемая панель открывается на дисплее водителя в штатной вкладке «Навигация» и управляется прокруткой и подтверждением на руле. | `В КОДЕ / НУЖЕН KX11`. |
| DIM-002 | В панель добавляются сохранённые маршруты, приложения, функции автомобиля, сценарии умного дома, звонки и Android Intent; порядок действий редактируется. | `В КОДЕ / НУЖЕН KX11`. |
| DIM-003 | Настраиваются координаты, размер панели и строк, число видимых строк, отдельные шрифты, иконки, внутренние отступы, интервалы, цвета, рамка и прозрачность. Пользовательские параметры оформления применяются при отключённом точном пресете mNavi. | `В КОДЕ / НУЖЕН KX11`. |
| DIM-004 | Панель автоматически уступает дисплей mNavi, штатному звонку, медиаменю, другой DIM-вкладке и выключенному экрану; при недоступности ECARX API мост восстанавливается в фоне без блокировки Natro. Полная приборная панель Natro не является конфликтом: меню экрана водителя обязано открываться поверх неё и оставаться управляемым кнопками руля. | `В СОСТАВЕ ПОДПИСАННОЙ 2.7.6 / НУЖЕН KX11`: собственная instrument-панель удалена из conflict-policy и controller-gate, реальные внешние конфликты сохранены. Требуется `GATE-038`. |
| DIM-005 | Для действий умного дома меню экрана водителя показывает рядом с названием актуальное состояние из той же явной `stateBinding`, что и HOME/панель водителя: включено/выключено, положение, температура или другое значение с единицей. Недоступное устройство помечается «Недоступно», устаревшее значение — символом обновления, а отсутствие подтверждённого значения — «Нет данных»; последнее старое значение не выдаётся за текущее. Статус обновляется без сброса выбранной строки и не блокирует выполнение действия. | `В СОСТАВЕ ПОДПИСАННОЙ 2.7.6 / НУЖЕН KX11`: overlay подписан на общий connector listener, очищает состояние при смене сервиса и обновляет правую подпись строки без сброса выбора. Требуется `GATE-039`. |
| DIM-006 | Точный пресет оформления меню повторяет mNavi 2.0, включая цвета: прозрачная подложка `#00FFFFFF`, обычный текст/заголовок `#FF6C7984`, выбранная строка `#FF197BC5`, её текст `#FFFFFFFF`; заголовок 14 sp по центру, строки 24 sp bold с отступом 8 dp, скругление выбранной строки 6 dp, без внешней рамки, иконок и счётчика позиции. Старые конфигурации автоматически переходят на этот пресет, а сохранённые пользовательские цвета, рамка и отступы не влияют на него. | `В СОСТАВЕ ПОДПИСАННОЙ 2.7.6 / НУЖЕН KX11`: значения сняты с исполняемых ресурсов и реализации mNavi 2.0, закреплены константами renderer-а и schema-v2 migration. Требуется `GATE-040`. |
