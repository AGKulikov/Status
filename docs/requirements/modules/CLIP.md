# CLIP: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| CLIP-001 | Natro — локальный сервер, iPhone — клиент через Safari без обязательного дополнительного приложения. Единая функция работает, когда магнитола подключена к Personal Hotspot этого iPhone, и когда оба устройства в одной LAN. Реальные адреса интерфейсов, без фиксированного IP/интернет-сервера; обработать смену сети и обрыв. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9; Android и профильные тесты успешны. Safari + iPhone Personal Hotspot / Wi-Fi LAN на KX11 не подтверждены, GATE-103. |
| CLIP-002 | Передавать текст с телефона в буфер Natro/Android и в поле команд ADB, отдавать текст с магнитолы клиенту. Вставка/копирование на iOS только через явное действие пользователя; не обещать фоновый доступ Safari к системному буферу. Команды выполняются только отдельным действием «Выполнить», не при вставке или загрузке. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9; Android и профильные тесты успешны. Safari + iPhone Personal Hotspot / Wi-Fi LAN на KX11 не подтверждены, GATE-103. |
| CLIP-003 | Передавать файлы с iPhone на магнитолу, показывать имя, размер, прогресс и результат; скачивание полученных файлов обратно на телефон. Бounded upload/streaming, безопасные имена, без traversal/перезаписи произвольных путей/автоустановки APK. Прерывание не выдаётся за успешную передачу. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9; Android и профильные тесты успешны. Safari + iPhone Personal Hotspot / Wi-Fi LAN на KX11 не подтверждены, GATE-103. |
| CLIP-004 | Сервер явно включается/выключается, работает в отдельном foreground-сервисе, доступ защищён сопряжением и сеансовым токеном; выполнение ADB удалённо — отдельное разрешение. Никакого неавторизованного shell, выдачи ADB-ключей, публичного облачного доступа, UPnP/проброса портов или сброса Bluetooth. Подключения только с локальной сети, ограничения размера/частоты запросов, отсутствие секретов в журналах. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9; Android и профильные тесты успешны. Safari + iPhone Personal Hotspot / Wi-Fi LAN на KX11 не подтверждены, GATE-103. |
