# ADB: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| ADB-001 | Отдельный доступный из настроек и поиска раздел ADB: статус подключения, слева общие команды/специальные возможности/параметры разработчика/постоянный ADB/проверка установки, справа ввод и прокручиваемый выделяемый журнал. Сохранить порядок, подписи, OFF/ON/USB и доступность элементов эталона. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/ADB_AND_IPHONE_TRANSFER_RU.md, GATE-101/102. |
| ADB-002 | Локальный ADB 127.0.0.1:5555/7777, собственный сохраняемый RSA-ключ Natro, реальные handshake/ошибки/переподключение. Команды без префикса adb, многострочный результат, код завершения; повторное соединение не повторяет уже отправленную команду. Работа/ожидание не блокируют main или другие подсистемы. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/ADB_AND_IPHONE_TRANSFER_RU.md, GATE-101/102. |
| ADB-003 | Полный перечень общих команд и условий MConfig, включая выдачу разрешений, только установленные GPS-приложения, CHECK/RESET mock_location, служебные пункты и их настройки. Не подменять реально неработающий пункт сохранением неиспользуемого флага. Собственные разрешения выдаются Natro; совместимость с MConfig документируется отдельно. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/ADB_AND_IPHONE_TRANSFER_RU.md, GATE-101/102. |
| ADB-004 | Список установленных выключенных AccessibilityService с понятными названиями, включение выбранного сервиса без потери прежнего списка; полные/сокращённые имена и null обрабатываются корректно. После выполнения перечень и состояние обновляются. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/ADB_AND_IPHONE_TRANSFER_RU.md, GATE-101/102. |
| ADB-005 | Показать/скрыть/открыть параметры разработчика; OFF/ON/USB по двум точным свойствам persist.service.usb.enable и persist.sys.usb.adb; проверка установки persist.install.verify и скрытый Wi-Fi-пункт persist.service.wifi.ipcp. Подтверждать результат чтением, показывать отказ/частичное применение, не сообщать успех по одному API-вызову. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/ADB_AND_IPHONE_TRANSFER_RU.md, GATE-101/102. |
| ADB-006 | Дополнение пользователя: «И проверь, может ли терминал работать в режиме adb root». В MConfig v46.1 aliases root/unroot возвращают Not supported; в Natro проверить отдельный протокольный сервис root:/unroot:, переподключение после перезапуска adbd, отказ production build и фактический UID (`id -u`). `su 0` — отдельный режим; не выдавать наличие su или TCP-соединения за подтверждение root. Не повторять root-запрос при разрыве, не менять boot/verified boot и не обходить ограничения прошивки. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9; истинные root:/unroot:, ожидание и проверка UID реализованы и пройдены в replay. Историческое принятие root устройством найдено; новый фактический UID локального клиента на KX11 ещё не получен, GATE-102. |
| ADB-007 | Пользователь потребовал сначала найти ранее подготовленные для его ноутбука скрипты, а не спрашивать у него способ root. Проверены KX11_Enable_BLE_Mac.command (25.07), kx11_cruise_trace.sh v22 (09.08), KX11_Bluetooth_Collect.sh (14.08) и hud_lca_mode_patch(1).sh (14.09): все используют именно adb root, ожидание возврата устройства, затем adb shell id / id -u и проверку UID=0; cruise_trace возвращает adb unroot, только если root включён этим сеансом. Сохранённый adb-root.txt от 15.08 содержит restarting adbd as root. Это подтверждение прежнего способа и принятия запроса устройством, не новая аппаратная проверка локального клиента Natro. | Источники повторно найдены и прочитаны 16.09; схема root в Natro должна соответствовать этим скриптам. |
