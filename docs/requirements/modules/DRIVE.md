# DRIVE: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| DRIVE-004 | В существующем меню назначения кнопок семь готовых действий: показать без смены; назад/вперёд на 1, 2 или 3 режима. Выбор без ручных action/package/extras, понятные подписи сохранённых назначений, независимо от 1X/2X/3X/long жеста. Не менять ранее заданные назначения автоматически. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9; IDs 101–107, собственный сервис и существующий CarIntegration SET. Семь действий/шаги/параметры проверены replay; физические кнопки и оформление — открытая часть GATE-105. |
| DRIVE-005 | Отдельный раздел настроек режимов вождения по monjaro-selector v1.0.0: состав/порядок режимов, оверлей с активным режимом, параметры расположения/времени скрытия и поведения селектора; точный состав сверить с исходниками релиза. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/DRIVE_SELECTOR_PORT_RU.md, GATE-104. |
| DRIVE-006 | Использовать иконки типов вождения из указанного исходного проекта с сохранением лицензии/авторства. Единое отображение во всех существующих потребителях Natro: пульт, меню водителя, лаунчер, HUD/приборка, кнопки/выбор действий и новый селектор. Не заменять посторонние иконки с похожими именами. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/DRIVE_SELECTOR_PORT_RU.md, GATE-104. |
| DRIVE-007 | Смена режима только существующим проверенным CarIntegration/IDriveMode маршрутом; реальное подтверждение состояния, отсутствие записи при простом открытии оверлея. Физический селектор и вызов кнопкой должны использовать собственный контроллер Natro, без обязательного запущенного MConfig и двойной обработки. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.9 / НУЖЕН KX11; сопоставление и проверки: docs/DRIVE_SELECTOR_PORT_RU.md, GATE-104. |
| DRIVE-001 | В перспективе включать/выключать лимитер и круиз-контроль со штатной ГУ и задавать выбранную скорость, сохраняя штатную индикацию приборки/HUD. | `ТРЕБОВАНИЕ / ИССЛЕДОВАНИЕ`. |
| DRIVE-002 | Любая запись в шину допускается только после доказанного безопасного протокола, проверки модели/года и обратимого стендового теста. | `ЗАБЛОКИРОВАНО` до подтверждения команд. |
| DRIVE-003 | Для диагностики доступен root ADB через компьютер; отсутствие app-level root не считать окончательным ограничением. | `ПОДТВЕРЖДЕНО`. |
