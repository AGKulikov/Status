# KNOW: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| KNOW-001 | Повторно разобрать все доступные дампы и логи прошивки Geely и создать полноценный цифровой справочник проекта: какие функции автомобиля существуют, через какие компоненты и API читаются и управляются. Особый приоритет — функции, чей механизм пока не установлен. | `В РАБОТЕ`; опубликована редакция 1.0 [базы знаний](../../../GEELY_KX11_KNOWLEDGE_RU.md) и её каталоги из коммита `a2174b7`. Указаны охват, ограничения и 14 открытых вопросов. Полнота всех механизмов и аппаратная проверка не объявлены завершёнными; `GATE-048` открыт. |
| KNOW-002 | Справочник хранится в публичном `AGKulikov/Status` рядом с `PROJECT_REQUIREMENTS_RU.md`, содержит ссылки на требования и обновляется при новых доказательствах и исправлениях. | `ПРОВЕРЕНО ПО АРТЕФАКТУ` для размещения: корневой [GEELY_KX11_KNOWLEDGE_RU.md](../../../GEELY_KX11_KNOWLEDGE_RU.md) опубликован рядом с реестром (`REL-016`). Ранее намеченное имя `GEELY_KX11_DIGITAL_MANUAL_RU.md` заменено фактическим именем опубликованного документа. Актуализация продолжается; ограничения `REL-008` сохраняются. |
| KNOW-003 | Для каждого механизма справочник различает подтверждённый факт, гипотезу и неизвестное; фиксирует версию/компонент, источник в дампе/логе, точку входа, единицы и значения, ограничения и результат реальной проверки. Включение подсистемы не принимается за доказательство отображения её UI. | `КРИТЕРИЙ ИСПОЛНЕНИЯ KNOW-001`; парковочная ошибка `NOTIF-008/NOTIF-009` — обязательный пример такого разграничения. Команды движения остаются под `DRIVE-002`. |
| KNOW-004 | Вести расширяемую матрицу охвата всех систем целевого Geely KX11 и журнал исследования. Для каждой системы фиксировать подтверждение наличия оборудования и ECU/владельца, имеющиеся и отсутствующие источники, состояния и команды, путь доступа из ГУ, условия/ограничения, способ независимого подтверждения и следующий недостающий факт. Различать неизвестное наличие, неизученную область и недоступный в точно исследованной области путь. Прежние 14 открытых вопросов сохраняются как приоритетная очередь и не считаются исчерпывающим перечнем. Сначала использовать уже полученные дампы/логи; новые данные запрашивать только для конкретного зафиксированного пробела. | `В РАБОТЕ`; подготовлены [матрица охвата](../../../docs/geely-kx11/research-2026-09-05/COVERAGE_RU.md), [журнал исследования](../../../docs/geely-kx11/research-2026-09-05/RESEARCH_LOG_RU.md) и [план недостающих данных](../../../docs/geely-kx11/research-2026-09-05/DATA_PLAN_RU.md). Первичный каталог деклараций и отдельный аудит нулевых значений расширяют доказательную базу, но не подтверждают полноту всех систем, наличие конкретного оборудования или физическое исполнение команд; `GATE-048` остаётся открытым. |
| KNOW-005 | Продолжать доскональный разбор относящегося к задаче доступного корпуса до исчерпания его содержимого; публикация промежуточных результатов не является завершением исследования. Сначала исчерпывать уже полученные файлы, затем для конкретно установленного пробела подготовить адресный скрипт досбора недостающих файлов на macOS и инструкцию запуска. Итог фиксирует точные источники, SHA-256, область проверки, проверенные результаты и статусы недостающих/недоступных данных; количество записей и файлов не превращается в процент понимания автомобиля. | `В КОДЕ / НУЖЕН KX11`; исходники и49 офлайн-проверок адресного сборщика готовы, дальнейшее исследование продолжает `KNOW-004`. Инструкция и исходники сборщика — [tools/geely-macos-collector/README_RU.md](../../../tools/geely-macos-collector/README_RU.md); `GATE-049` открыт. Исчерпание доступных материалов не закрывает аппаратные вопросы и `GATE-048`. |
