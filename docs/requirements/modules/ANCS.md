# ANCS: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| ANCS-015 | Прекратить неограниченный same-wrapper recovery при OWNER_UNPROVABLE. Ограниченные попытки и пауза; новый владелец только после доказанного завершения прежнего и drain. BLE-операции не блокируют UI. Не сбрасывать глобальное радио, сопряжение, HFP/A2DP и не ослаблять проверку peer. | В СОСТАВЕ ПОДПИСАННОЙ 2.9.8 / НУЖЕН KX11; GATE-096. Первопричина системного отказа подключения не доказана. |
| ANCS-001 | После обновления Natro ANCS должен восстанавливаться без перезагрузки магнитолы и без повторного сопряжения. | `ОШИБКА НА 2.7.7` 05.09.2026: после package replacement в 14:28:05 журнал до 14:30:05 не содержит READY; обычное HFP-подключение не означает готовность ANCS. |
| ANCS-002 | Сохраняется один владелец обратного ANCS GATT-канала; Helper не создаёт конкурирующее второе BLE-подключение после handoff. | `ТРЕБОВАНИЕ`. |
| ANCS-003 | Длительный «тихий» владелец не должен задерживать вход в scan примерно на четыре минуты; повторные ступени поиска должны быть короткими и ограниченными. | `ОШИБКА` 05.09.2026: точные LE advertisements постоянно опережают таймер и не увеличивают счётчик reassert, поэтому зарегистрированный owner не достигает уже предусмотренного retirement. Таймер сам по себе не даёт разрешения создать второго владельца. |
| ANCS-004 | Ошибки `encryption key size is insufficient` и `handle is invalid` должны приводить к безопасному восстановлению, а не вечному зависанию. | `ОШИБКА`. |
| ANCS-005 | Телеметрия iPhone: точная батарея, зарядка, блокировка, тип сети и сигнал обновляются без минутной задержки. | `ОШИБКА`. |
| ANCS-006 | В Natro и Helper есть расширенный журнал этапов подключения, причин backoff/quarantine и экспорта диагностик. | `ТРЕБОВАНИЕ`. |
| ANCS-007 | Экспорт логов на магнитоле должен работать даже при отсутствии стороннего файлового приложения. | `ОШИБКА`. |
| ANCS-008 | Helper сохраняет управление климатом/функциями из Live Activity. | `ОШИБКА` в отдельных сборках. |
| ANCS-009 | Live Activity автоматически активируется только при подключении магнитолы по выбранному Bluetooth и выключается после отключения. | `ТРЕБОВАНИЕ`. |
| ANCS-010 | Взаимодействие с кнопками Live Activity не должно обнулять состояние управления; ограничение iOS на время гашения экрана фиксируется отдельно и не выдаётся за исправляемое Android-кодом. | `ТРЕБОВАНИЕ / ОГРАНИЧЕНИЕ ПЛАТФОРМЫ`. |
| ANCS-011 | Helper определяет LTE/5G/3G/2G только по активной линии мобильных данных (`dataServiceIdentifier`); неактивная SIM с 2G не может переопределять активную LTE/5G, смена data-SIM обновляется сразу. | `В КОДЕ / НУЖЕН IPHONE/KX11`; Helper 70. |
| ANCS-012 | Natro остаётся авторитетным источником состояния HFP/A2DP/PBAP; Helper не сбрасывает глобальный Bluetooth, не удаляет системную пару и не подменяет идентичность телефона ради восстановления ANCS. | `ТРЕБОВАНИЕ`; проверять один видимый телефон и один владелец ANCS. |
| ANCS-013 | Внутри одной проверенной BLE-эпохи восстановление соединения сбрасывает временную аутентификацию и подписки, сохраняя уже загруженный проверенный enrollment snapshot до завершения эпохи. Ошибка GATT не должна превращаться в ложное требование повторного сопряжения. Новая эпоха заново загружает запись вне main thread и проверяет выбранную пару и обе установки; доверие не расширяется. | `В ПОДПИСАННОЙ 2.7.8 / НУЖЕН KX11`: RESET_SESSION_STATE теперь очищает handshake отдельно от enrollment snapshot; новая эпоха/остановка сохраняют полный reset. В старом логе transient C4 error сменялся ложным no exact enrollment record. |
| ANCS-014 | При выключении/возврате Bluetooth во время любого этапа установления ANCS терминальное завершение текущего GATT должно освобождать общий STARTING. Автоматическое и ручное восстановление запускают свежую эпоху после подтверждённого owner=0 и drain; не остаются в бесконечном «запускается», не очищают сопряжение и не создают второго владельца. | `В СОСТАВЕ ПОДПИСАННОЙ 2.8.3 / НУЖЕН KX11` 08.09.2026: журнал показывает WAIT_RADIO + terminal в 08:08:01, radio=true в 08:08:19 и отсутствие нового запуска до ручного recovery в 08:12:58. Три сценария воспроизвели STARTING на прежнем коде; аппаратная приёмка GATE-061 открыта. |
