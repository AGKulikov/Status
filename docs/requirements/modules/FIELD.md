# FIELD: исходные требования

Автоматическая выборка полных строк из [реестра](../../../PROJECT_REQUIREMENTS_RU.md). Статусы относятся к указанным в них датам; последующие уточнения могут менять правило. Перед работой прочитать [действующие уточнения](../../CURRENT_REQUIREMENTS_RU.md) и найти изменения по ID, семейству и теме через `python tools/requirements.py search`. Проза вне таблиц также содержит обязательные требования. Не редактировать эту выборку вручную.

| ID | Требование | Статус / критерий |
|---|---|---|
| FIELD-001 | После разрыва Bluetooth Helper восстанавливает маршрут без ручного перезапуска. Проверить задержанные фоновые события, тайм-аут остановки и позднее подтверждение owner-zero; не создавать второго владельца и не сбрасывать Bluetooth/сопряжение. | ОШИБКА: журнал Helper 04.10, потеря CONTROL 08:45:23, поздняя обработка 08:49:29 и stopTimeout, ручной retry 08:49:35. Причина приостановки процесса отдельно не доказана. |
| FIELD-002 | Проверить повторное появление белой полосы вместе с отказом VA, восстановление режимов и владельцев после обновления/перезапуска. Совпадение симптомов не считать доказательством одной причины. | ОШИБКА по сообщению пользователя; исходная локализация и регрессии в работе. |
| FIELD-003 | Восстановить исполнение назначений VA, а не только приём нажатий; отделить потерю входного канала от отказа назначенного действия. | ОШИБКА; журнал содержит dispatch VA без подтверждённого результата. GATE-112 остаётся открытым. |
| FIELD-004 | Пассажирский HOME открывается независимо на display 3 без требования вручную переносить всё приложение и без переноса водительского HOME/настроек. Исследовать отдельный overlay-владелец; не заменять полноценный HOME урезанной панелью. | ОТРИЦАТЕЛЬНАЯ ПРИЁМКА PASSHOME-001: launch_submitted не доказывает правильного окна. Прежние source/JVM результаты сохраняются только как программные. |
| FIELD-005 | Проверка модуля управления «машинкой» должна давать явный результат и разблокировать только действительно проверенные операции. Устранить цикл «выполните проверку» после нажатия проверки; неизвестную библиотеку/неуспешную проверку не принимать за поддержанную. | ОШИБКА по сообщению; журнал фиксирует HudLcaPatchActivity, но не результат проверки. Необходимы проверка состояния UI и диагностируемый отказ. |
| FIELD-006 | Импорт своих PNG/JPEG для приложений телефона работает на ГУ без системного DocumentsUI/выбора файлов; доступен встроенный выбор памяти/USB с запросом разрешения и без потери прежней иконки при отказе/отмене. | ОШИБКА подтверждена фотографией 04.10 09:54 МСК: «На устройстве нет выбора файлов». PhoneAppIconsActivity имеет только ACTION_OPEN_DOCUMENT и завершает выбор при ActivityNotFoundException. Исправление и регрессии в работе. |
