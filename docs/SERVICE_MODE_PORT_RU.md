# Сервисный режим — перенос в Natro

Проверка восстановления: `python3 -m unittest tools.tests.test_adb_service_replay -v`.
Исполняются ServiceModeJournal/PinStorage/AppsToHideStorage с Android test doubles:
запись до pm, восстановление DEFAULT/ENABLED, отказ чтения состояния, ошибка commit,
сохранение PIN, запрет системных/self/ECARX/звонилки. Поиск портов отменяется при
onStop, журнал с сохранённым исходным состоянием не очищается обновлением списка.
Реальные PackageManager, звонилка, reboot и частичное скрытие на KX11 остаются
отдельной открытой приёмкой.

| Логика источника | Natro |
|---|---|
| «Скрыть» / «Восстановить», иконки, галочки | Перенесены Activity, adapter, layouts; namespace `servicemode`, ресурсы `service_mode_*` |
| Исключить системные приложения, себя, `com.ecarx.*` | Сохранено; весь пакет Natro не отключается |
| Снятые галочки — оставить видимым | Device-protected `ExcludeAppsStorage` |
| Обнаружение отключённых приложений вне журнала | Сохранено; восстановление только выбранных пользователем, не автоматическое |
| PIN минимум три цифры, не с нуля, default 123456; перед скрытием свой PIN | Сохранено; дополнительно только ASCII-цифры, максимум 32, проверка результата записи |
| Телефонные разрешения, подтверждение списка | До скрытия; без разрешений операция не начинается |
| ADB/Telnet, IPv4/IPv6 своих интерфейсов, детали портов, кэш | Сохранено; устаревший адрес, уже не принадлежащий устройству, не сканируется |
| `pm disable-user --user 0` / `pm enable` | Отключение сохранено; восстановление явно user 0, возврат прежнего DEFAULT/ENABLED |
| Список для восстановления, частичные результаты | Write-ahead журнал до команды, read-back PackageManager, запись независимо от жизни Activity |
| Скрыть собственную иконку через trampoline | Trampoline Natro; обычный запуск по-прежнему открывает SettingsHubActivity |
| Возврат PIN из звонилки с отменой вызова | Receiver активен для PIN только при скрытых приложениях и заданном PIN |
| Keep-alive, boot, исключение battery optimization | Перенесено; best-effort, не гарантия против OEM force-stop |
| Рекомендация перезагрузить ГУ после восстановления | Сохранена, автоматической перезагрузки нет |

ADB использует общий ключ Natro и bounded чтение с exit status вместо одного пакета.
Телnet ограничен временем/размером ответа. Пакеты проверяются перед shell;
штатная звонилка дополнительно защищена от отключения. Другие Android-пользователи
блокируются, чтобы список текущего пользователя не применялся к user 0.

## Открытая приёмка GATE-106

- Android-сборка успешна; визуальная проверка раздела остаётся открытой.
- Прерывание batch, уничтожение Activity/процесса, отказ записи preferences,
  разрыв после принятой команды, частичное восстановление и DEFAULT/ENABLED.
- PIN через **штатную звонилку KX11**. После OEM force-stop доставка может прекратиться;
  гарантированный возврат одним PIN пока не заявляется. Прямой запуск SettingsHubActivity
  остаётся доступен как резервный путь.
- Согласованное поведение собственных HOME/поверхностей Natro: текущая адаптация,
  как источник, не отключает собственный пакет и не останавливает все его функции.
- Скрытие — отключение выбранных приложений, не удаление APK/данных и не гарантия
  заводского состояния или отсутствия следов при диагностике.

Никакие приложения на пользовательском автомобиле при разработке не отключались.
Перенос опубликован и включён в подписанную Natro 2.9.9. Android CI и replay журнала
успешны; [итоговый протокол](releases/2.9.9/README_RU.md). Реальные PM, PIN/звонилка,
перезагрузка и аппаратная/визуальная приёмка не заменяются этими тестами.
