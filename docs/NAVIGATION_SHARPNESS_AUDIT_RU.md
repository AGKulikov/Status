# Ревизия чёткости масштабируемых слоёв

Дата ревизии: 04.09.2026. Область: обе независимые карты, отдельные элементы HUD и панели
приборов. Документ фиксирует исполняемый путь; визуальное закрытие остаётся за `GATE-020` и
`GATE-032` на KX11.

| Элемент | Источник и масштабирование | Результат ревизии |
|---|---|---|
| Дороги и штатные подписи | Нативный MapKit style/label scale | Bitmap в Natro не создаётся; шрифт, контур и collision остаются у MapKit. |
| Маршрут, пробки, стрелки, секторы камер | Нативные polyline/arrow/polygon | Растрового масштабирования нет. |
| Камера, скорость и составная пластина | Drawable/Canvas строятся заново не меньше 80 px; один `IconStyle`-downsample задаёт физический размер | Нет промежуточного уменьшенного bitmap; cache пересоздаётся при изменении профиля. Это намеренный единственный oversampling-путь `MAP-035`. |
| Светофор со штатным цветом | Новый `TrafficLightViewImpl(Context, scale)` при каждом изменении размера | Фабрика получает текущий scale, MapKit принимает финальную текстуру с `IconStyle.scale=1`. |
| Светофор с выбранным цветом | Штатный `TrafficLightViewImpl(Context, scale)` растрируется в текущий размер после подмены его body/leg Paint; при несовместимой региональной реализации — Canvas из тех же signal/seconds | Сохраняются штатные форма, градиент сигнала, стрелка направления и цифры; тело передаётся 1:1, цвет тела и хвоста общий. |
| Хвост светофора | Vector `Path` строится заново из scale/density | Удалено второе уменьшение готовой текстуры; `IconStyle.scale=1`. |
| Обычный светофор маршрута без отсчёта | Штатный day/night vector drawable растрируется сразу в выбранный физический размер 50–250% | Повторного bitmap-resize нет; MapKit получает финальную текстуру с `IconStyle.scale=1`. |
| Табличка полос | `LaneSignBalloonTextureFactory.createTexture(..., scale)` | Финальная штатная текстура и anchor передаются с явным `IconStyle.scale=1`. |
| Дорожные события | Исходный Yandex `RoadEventsLayer` provider | Natro не извлекает и не масштабирует bitmap: меняются только нативная zoom-scale function и размер штатного caption. |
| Искусственная неровность | Штатный vector drawable растрируется прямо в целевые width/height | `IconStyle.scale=1`; повторного bitmap-resize нет. |
| Конечная точка | Собственный vector `Path` строится в текущем размере | Кэш сбрасывается при изменении профиля, `IconStyle.scale=1`. |
| Курсор | Собственный vector `Path` строится в текущем размере | Кэш сбрасывается при масштабе/цвете, `IconStyle.scale=1`. |
| Canvas-модули HUD/панели | Геометрия и glyph отрисовываются в текущие bounds | Добавлен subpixel text; изменение frame не масштабирует старый слой. Статический слой панели перестраивается в полном размере display. |
| Знак манёвра/полос в отдельном модуле | В прямом потоке знак манёвра строится как semantic vector из точного `Action` текущего snapshot; полосы используют один исходный bitmap Яндекса в target bounds | Неключевой трёхминутный bitmap манёвра больше не читается и не может зависнуть после смены поворота. Промежуточный bitmap не кэшируется; oversized Parcelable отклоняется. |

Статический запрет для дальнейших изменений: в `navigator-mod` и навигационном хранилище не
должно появляться `Bitmap.createScaledBitmap`; исключение камеры реализуется через один
осознанный `IconStyle`-downsample из заново созданного oversampled drawable/Canvas, а не через
цепочку растров. Любой новый placemark/card обязан попасть в эту таблицу и в аппаратную матрицу
масштабов до выпуска.
