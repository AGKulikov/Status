# HUD-дисплей: аппаратная геометрия и безопасный вывод

Проверено по `mHUD 6.1` (`ack48.monjarodev.mhud`, SHA-256 APK:
`8ba8da9aea2b6072cd5ec3cb42fc145a82547dc48f5e7b1d9e705cfee9a25d2e`).

## Подтверждённые размеры

- Экран редактора mHUD: `1760×720 px`.
- Область предпросмотра HUD на нём: примерно `1760×460 px`, `Y=130`.
- Координатная область физического HUD: ровно `728×190 px`.
- Начало HUD во внешнем `Presentation`: `X=0`, `Y=720`.
- Безопасный прямоугольник вывода: `[0,720]–[728,910]`.
- Поэтому внешняя Android-поверхность должна быть не меньше `728×910 px`.

Полное разрешение внешней Android-поверхности в APK mHUD не зафиксировано: приложение получает
её от прошивки. Status Widget показывает фактический результат `Display.getRealSize()` для
выбранного дисплея.

## Защита от вывода на соседний экран

- Целевой дисплей выбирается только по сохранённому числовому `Display ID`.
- Если этот ID исчез, вывод останавливается; перехода на другой внешний дисплей нет.
- Основной дисплей (`ID 0`) не может быть выбран как HUD.
- Перед запуском проверяется, что поверхность вмещает весь прямоугольник `728×190 @ (0,720)`.
- Внешнее окно прозрачно вне HUD-области.
- Фон панели, сетка и каждый виджет рисуются под жёстким `Canvas.clipRect`; импорт конфигурации
  не может изменить аппаратные границы.
