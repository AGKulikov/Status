# Natro 3.0.7 — исправления по логам 6 октября

База: выпущенная 3.0.6, без отката настроек, пассажирского экрана, автозапуска,
карт и прежних исправлений кнопок. Новая версия 3.0.7 / 208021340.

| Наблюдение | Изменение | Граница доказательства |
|---|---|---|
| HUD/LCA: BufferOverflowException сразу после connect | Короткий ASCII OPEN, передача полного UTF-8 script отдельными WRTE не больше min(peer max,4096), закрытие stream в finally | Тест воспроизводит ошибку реальной adblib, проверяет инспекцию и все варианты патча; KX11 отдельно |
| MAIN задержан в HWGPS sendBroadcast на3356мс | Отдельная последовательная очередь, один запрос в полёте, три попытки, generation fence при stop/restart | JVM lifecycle/retry; системный Binder не эмулирует нагрузку автомобиля |
| Белая полоса разрешена при mode1 и видимой панели | Возврат mode3 только при подтверждённых foreground/window/vendor navigation+idle; до3 попыток, без пересоздания Activity | Unknown/звонки/медиа/другая вкладка сохраняют штатный приоритет; физическое скрытие требует KX11 |
| Ошибка VA могла быть скрыта успешным MEDIA в batch | Полный per-button readback, terminal compatibility errors без повторного рестарта XSF | Проверяется parser/gate; штатное подавление VA требует allowlist и аппаратной проверки |
| Старый input_reader_failed во время планового reconnect | Сохранено исправление 3.0.6 с generation fence и retired_reader_closed | Новую гонку ArrayList лог не доказывает |
| Старые UI incidents inflate/MaterialAutoComplete, внешний lifecycle | Сохранены исправления startup/settings 3.0.6; внешние причины не переименованы в ошибки Natro | Нет свежего доказательства нового дефекта в этих путях |
| checkpoint3141/3172мс, live_reads_blocked=false | Сохранён фоновый runtime-cache writer, не возвращены apply/fsync на MAIN | Медленный накопитель и физические задержки остаются отдельной проверкой |
| command_delivery/audio_output/physical_effect=unobserved | Честные статусы сохранены | Отсутствие независимого наблюдения не равно отказу |

HUD/LCA не устанавливается автоматически после проверки. Неизвестные firmware/hash
по-прежнему запрещены; режим, backup, root, журнал и rollback сохраняются. Исправлена
доставка команды до проверок, а не объявлена аппаратная совместимость по фото.

Для приёмки на KX11: проверка модуля должна вернуть конкретный ORIGINAL/SIMPLE/GUIDE/AR
без BufferOverflow; затем выбранная пользователем операция проверяется отдельно.
Проверить белую полосу после возврата режима, штатный звонок/медиаплеер и выход из
панели. Проверить VA short/long, отсутствие двойного штатного действия и повторный
запуск после reboot. Эти физические проверки не выполнены в среде сборки.
