# Natro 2.4.4 + Навигатор 30.3.0 HUD v2: установка на ECARX KX11

## Что проверяет сборка

- Natro сохраняет пакет `ru.natro.statuswidget`, `minSdk=28`, `targetSdk=28` и не содержит
  нативного кода, поэтому подходит для Android 9 на KX11 независимо от ABI процесса.
- Навигатор сохраняет пакет `ru.yandex.yandexnavi`, версию, разрешения и ABI `arm64-v8a` рабочего
  `YN_30.3.0_T2_`.
- В Навигаторе меняются только `AndroidManifest.xml`/`resources.arsc` с проверенной прозрачной
  темой `MapActivity`, `classes4.dex`; добавляется `classes19.dex`. Точные SHA-256 обоих theme
  entries закреплены в verifier. `classes14.dex`, `classes18.dex`, `assets/` и `lib/` остаются
  побайтно равны рабочему APK 30.3.0.
- Оба APK подписываются одним сертификатом Natro. Это необходимо для закрытого Binder-моста.
- В manifest Навигатора отсутствует `sharedUserId`, поэтому установленная оригинальная
  Яндекс Музыка не должна требовать подпись Навигатора. Удалять Яндекс Музыку не нужно.
- Профиль экрана зафиксирован для KX11: основная область Natro `1760×720`; HUD — Display ID 2,
  поверхность `1920×1080`, окно `728×190 @ (0,720)`.
- Оконный режим применяет проверенный по 29.4.2 тип overlay/system-alert 2038/2003 в конце
  `onResumeFragments`. `NatroTransparentAppTheme` делает Activity прозрачной ещё до запуска, как
  в рабочей 29.4.2. Для 30.3.0 отдельно очищаются Window, decor, content root,
  `map_activity_root` и `activity_search_map_view`, а после смены типа фиксируется реальный
  bounded frame. Поэтому вокруг окна нет чёрной поверхности. Новые разрешения не добавляются.
- В настройках независимой HUD-карты есть режим «Только дороги — прозрачный фон». MapKit скрывает
  весь substrate без дорожных тегов, включает alpha background, а Natro композитит такой
  `TextureView` без чёрной заливки. Маршрут, пробки и курсор остаются отдельными HUD-слоями.
- Точное определение LTE/5G для dual-SIM исправлено в Helper 70: он выбирает активную линию по
  `dataServiceIdentifier`. Обновление APK Natro само по себе не обновляет Helper на iPhone.
- Камера 360 и парктроники приостанавливают уже показанное уведомление и удерживают новые до
  фактического сигнала закрытия. Настройка максимального ожидания обычного приложения не снимает
  эту защитную паузу; удалённые на телефоне уведомления после закрытия не воспроизводятся.

## Важно перед установкой

Android разрешает обновление пакета только APK с тем же сертификатом. Если установленный
`ru.yandex.yandexnavi` подписан не сертификатом
`6e9855aedc008bbdd8a7fbf3f490be07f964b7ac658a837a1592647a08365c75`, команда
`adb install -r` для нового Навигатора завершится `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

До удаления текущего Навигатора сохраните важные настройки и данные. Удаление пакета может
стереть его приватные данные и загруженные офлайн-карты. Не удаляйте Навигатор только ради
эксперимента, пока резервная копия и возможность вернуть рабочий APK не подтверждены.

## Порядок установки

1. Проверить сертификат уже установленного Навигатора: получить путь через
   `adb shell pm path ru.yandex.yandexnavi`, скопировать APK командой `adb pull`, затем выполнить
   `apksigner verify --print-certs <полученный.apk>`.
2. Natro обновить без удаления: `adb install -r Natro-2.4.4-signed.apk`.
3. Если сертификат установленного Навигатора совпадает — выполнить
   `adb install -r YN_30.3.0_Natro-HUD-v2-signed.apk`.
4. Если сертификат отличается — после резервного копирования удалить только пакет
   `ru.yandex.yandexnavi`, затем установить новый APK без `-r`.

## Обязательная проверка на магнитоле

1. Навигатор запускается полноэкранно и кнопкой переключается в оконный режим и обратно.
2. Существующие команды Natro запускают новый Навигатор в окне; перемещение, изменение размера,
   фиксация, скругление, прозрачность и возврат в полный экран работают.
3. Оригинальная Яндекс Музыка остаётся установленной, запускается и воспроизводит музыку.
4. Онлайн-карта, ранее загруженная офлайн-карта, поиск, построение и ведение по маршруту работают.
5. Natro видит мост Навигатора, получает манёвр, расстояние, полосы, ETA и геометрию маршрута.
6. HUD выбирает только Display ID 2; изображение находится в зоне `728×190`, не попадает на
   соседние области приборной панели и восстанавливается после двух перезагрузок/QuickBoot.
7. Включить для HUD-карты «Только дороги — прозрачный фон»: между дорогами должен быть виден
   нижний слой HUD, без чёрной/цветной карты; подписи, здания, вода, парки и POI отсутствуют,
   маршрут, его пробки и курсор не мерцают.
8. После холодного запуска отдельно замерить время до ANCS и до начала музыки — этот релизный
   контроль совместимости не заменяет реальный замер OEM Bluetooth/MediaSession на KX11.
9. После установки Helper 70 проверить смену LTE/5G/3G/2G на активной линии; значение резервной
   SIM не должно попадать в Natro.
10. Во время 360 и парктроников уведомление не перекрывает автомобильное окно. После полного
   закрытия ещё актуальное уведомление возвращается с оставшимся временем, а полученные во время
   камеры уведомления показываются по очереди; удалённые на iPhone элементы не возвращаются.
   Повторить цикл дважды на одном уведомлении: каждая новая камера должна замораживать уже
   уменьшившийся остаток времени и продолжать его после своего закрытия.

До прохождения всех пунктов пара считается тестовой, а не готовой для ежедневной эксплуатации.
Результат машинной проверки конкретных подписанных APK сохраняется рядом с ними в
`KX11-COMPATIBILITY.txt`.
