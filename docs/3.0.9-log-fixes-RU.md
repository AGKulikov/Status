# Natro 3.0.9 — повторные отказы 07.10.2026

Кандидат 208021342 поверх 3.0.8 с прежней подписью. Исходные журналы приватны.

| Область | Изменение | Доказательство и граница |
|---|---|---|
| UID/ADB | Закрытие потока синхронизировано с извлечением последнего пакета | Детерминированная гонка падает на исходной3.0.8 и проходит на новом коде. Не доказывает, что оба аппаратных UID-отказа имели только эту причину; stage теперь различает missing_exit/command_failed/truncated/invalid_uid. |
| Иконки | Файловая проверка удалена из MAIN signature/layout selection; декодирование в отдельной ограниченной очереди | Текст получает fallback немедленно; поздняя картинка сверяет generation. Android-тест удерживает monitor хранилища при показе карточки. Проверка SprutHub на KX11 открыта. |
| Уведомления | submitted, attach и pre_draw раздельны | pre_draw не называется доказательством физических пикселей. Нет текста уведомлений в новых записях. |
| ANCS | Проверка свежего PackageInfo до запуска контроллера, поздний broadcast не продлевает тот же барьер | Один owner/drain, без radio reset или pair removal. Корневая причина system GATT133 и устойчивость на машине не доказаны. |
| Белая полоса | Android9 read-only am stack list для exact display owner вместо отсутствующего secondary Accessibility | Сохраняются собственное готовое окно и подтверждённый DIM idle/tab. Unknown/конфликт/чужое приложение не разрешают восстановление. Отсутствие DIM callbacks может всё ещё блокировать repair; это явно логируется. |
| Музыка | После PLAY в STATE_NONE допускается ограниченный rebind без повторного PLAY | Старые manual/plan permits проверяются перед отложенной работой. Фактическое время появления готовой сессии/звука требует KX11. |
| Backup |335…341→342, прежние defaults и данные | Отклонение будущих схем сохранено; проверка владельцев не заменяет runtime restore. |

Ни ошибки DNS, ни отсутствие HWGPS handshake не объявлены устранёнными:
предоставленные журналы не устанавливают исправимую первопричину сети/штатного
сервиса. Фоновый checkpoint с live_reads_blocked=false не приравнен к MAIN stall.

Чтение владельца сверено с первичным исходником AOSP Android9:
https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-9.0.0_r1/core/java/android/app/ActivityManager.java
StackInfo.toString печатает displayId в заголовке, visible/topActivity в строках
taskId. Parser принимает только однозначные собственные видимые stacks; он не
считает paused на вторичном экране скрытым. Новых vehicle IDs/setters нет.
