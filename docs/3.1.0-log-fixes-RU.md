# Natro 3.1.0 — повторные отказы и скрытие HUD при громкости

- ANCS/Helper не изменены по прямому поручению пользователя.
- Завершённая публикация уведомления обновляет оба reserved окна напрямую,
  не ожидая общей очереди коннекторов. Условия сценариев/редактора сохранены.
  Логируются request, блокирующие условия, attach/pre_draw; они не равны пикселям.
- ADB stdout отделяется случайной границей от shell preamble/echo; обязательные
  реальный exit и числовой UID сохранены. Тест с echo и фрагментами проходит.
  Эта воспроизведённая уязвимость парсинга НЕ доказывает точную причину на KX11.
- Ошибка применения удерживается отдельно от вращающегося основного журнала;
  этап пишется короткими словами, чтобы не попасть под маску длинных credentials.
  Защита токенов/ключей/паролей не ослаблена. Исторический action-tail явно помечен.
- options.hideDuringVolume=false по умолчанию для каждого HUD-элемента; отдельная
  настройка в редакторах обычного элемента, карты, группы, подложки. Используется
  существующее окно громкости 2 с после последнего изменения. Редактор не скрывает.
  Скрытие группы затрагивает её участников. TextureView карты лишь не компонуется,
  producer/surface lease и плеер не перезапускаются. Остальные условия показа остаются.
- Новый параметр входит в прежний JSON options/copy/backup. Совместимость343
  разрешает335…342; неизвестные будущие схемы отвергаются.
