# Natro 2.5.10: DIM-панель и точные навигационные карточки

## Новая панель экрана водителя

- Отдельная настраиваемая панель открывается на дисплее водителя в штатной вкладке
  «Навигация» и управляется прокруткой и подтверждением на руле.
- В список можно добавлять сохранённые маршруты, приложения, функции автомобиля, сценарии
  умного дома, звонки и Android Intent. Порядок действий редактируется независимо.
- Настраиваются координаты, размеры панели и строк, количество видимых строк, шрифты,
  иконки, внутренние отступы, интервалы, цвета, рамка и прозрачность.
- Панель автоматически уступает место mNavi, полной панели приборов Natro, штатному звонку,
  медиаменю, другой DIM-вкладке и выключенному экрану. Отсутствие ECARX API не останавливает
  приложение: мост переподключается в фоне с ограниченными задержками.

## Навигационные карточки

- Исходный знак манёвра Яндекс Навигатора передаётся как bitmap без собственной перерисовки.
  Если источник не прислал знак, приложение не подменяет его предположительной стрелкой.
- У карточки ближайшего манёвра HUD отдельно настраиваются размеры трёх шрифтов, зона и масштаб
  знака, отступы знака и текста, интервалы, фон, рамка и скругление.
- Маршрутный блок панели приборов сохраняет отдельные размеры шрифта для расстояния, времени
  прибытия и оставшегося времени, четыре внутренних отступа карточки и знака, ширину области
  знака, толщину и положение прогресс-бара, размер маркера, фон, рамку и скругление.
- Прогресс-бар продолжает использовать реальные сегменты пробок и не содержит кнопки завершения.

## Камера карты

- В режиме «Свободное положение» фиксируется только географическая точка: изменение наклона и
  масштаба продолжает применяться сразу после сохранения.
- После команды перемещения проверяется фактическая камера MapKit. Если нативный слой вернул
  старый наклон или масштаб, профиль применяется повторно на следующем кадре навигации.
- Фиксированный масштаб и готовые режимы 2D/3D остаются независимыми для HUD и панели приборов.

## Установка

```bash
adb install -r Natro-2.5.10-signed.apk
adb install -r YN_30.3.0_Natro-HUD-v2-signed.apk
```

Не удаляйте Natro или Навигатор: для обновления должны сохраниться прежний пакет и сертификат.
Дорожная проверка на ECARX KX11 всё равно обязательна: настольные тесты не воспроизводят
реальный DIM-сервис и нативный рендер MapKit головного устройства.
